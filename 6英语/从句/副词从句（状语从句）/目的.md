# so … that 与 so that 分开讲（考试高频）

## 1）so that（连在一起，引导**目的状语从句**）

含义：**为了，以便**，表目的；从句常带 can / could / may / might。

> Speak clearly **so that** they can hear you. 说清楚一点，**好让**他们听见。

✅ 可以省略 that；否定：so that…not（以便不）

## 2）so … that …（分开！so + 形容词/副词 + that，**结果状语从句**）

含义：**如此……以至于……**，引出结果。 公式：

- so + **形容词** + that He is **so hungry that** he eats two carrots. 他如此饿，以至于吃了两根胡萝卜。
- so + **副词** + that He runs **so fast that** we can’t catch him. 他跑得如此快，我们追不上。

> ⚠️ 重点区分： **so that（目的）**：为了……（强调意图） **so … that（结果）**：如此…以至于（强调带来的结果）

## 3）特殊：so + many/much/few/little +名词 + that

只能用 so，**不能用 such**

- so many carrots that… 如此多胡萝卜以至于……

## 和 such … that 简单对比（容易混）

- so + adj./adv. + that
- such + (a/an) + adj. + 名词 + that
    
    > such a hungry rabbit that… 一只如此饿的兔子以至于……
    

## 极简口诀

**so that 连写表目的；so…that 分开表结果。**

### 小练习判断

1. He studies hard **so that** he can pass the exam. → 目的（为了通过考试）
2. He studied **so hard that** he passed the exam. → 结果（学得如此努力，所以考过了）
