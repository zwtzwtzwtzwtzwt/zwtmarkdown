# 无界但不是无穷  

要理解“无界”和“无穷大”的区别，核心在于抓住它们在定义上的差异：

- **无界（Unbounded）：** 指的是函数（或数列）的值能够**偶尔**跑得非常远，没有一个固定的“天花板”或“地板”能把它永远关住。
    
- **无穷大（Infinitely Large）：** 这是一个极限概念。指的是当自变量趋于某个过程时，函数的值**最终必须全部**跑到很远的地方，不能再回来。
    

简而言之：**无穷大一定无界，但无界不一定是无穷大。** 那些“无界但不是无穷大”的例子，通常都有一个共同特征：**振幅越来越大，但始终会频繁地回到 0（或某个固定范围内）。**

以下是高等数学中最经典的几个例子，无论是在数列还是函数极限中都非常常见：

### 1. 趋于无穷时的连续函数：$f(x) = x \sin x \ (x \to +\infty)$

这是考研数学中最常用来举反例的函数。

- **为什么无界？**
    
    我们取特殊的点列 $x_k = 2k\pi + \frac{\pi}{2}$，此时 $\sin x_k = 1$。
    
    那么 $f(x_k) = 2k\pi + \frac{\pi}{2}$。随着 $k \to \infty$，$f(x_k) \to +\infty$，所以它没有上限，是无界的。
    
- **为什么不是无穷大？**
    
    我们再取另一个特殊的点列 $x_k = k\pi$，此时 $\sin x_k = 0$。
    
    那么 $f(x_k) = 0$。这意味着无论 $x$ 跑得多远（无论 $X$ 取多大），在 $(X, +\infty)$ 这个区间里，函数图像总是会不断地穿过 $x$ 轴（值为 0）。它没有办法“永远待在绝对值大于 $M$ 的地方”，因此 $\lim_{x \to +\infty} x \sin x \neq \infty$。
    

### 2. 趋于某一点时的连续函数：$f(x) = \frac{1}{x} \sin(\frac{1}{x}) \ (x \to 0)$

这个例子和第一个本质相同，只是把趋于无穷的过程换成了趋于一个具体点（$x \to 0$）。

- **为什么无界？**
    
    令 $x_k = \frac{1}{2k\pi + \frac{\pi}{2}}$，当 $k \to \infty$ 时，$x_k \to 0$。
    
    此时 $f(x_k) = (2k\pi + \frac{\pi}{2}) \cdot 1 \to +\infty$。在 0 的任意小邻域内，函数值都能大到离谱，所以无界。
    
- **为什么不是无穷大？**
    
    令 $x_k = \frac{1}{k\pi}$，当 $k \to \infty$ 时，$x_k \to 0$。
    
    此时 $f(x_k) = k\pi \cdot 0 = 0$。在 0 的任意小邻域内，函数总是不断地回落到 0，因此极限不是无穷大。
    

### 3. 数列极限中的例子：$x_n = n(1 + (-1)^n) \ (n \to \infty)$

在离散的数列中，这个构造更加直观。

- 把数列的前几项写出来：
    
    $n=1: x_1 = 1(1-1) = 0$
    
    $n=2: x_2 = 2(1+1) = 4$
    
    $n=3: x_3 = 3(1-1) = 0$
    
    $n=4: x_4 = 4(1+1) = 8$
    
    $n=5: x_5 = 0$
    
- **为什么无界？** 当 $n$ 为偶数时，$x_n = 2n \to +\infty$，偶数项子列发散，所以整个数列无界。
    
- **为什么不是无穷大？** 当 $n$ 为奇数时，$x_n = 0$。因为奇数项子列始终为 0，它并没有“最终所有项的绝对值都大于给定的正数 $M$”，所以数列的极限不是无穷大。
    

> **总结规律：** 在构造这类函数或数列时，标准套路就是用一个**趋于无穷的项**（比如 $x$、$\frac{1}{x}$ 或 $n$）去乘以一个**在 0 附近震荡的项**（比如 $\sin x$ 或 $1+(-1)^n$）。
