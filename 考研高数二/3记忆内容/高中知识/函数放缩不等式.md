## 1. 函数放缩核心不等式（最常用于极限与证明）

这一组不等式在构造夹逼定理、判断级数敛散性以及中值定理证明题中出现频率极高，通常可以通过泰勒公式或单调性推导出来。

- **指数与线性化：**
    
    $$e^x \ge x + 1$$
    
    _(等号成立条件：$x = 0$。这个不等式非常万能，常用来把复杂的指数放缩为多项式)_
    
- **对数与线性化：**
    
    当 $x > 0$ 时：
    
    $$\ln x \le x - 1$$
    
    或者写成等价形式，当 $x > -1$ 时：
    
    $$\ln(1+x) \le x$$
    
- **对数的双边夹逼：**
    
    当 $x > 0$ 时：
    
    $$\frac{x}{1+x} < \ln(1+x) < x$$
    
- **三角函数双边夹逼：**
    
    当 $x \in (0, \frac{\pi}{2})$ 时：
    
    $$\sin x < x < \tan x$$
    
    _(这是推导重要极限 $\lim_{x \to 0} \frac{\sin x}{x} = 1$ 的基础)_
    
- **乔丹不等式（常用在积分估计中）：**
    
    当 $x \in (0, \frac{\pi}{2}]$ 时：
    
    $$\frac{2}{\pi}x \le \sin x \le x$$
