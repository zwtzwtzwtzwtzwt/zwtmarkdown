

### 1. 将已知条件翻译为“秩”的语言

定理给出了两个已知条件，我们直接把它们转换为矩阵秩的表达式：

- **条件一：** 向量组 $\beta_1, \beta_2, \cdots, \beta_s$ 线性无关。
    
    这意味着这 $s$ 个向量提供的全都是独立信息。因此，由它们组成的矩阵的秩达到了最大可能值，即：
    
    $$r(\beta_1, \beta_2, \cdots, \beta_s) = s$$
    
- **条件二：** 向量组 $\beta_1, \beta_2, \cdots, \beta_s, \alpha$ 线性相关。
    
    这意味着这 $s+1$ 个向量中存在信息冗余。因此，它们的秩必然**严格小于**向量的总个数 $s+1$，即：
    
    $$r(\beta_1, \beta_2, \cdots, \beta_s, \alpha) < s + 1$$
    

### 2. 锁定增广矩阵的绝对“秩”

在线性代数中有一个基本常识：**给矩阵增加一列，矩阵的秩要么不变，要么最多增加 1。**

现在我们把 $\alpha$ 作为新的一列拼接到 $\beta$ 组后面。

原来的秩是 $s$。加上 $\alpha$ 后，新的秩只能是 $s$ 或者 $s+1$。

但根据第一步中的条件二，新的秩必须严格小于 $s+1$。

因此，唯一的可能就是**秩没有增加**：

$$r(\beta_1, \beta_2, \cdots, \beta_s, \alpha) = s$$

### 3. 证明“能够表示”（解的存在性）

探讨 $\alpha$ 能否由 $\beta$ 组线性表示，等价于探讨非齐次线性方程组 $Bx = \alpha$ 是否有解。其中系数矩阵 $B = (\beta_1, \beta_2, \cdots, \beta_s)$。

根据线性方程组解的判定定理（克罗内克-卡佩里定理）：

- 系数矩阵的秩：$r(B) = r(\beta_1, \beta_2, \cdots, \beta_s) = s$
    
- 增广矩阵的秩：$r(B, \alpha) = r(\beta_1, \beta_2, \cdots, \beta_s, \alpha) = s$
    

既然**系数矩阵的秩 = 增广矩阵的秩**，那么该线性方程组**必然有解**。

这就从根本上证明了 $\alpha$ 一定能由 $\beta$ 组线性表示。

### 4. 证明“表示唯一”（解的唯一性）

既然有解，这个解会不会有无数个呢？这取决于方程组的**自由度**。

- 未知数的个数：我们要找的是 $\beta_1$ 到 $\beta_s$ 前面的系数 $x_1, x_2, \cdots, x_s$，总共有 ** $s$ 个未知数**。
    
- 有效方程的个数（即矩阵的秩）：从第 3 步已知，**秩 $r = s$ **。
    

因为 **矩阵的秩 ($r$) = 未知数的个数 ($n$)**，即 $s = s$。

这意味着方程组是“满秩”的，没有任何自由变量可以随意取值。因此，方程组不仅有解，而且**有且仅有唯一解**。

这就证明了表示式是唯一的。

**秩视角的本质总结：**

$\beta$ 组已经撑起了一个完整的 $s$ 维空间（$r=s$）。把 $\alpha$ 加进去后，总体的维度依然是 $s$ 维（$r$ 没变）。这说明 $\alpha$ 这个向量身上**没有任何一丝一毫突破原空间的新维度信息**，它被死死地困在了 $\beta$ 组撑起的空间里。既然在别人的地盘里，它自然能被这组坐标基（$\beta$ 组）精准且唯一地定位。
