这四个定律是代数学和抽象代数中最基础的运算规则。它们定义了数字或变量在进行运算时如何相互作用。以下是它们的具体定义和数学表达式：

### 1. 交换律 (Commutative Law)

**定义**：在特定的二元运算中，交换参与运算的两个元素的位置（顺序），其最终的运算结果保持不变。这意味着“谁先谁后”并不影响结果。

- **加法交换律**：
    
    $$a + b = b + a$$
    
- **乘法交换律**：
    
    $$a \times b = b \times a$$
    
    _(注：减法和除法不满足交换律，例如 $a - b \neq b - a$)_
    

### 2. 结合律 (Associative Law)

**定义**：在含有三个或以上元素的连续运算中，改变运算的先后结合顺序（即括号的位置），其最终的运算结果保持不变。这意味着“先算哪一部分”并不影响结果。

- **加法结合律**：
    
    $$(a + b) + c = a + (b + c)$$
    
- **乘法结合律**：
    
    $$(a \times b) \times c = a \times (b \times c)$$
    

### 3. 分配律 (Distributive Law)

**定义**：分配律描述了两种不同运算（通常是乘法和加法）之间的交互关系。将一个数乘以两个数的和，其结果等于将这个数分别乘以这两个加数，然后再将得到的乘积相加。

- **乘法对加法的分配律**：
    
    $$a \times (b + c) = a \times b + a \times c$$
    
    _(注：在布尔代数或集合论中，还存在加法对乘法的分配律，但在我们日常的实数运算中，乘法对加法的分配律是最常用到的。)_
    

### 4. 消去律 (Cancellation Law)

**定义**：在等式的两边同时存在相同的元素和相同的运算时，可以在满足特定条件的情况下将该元素“消去”，从而得出剩余元素相等的结论。

- **加法消去律**：如果
    
    $$a + c = b + c$$
    
    ，那么可以得出
    
    $$a = b$$
    
    。（相当于等式两边同时减去 $c$）
    
- **乘法消去律**：如果
    
    $$a \times c = b \times c$$
    
    且前提条件是
    
    $$c \neq 0$$
    
    ，那么可以得出
    
    $$a = b$$
    
    。（相当于等式两边同时除以 $c$，因此 $c$ 不能为零）
