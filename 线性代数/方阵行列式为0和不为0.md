
以下是$n$阶方阵$A$的行列式$|A|\neq0$与$|A|=0$所能推出的等价结论对照表：

| 核心维度 | $|A|\neq0$ (非奇异/满秩) | $|A|=0$ (奇异/降秩) |

| :--- | :--- | :--- |

| **可逆性** | $A$是可逆矩阵，存在逆矩阵$A^{-1}$ | $A$是不可逆矩阵，不存在逆矩阵 |

| **矩阵的秩** | 满秩，$r(A)=n$ | 降秩，$r(A)<n$ |

| **行/列向量组** | $A$的$n$个行(或列)向量线性无关 | $A$的$n$个行(或列)向量线性相关 |

| **齐次方程组 $Ax=0$** | 只有唯一零解$x=0$ | 有非零解(即有无穷多解) |

| **非齐次方程组 $Ax=b$** | 有唯一解 | 无解或有无穷多解 |

| **特征值** | $A$的所有特征值$\lambda\neq0$ | $A$至少有一个特征值$\lambda=0$ |

| **矩阵等价** | $A$与$n$阶单位矩阵$E$等价($A\cong E$) | $A$不与单位矩阵$E$等价 |

| **初等变换** | $A$可表示为有限个初等矩阵的乘积 | $A$不能表示为初等矩阵的乘积 |

| **等价标准形** | $A$的等价标准形为单位矩阵$E$ | $A$的等价标准形主对角线上至少含一个$0$ |

| **伴随矩阵 $A^*$** | $|A^*|\neq0$，$r(A^*)=n$ | 若$r(A)=n-1$则$r(A^*)=1$；若$r(A)<n-1$则$r(A^*)=0$ |
