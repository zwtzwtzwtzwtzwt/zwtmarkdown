在线性代数中，**行列式是否为 0** 是判断矩阵性质最重要的依据之一。很多结论都可以由此直接推出。

下面总结为一张考试最常用的对比表。

| 性质           | (\det(A)\neq 0)                  | (\det(A)=0)                                     |
| ------------ | -------------------------------- | ----------------------------------------------- |
| 矩阵类型         | 非奇异矩阵（可逆矩阵）                      | 奇异矩阵（不可逆矩阵）                                     |
| 是否可逆         | ✅ 可逆                             | ❌ 不可逆                                           |
| 是否存在逆矩阵      | (A^{-1})存在                       | (A^{-1})不存在                                     |
| 矩阵秩          | (r(A)=n)                         | (r(A)<n)                                        |
| 行（列）向量关系     | 线性无关                             | 线性相关                                            |
| 行（列）是否构成基    | 可以                               | 不可以                                             |
| 是否满秩         | 是                                | 否                                               |
| 齐次方程 (Ax=0)  | 只有零解                             | 有非零解（无穷多个）                                      |
| 非齐次方程 (Ax=b) | 对任意(b)唯一解                        | 可能无解，也可能无穷多解                                    |
| 是否可以表示所有向量   | 可以                               | 不一定                                             |
| 特征值          | 没有 0 特征值                         | 至少有一个 0 特征值                                     |
| 特征值乘积        | (\lambda_1\cdots\lambda_n\neq 0) | (\lambda_1\cdots\lambda_n=0)                    |
| 是否存在伴随矩阵     | 存在                               | 存在（任何方阵都有）                                      |
| 伴随矩阵性质       | (A^*=\det(A)A^{-1})              | 不能写成此形式                                         |
| 伴随矩阵秩        | (r(A^*)=n)                       | 若(r(A)=n-1)，则(r(A^_)=1)；若(r(A)\le n-2)，则(A^_=0) |
| 初等变换         | 可化为单位矩阵                          | 不能化为单位矩阵，只能化为阶梯形                                |
| 是否可分解为初等矩阵乘积 | 可以                               | 不可以                                             |
| 是否可用克拉默法则    | 可以                               | 不可以                                             |
| 是否满射（线性变换）   | 是                                | 否                                               |
| 是否单射（线性变换）   | 是                                | 否                                               |
| 是否双射         | 是                                | 否                                               |

---

# 关于线性方程组

设 (A) 为 (n\times n) 方阵。

| 行列式             | 齐次方程 (Ax=0) | 非齐次方程 (Ax=b) |
| --------------- | ----------- | ------------ |
| (\det(A)\neq 0) | 只有零解        | 对任意(b)唯一解    |
| (\det(A)=0)     | 一定有非零解      | 无解或无穷多解      |

考试中最喜欢考这一条。

---

# 关于秩

|行列式|秩|
|---|---|
|(\det(A)\neq 0)|(r(A)=n)|
|(\det(A)=0)|(r(A)<n)|

反过来也成立：

- (r(A)=n\iff\det(A)\neq 0)
    
- (r(A)<n\iff\det(A)=0)
    

因此在考试中，这四句话完全等价。

---

# 关于向量组

设矩阵列向量为

[  
A=(\alpha_1,\alpha_2,\cdots,\alpha_n)  
]

|行列式|向量关系|
|---|---|
|(\det(A)\neq 0)|列向量线性无关|
|(\det(A)=0)|列向量线性相关|

同样适用于行向量。

---

# 关于特征值

因为

[  
\det(A)=\lambda_1\lambda_2\cdots\lambda_n  
]

所以：

|行列式|特征值|
|---|---|
|(\det(A)\neq 0)|所有特征值都不为 0|
|(\det(A)=0)|至少有一个特征值为 0|

---

# 关于伴随矩阵（考研高频）

设 (A) 为 (n) 阶矩阵。

|(r(A))|(r(A^*))|
|---|---|
|(n)|(n)|
|(n-1)|(1)|
|(\le n-2)|(0)|

这是考研数学中关于伴随矩阵最经典的结论。

---

# 所有等价条件（重点记忆）

对于 (n) 阶方阵，下列命题两两等价：

|等价命题|
|---|
|(\det(A)\neq 0)|
|(A)可逆|
|存在(A^{-1})|
|(r(A)=n)|
|满秩矩阵|
|行向量线性无关|
|列向量线性无关|
|初等变换可化为单位矩阵|
|能表示成有限个初等矩阵乘积|
|齐次方程只有零解|
|非齐次方程唯一解|
|可以使用克拉默法则|
|没有 0 特征值|
|线性变换是一一对应（双射）|

对应地，下面这些命题也两两等价：

|等价命题|
|---|
|(\det(A)=0)|
|(A)不可逆|
|不存在逆矩阵|
|(r(A)<n)|
|非满秩|
|行向量线性相关|
|列向量线性相关|
|初等变换不能化为单位矩阵|
|齐次方程有非零解|
|非齐次方程无解或无穷多解|
|至少存在一个 0 特征值|
|线性变换不是双射|

这两组等价命题几乎涵盖了考研线性代数中由**行列式是否为零**所能推出的所有核心结论，也是考试中最常见的推理链。
