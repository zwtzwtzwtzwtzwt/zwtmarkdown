**幂零矩阵**（Nilpotent Matrix）是线性代数中一个非常经典且常考的特殊矩阵。

通俗地讲，它就是一个“自己乘自己，乘着乘着就变成零矩阵”的方阵。

### 1. 数学定义

设 $\mathbf{A}$ 是一个 $n$ 阶方阵，如果存在一个正整数 $k$，使得：

$$\mathbf{A}^k = \mathbf{O}$$

（其中 $\mathbf{O}$ 是全零矩阵），那么就称 $\mathbf{A}$ 为**幂零矩阵**。

满足 $\mathbf{A}^k = \mathbf{O}$ 的最小正整数 $k$，被称为该矩阵的**幂零指数**。

### 2. 直观的例子

最典型的幂零矩阵就是**严格的对角线全为 0 的上（下）三角矩阵**。

例如，对于一个 $2 \times 2$ 的矩阵：

$$\mathbf{A} = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}$$

你算一下它的平方：

$$\mathbf{A}^2 = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix} = \begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix} = \mathbf{O}$$

这里 $\mathbf{A}$ 就是一个幂零矩阵，它的幂零指数是 2。

### 3. 核心性质（考研线代高频考点）

在复习备考时，遇到“题目已知某矩阵为幂零矩阵（或已知 $\mathbf{A}^k=0$）”，你需要条件反射般地联想到以下几个核心结论：

- **特征值全为 0**：这是它最重要的性质。因为如果 $\lambda$ 是 $\mathbf{A}$ 的特征值，那么 $\lambda^k$ 就是 $\mathbf{A}^k$ 的特征值。既然 $\mathbf{A}^k = \mathbf{O}$，说明 $\lambda^k = 0$，即所有的特征值 $\lambda_1 = \lambda_2 = \dots = \lambda_n = 0$。
    
- **行列式为 0**：因为行列式等于所有特征值的乘积（$|\mathbf{A}| = \prod \lambda_i = 0$）。这意味着幂零矩阵**一定不可逆**。
    
- **迹为 0**：我们在上个问题提过，矩阵的迹等于特征值之和。既然特征值全是 0，所以 $\text{tr}(\mathbf{A}) = 0$。
    
- **特征多项式极简**：它的特征多项式必然是 $f(\lambda) = |\lambda \mathbf{I} - \mathbf{A}| = \lambda^n$。
    

### 4. 经典考法：与恒等变形结合的逆矩阵运算

有一类非常经典的题目，会利用幂零矩阵来求另一个矩阵的逆。

我们都知道代数里的多项式展开公式：

$(1-x)(1+x+x^2+\dots+x^{k-1}) = 1 - x^k$

把它平移到矩阵的世界里（因为 $\mathbf{I}$ 和 $\mathbf{A}$ 是可以交换的，所以多项式乘法规则适用）：

$$(\mathbf{I} - \mathbf{A})(\mathbf{I} + \mathbf{A} + \mathbf{A}^2 + \dots + \mathbf{A}^{k-1}) = \mathbf{I} - \mathbf{A}^k$$

如果已知 $\mathbf{A}$ 是幂零矩阵，且 $\mathbf{A}^k = \mathbf{O}$，那么等式右边就变成了 $\mathbf{I} - \mathbf{O} = \mathbf{I}$。

这就直接推导出了一个极其重要的结论：**如果 $\mathbf{A}$ 是幂零矩阵，那么 $(\mathbf{I} - \mathbf{A})$ 一定可逆**，且它的逆矩阵非常规整：

$$(\mathbf{I} - \mathbf{A})^{-1} = \mathbf{I} + \mathbf{A} + \mathbf{A}^2 + \dots + \mathbf{A}^{k-1}$$

这种“通过构造多项式直接写出逆矩阵”的技巧，在综合大题中非常实用。
