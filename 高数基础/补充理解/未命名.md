在微积分中，极限和导数的存在性是分析函数性质的核心。以下是关于**极限不存在**和**导数不存在**的具体情况，已为你整理成表格对比，并附带了典型的数学反例。

### 一、 极限 $\lim_{x \to x_0} f(x)$ 不存在的情况

函数在某一点的极限存在，要求其左极限和右极限均存在且相等。若打破这一条件，极限即不存在。

| **情况分类**    | **几何表现 / 特征**                                | **数学表现形式**                                                                           | **典型反例 (在 x=0 处)**                                                            |     |                                          |
| ----------- | -------------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- | --- | ---------------------------------------- |
| **左右极限不相等** | 函数图像在 $x_0$ 处发生“断崖式”跳跃（跳跃间断点）。               | $\lim_{x \to x_0^-} f(x) \neq \lim_{x \to x_0^+} f(x)$<br><br>  <br><br>（左右极限均存在但不等） | $f(x)=\|x\|$                                                                  | x\\ | }{$<br><br>  <br><br>左极限为 $ $$，右极限为 $ $。 |
| **极限趋于无穷大** | 函数图像在 $x_0$ 处有一条垂直渐近线（无穷间断点）。                | $\lim_{x \to x_0} f(x) = \infty$<br><br>  <br><br>（作为实数，极限不存在）                       | $f(x) = \frac{1}{x}$<br><br>  <br><br>当 $x \to 0$ 时，函数值趋于 $\infty$。           |     |                                          |
| **函数值剧烈震荡** | 函数在 $x_0$ 附近在两个常数之间无限次震荡，无法稳定逼近某一确定值（震荡间断点）。 | $\lim_{x \to x_0} f(x)$ 的值不唯一或无法确定。                                                  | $f(x) = \sin(\frac{1}{x})$<br><br>  <br><br>当 $x \to 0$ 时，值在 $[-1, 1]$ 间无限震荡。 |     |                                          |

### 二、 导数 $f'(x_0)$ 不存在的情况

**连续是可导的必要条件。** 导数本质上是差商的极限，因此导数不存在的情况，本质上也是某种极限不存在的表现。

|**情况分类**|**几何表现 / 特征**|**数学表现形式**|**典型反例 (在 x=0 处)**|
|---|---|---|---|
|**函数在该点不连续**|图像在该点断开（包含跳跃、无穷、可去或震荡间断点）。| $\lim_{x \to x_0} f(x) \neq f(x_0)$ 或极限不存在。<br><br>  <br><br>**（不连续必不可导）**| $f(x) = \begin{cases} 1, & x \geq 0 \\ 0, & x < 0 \end{cases}$<br><br>  <br><br>在 $x=0$ 处断开，无切线。|
|**连续，但左右导数不等**|图像连续，但在该点出现**尖点**或**折点**，不够平滑。| $f'_-(x_0) \neq f'_+(x_0)$<br><br>  <br><br>（左右导数均存在但不等）| $f(x) = \\ |x$<br><br>  <br><br>左导数为 $ $$，右导数为 $ $，折点处无唯一切线。 |
|**导数趋于无穷大**|图像在该点连续且平滑，但**切线垂直于 x 轴**（斜率为无穷大）。| $\lim_{\Delta x \to 0} \frac{f(x_0+\Delta x)-f(x_0)}{\Delta x} = \infty$ | $f(x) = x^{\frac{1}{3}}$<br><br>  <br><br>在 $x=0$ 处有一条垂直切线 $x=0$。|

> **核心逻辑备忘：**
> 
> - **可导必连续，连续不一定可导**（如尖点 $f(x)=|x|$）。
>     
> - 判断分段函数在分界点是否可导时，必须严格按照定义，先验证**连续性**，再分别求**左导数和右导数**看是否相等。这是基础题型中极易设置陷阱的地方。
