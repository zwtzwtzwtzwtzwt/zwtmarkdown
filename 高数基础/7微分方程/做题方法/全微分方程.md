这是一道非常经典的**全微分方程**题目。图片里的提示已经给出了核心思路，即验证偏导数是否相等，然后使用**偏积分**法来求解。

下面是详细的求解过程：

### 第一步：验证是否为全微分方程

已知微分方程为：

$$(2y - 3x)dx + (2x - 5y)dy = 0$$

我们可以令：

- $P(x, y) = 2y - 3x$
    
- $Q(x, y) = 2x - 5y$
    

分别求偏导数：

$$\frac{\partial P}{\partial y} = 2$$

$$\frac{\partial Q}{\partial x} = 2$$

因为 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = 2$，所以该方程满足全微分方程的结构特点，原式的左端是一个二元函数 $u(x, y)$ 的全微分，即 $du = Pdx + Qdy = 0$。

### 第二步：求通解（偏积分法）

根据全微分的定义，我们知道：

$$\frac{\partial u}{\partial x} = 2y - 3x$$

$$\frac{\partial u}{\partial y} = 2x - 5y$$

对第一个式子两边关于 $x$ 进行偏积分（将 $y$ 视为常数）：

$$u(x, y) = \int (2y - 3x) dx = 2xy - \frac{3}{2}x^2 + \phi(y)$$

_注意：这里的积分常数是一个关于 $y$ 的函数 $\phi(y)$。_

接着，将得到的 $u(x, y)$ 对 $y$ 求偏导，并令其等于 $Q(x, y)$：

$$\frac{\partial u}{\partial y} = 2x + \phi'(y) = 2x - 5y$$

化简后得到：

$$\phi'(y) = -5y$$

对 $\phi'(y)$ 关于 $y$ 积分：

$$\phi(y) = -\frac{5}{2}y^2 + C_1$$

将 $\phi(y)$ 代回 $u(x, y)$ 的表达式中：

$$u(x, y) = 2xy - \frac{3}{2}x^2 - \frac{5}{2}y^2 + C_1$$

因为微分方程是 $du = 0$，所以 $u(x, y) = C_2$。我们将常数合并为 $C$，得到方程的通解：

$$2xy - \frac{3}{2}x^2 - \frac{5}{2}y^2 = C$$

### 第三步：代入初始条件求特解

题目给定了初始条件 $y(1) = 1$，即当 $x = 1$ 时，$y = 1$。

将其代入通解方程：

$$2(1)(1) - \frac{3}{2}(1)^2 - \frac{5}{2}(1)^2 = C$$

$$2 - 1.5 - 2.5 = C$$

$$C = -2$$

将 $C = -2$ 代回原式：

$$2xy - \frac{3}{2}x^2 - \frac{5}{2}y^2 = -2$$

为了让表达式看起来更整洁，我们可以等式两边同乘 $-2$，最终得到特解为：

$$3x^2 - 4xy + 5y^2 = 4$$

**💡 效率小贴士：**

在考研数学的备考中，如果遇到结构比较简单的多项式全微分方程，熟练掌握“凑微分法”（分组法）往往比偏积分法速度更快、更不容易出错。

比如这个方程展开后可以这样分组：

$$(2ydx + 2xdy) - 3xdx - 5ydy = 0$$

直接凑成全微分形式：

$$2d(xy) - d\left(\frac{3}{2}x^2\right) - d\left(\frac{5}{2}y^2\right) = 0$$

也就是：

$$d\left(2xy - \frac{3}{2}x^2 - \frac{5}{2}y^2\right) = 0$$

这样可以瞬间得到通解，在考场上能节省不少时间！
