图片中要求求解微分方程 $(x-2y)dy = 2ydx$ 的通解。

这是一道典型的一阶线性微分方程题目。为了方便求解，我们可以打破常规，**将 $x$ 视为 $y$ 的函数**进行化简。

### 求解过程

**第一步：整理方程标准形式**

将原方程 $(x - 2y)dy = 2ydx$ 两边同除以 $2ydy$（假设 $y \neq 0$）：

$$\frac{dx}{dy} = \frac{x - 2y}{2y}$$

展开右侧并移项，得到一阶线性微分方程的标准形式 $\frac{dx}{dy} + P(y)x = Q(y)$：

$$\frac{dx}{dy} - \frac{1}{2y}x = -1$$

在这里，我们可以确定 $P(y) = -\frac{1}{2y}$，$Q(y) = -1$。

**第二步：使用积分因子法或代入通解公式**

一阶线性微分方程的通解公式为：

$$x = e^{-\int P(y)dy} \left[ \int Q(y) e^{\int P(y)dy} dy + C \right]$$

先计算积分因子中的指数部分（为书写简便，积分过程暂按 $y > 0$ 处理，符号最终可被常数 $C$ 吸收）：

$$\int P(y)dy = \int -\frac{1}{2y} dy = -\frac{1}{2} \ln y$$

将其代入通解公式：

$$x = e^{\frac{1}{2} \ln y} \left[ \int (-1) \cdot e^{-\frac{1}{2} \ln y} dy + C \right]$$

利用对数性质 $e^{a \ln y} = y^a$ 进一步化简：

$$x = y^{\frac{1}{2}} \left[ \int -y^{-\frac{1}{2}} dy + C \right]$$

$$x = \sqrt{y} \left( -2\sqrt{y} + C \right)$$

**第三步：化简得到最终结果**

将括号外的 $\sqrt{y}$ 乘进去展开：

$$x = -2y + C\sqrt{y}$$

移项整理：

$$x + 2y = C\sqrt{y}$$

为了让表达式消除根号使其更整洁，可以将等式两边同时平方（常数 $C^2$ 可以直接用一个新的任意常数 $C$ 代替）：

$$(x + 2y)^2 = C y$$

**最终结论：**

原微分方程的通解为 ** $(x + 2y)^2 = Cy$ ** （其中 $C$ 为任意常数）。
