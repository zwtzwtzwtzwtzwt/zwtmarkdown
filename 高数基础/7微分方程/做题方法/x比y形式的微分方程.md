图片中要求求解微分方程 $(x-2y)dy = 2ydx$ 的通解。

这是一道典型的一阶线性微分方程题目。为了方便求解，我们可以打破常规，**将 $x$ 视为 $y$ 的函数**进行化简。  
这两种解法在处理一阶微分方程时都非常经典，它们代表了两种截然不同的破题思维。为了在未来的复习和实战中能够迅速调用，我们可以从**核心思维**、**适用场景**和**优缺点**三个维度对这两种方法进行总结对比。

### 解法一：反客为主（一阶线性微分方程法）

这种方法的核心在于**打破常规的自变量与因变量认知**。我们习惯了 $y$ 是 $x$ 的函数，但有时调换视角，问题会豁然开朗。

- **核心思维：** 角色互换。将 $y$ 视为自变量，$x$ 视为因变量，将方程强行凑成一阶线性标准型 $\frac{dx}{dy} + P(y)x = Q(y)$。
    
- **适用场景（触发条件）：** 观察方程中的各项，如果发现某一个变量及其微分（例如 $x$ 和 $dx$）在方程中**只以一次方的形式出现**，而另一个变量（$y$）可能包含高次幂、对数或指数等复杂形式，即可立刻采用此法。
    
- **优点：** * **流程机械化，容错率高。** 一旦化为标准型，只需无脑代入通解公式 $x = e^{-\int P(y)dy} [ \int Q(y) e^{\int P(y)dy} dy + C ]$ 即可。在考研等高压计算环境下，这种“套公式”的方法往往能减少因为代数变形导致的失误。
    
- **缺点：** * 重度依赖积分技巧。如果 $P(y)$ 或 $Q(y)$ 极其复杂，后续计算积分因子和整体积分时可能会遇到阻碍。
    

### 解法二：降维解耦（齐次方程换元法）

这种方法本质上是一种**代数降维**，通过引入中间变量，将原本相互纠缠的 $x$ 和 $y$ 剥离开来。

- **核心思维：** 变量代换。利用 $u = \frac{x}{y}$（或 $u = \frac{y}{x}$），将复杂的齐次方程转化为最基础的**可分离变量方程**。
    
- **适用场景（触发条件）：** 观察方程各项的**总次数**。如果拆开括号后，每一项中 $x$ 和 $y$ 的次数之和完全相同（例如本题中 $x \cdot dy$, $y \cdot dy$, $y \cdot dx$ 都是一次项），则该方程必定是齐次方程。
    
- **优点：** * **逻辑流畅，计算纯粹。** 换元后的计算大多是基础的多项式或分式运算，分离变量的过程非常直观，不需要死记长串的通解公式。
    
- **缺点：** * **步骤较繁琐。** 经历了求导代入、移项合并、分离变量、两边积分，最后还要**回代变量**并进行代数化简。步骤越多，在紧张的答题状态下，出现符号错误或漏掉常数 $C$ 的概率就越大。
    

### 💡 综合复习建议

可以通过以下表格在脑海中建立一个快速反应机制：

|**对比维度**|**视角互换法 (解法一)**|**齐次换元法 (解法二)**|
|---|---|---|
|**观察重点**|找**“一次项”** (单变量及其微分)|找**“同次项”** (各项总次数相等)|
|**解题主线**|凑标准型 $\rightarrow$ 套积分公式|设 $u=\frac{x}{y}$ $\rightarrow$ 凑分离变量 $\rightarrow$ 积分回代|
|**难点所在**|复杂的积分计算|繁冗的代数移项与化简|

这两把“武器”没有绝对的优劣。在日常的综合复习中，遇到此类题目时，**强烈建议在草稿纸上同时用两种思路各推演前两步**，评估哪一种后续的积分或化简更简单，然后再选择最优路径写下解答过程。这种多维度审题的习惯，对于应对难度较高、形式多变的 408 统考或数学专科考试非常有帮助。

### 求解过程

**第一步：整理方程标准形式**

将原方程 $(x - 2y)dy = 2ydx$ 两边同除以 $2ydy$（假设 $y \neq 0$）：

$$\frac{dx}{dy} = \frac{x - 2y}{2y}$$

展开右侧并移项，得到一阶线性微分方程的标准形式 $\frac{dx}{dy} + P(y)x = Q(y)$：

$$\frac{dx}{dy} - \frac{1}{2y}x = -1$$

在这里，我们可以确定 $P(y) = -\frac{1}{2y}$，$Q(y) = -1$。

**第二步：使用积分因子法或代入通解公式**

一阶线性微分方程的通解公式为：

$$x = e^{-\int P(y)dy} \left[ \int Q(y) e^{\int P(y)dy} dy + C \right]$$

先计算积分因子中的指数部分（为书写简便，积分过程暂按 $y > 0$ 处理，符号最终可被常数 $C$ 吸收）：

$$\int P(y)dy = \int -\frac{1}{2y} dy = -\frac{1}{2} \ln y$$

将其代入通解公式：

$$x = e^{\frac{1}{2} \ln y} \left[ \int (-1) \cdot e^{-\frac{1}{2} \ln y} dy + C \right]$$

利用对数性质 $e^{a \ln y} = y^a$ 进一步化简：

$$x = y^{\frac{1}{2}} \left[ \int -y^{-\frac{1}{2}} dy + C \right]$$

$$x = \sqrt{y} \left( -2\sqrt{y} + C \right)$$

**第三步：化简得到最终结果**

将括号外的 $\sqrt{y}$ 乘进去展开：

$$x = -2y + C\sqrt{y}$$

移项整理：

$$x + 2y = C\sqrt{y}$$

为了让表达式消除根号使其更整洁，可以将等式两边同时平方（常数 $C^2$ 可以直接用一个新的任意常数 $C$ 代替）：

$$(x + 2y)^2 = C y$$

**最终结论：**

原微分方程的通解为 ** $(x + 2y)^2 = Cy$ ** （其中 $C$ 为任意常数）。
