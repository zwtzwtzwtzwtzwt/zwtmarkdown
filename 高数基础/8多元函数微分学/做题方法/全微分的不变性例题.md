这道 2015 年的数二/数三真题非常经典。利用**一阶全微分形式的不变性**（即对方程两边同时作用微分算子 $d$，将 $x, y, z$ 的地位等同看待）来求解隐函数的全微分，往往比直接求偏导数再代入公式更高效且不易漏项。

以下是详细的求解步骤：
[全微分形式不变性](../补充理解/全微分形式不变性.md)  
[微分线性性质与乘积法则](../补充理解/微分线性性质与乘积法则.md)
这道题考察的是**隐函数求全微分**。

最终答案为：** $-\frac{1}{3}dx - \frac{2}{3}dy$ **

解决这类问题，正好可以用上我们刚才讨论的**微分线性性质、乘积法则**以及**全微分形式的不变性**。下面提供两种解题方法：

### 1. 寻找隐式给出的 $z$ 值

无论是哪种方法，第一步都需要知道在 $(x,y) = (0,0)$ 时，$z$ 等于多少。

将 $x=0, y=0$ 代入原方程 $e^{x+2y+3z} + xyz = 1$：

$$e^{0+0+3z} + 0 = 1$$

$$e^{3z} = 1$$

解得 $z = 0$。

因此，我们实际要代入计算的完整坐标点是 $(x, y, z) = (0, 0, 0)$。

### 2. 计算全微分

#### 方法一：直接求微分（推荐，利用全微分形式的不变性）

这种方法不需要记复杂的偏导数公式，直接对等式两边“打上 $d$” 即可，计算非常快。

对方程 $e^{x+2y+3z} + xyz = 1$ 两边同时求微分：

$$d(e^{x+2y+3z}) + d(xyz) = d(1)$$

- 左侧第一项（外层指数，内层加法）：$e^{x+2y+3z} \cdot d(x+2y+3z) = e^{x+2y+3z}(dx + 2dy + 3dz)$
    
- 左侧第二项（利用乘积法则拓展到三项）：$yz dx + xz dy + xy dz$
    
- 右侧常数求微分：$0$
    

组合起来：

$$e^{x+2y+3z} (dx + 2dy + 3dz) + yz dx + xz dy + xy dz = 0$$

**高分技巧：** 此时**千万不要**去化简或者提取 $dz$！直接把点 $(0,0,0)$ 代入这个微分式子中，绝大部分项会瞬间变成 0：

$$e^0 (dx + 2dy + 3dz) + 0 \cdot dx + 0 \cdot dy + 0 \cdot dz = 0$$

$$1 \cdot (dx + 2dy + 3dz) = 0$$

现在只需要简单移项，解出 $dz$ 即可：

$$3dz = -dx - 2dy$$

$$dz = -\frac{1}{3}dx - \frac{2}{3}dy$$

#### 方法二：隐函数公式法

这是比较常规的做法，适合用来检查。

令 $F(x,y,z) = e^{x+2y+3z} + xyz - 1 = 0$。

分别求 $F$ 对 $x, y, z$ 的偏导数：

- $F_x = e^{x+2y+3z} + yz$
    
- $F_y = 2e^{x+2y+3z} + xz$
    
- $F_z = 3e^{x+2y+3z} + xy$
    

将点 $(0,0,0)$ 代入这三个偏导数中：

- $F_x(0,0,0) = e^0 + 0 = 1$
    
- $F_y(0,0,0) = 2e^0 + 0 = 2$
    
- $F_z(0,0,0) = 3e^0 + 0 = 3$
    

根据隐函数求导公式求得两个一阶偏导数：

$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z} = -\frac{1}{3}$$

$$\frac{\partial z}{\partial y} = -\frac{F_y}{F_z} = -\frac{2}{3}$$

最后代入全微分标准公式 $dz = \frac{\partial z}{\partial x}dx + \frac{\partial z}{\partial y}dy$：

$$dz|_{(0,0)} = -\frac{1}{3}dx - \frac{2}{3}dy$$
