图片中展示的是高等数学中的隐函数微分法（即利用公式法对隐函数求导）。
为了让你更直观地理解公式的应用，下面我分别为图片中的两种情况各举一个具体的计算例子。
一、 由方程 $F(x,y)=0$ 确定的隐函数 $y=y(x)$
这是对应图片中第（1）部分的一元隐函数求导。
题目：已知方程 $x^2 + y^2 + xy - 3 = 0$，求导数 $y'$。
解答步骤：
构造函数 $F(x, y)$：
将方程的一侧化为 0，令 $F(x, y) = x^2 + y^2 + xy - 3$。
分别求偏导数 $F'_x$ 和 $F'_y$：
将 $y$ 视为常数，对 $x$ 求偏导：
$$F'_x = 2x + y$$
将 $x$ 视为常数，对 $y$ 求偏导：
$$F'_y = 2y + x$$
代入求导公式 $y' = -\frac{F'_x}{F'_y}$：
$$y' = -\frac{2x + y}{x + 2y}$$
(注意：此结果成立的前提是分母 $F'_y = x + 2y \neq 0$)
二、 由方程 $F(x,y,z)=0$ 确定的隐函数 $z=z(x,y)$
这是对应图片中第（2）部分的多元（二元）隐函数求偏导。
题目：已知方程 $x^2y + y^2z + z^2x - 1 = 0$，求偏导数 $\frac{\partial z}{\partial x}$ 和 $\frac{\partial z}{\partial y}$。
解答步骤：
构造函数 $F(x, y, z)$：
令 $F(x, y, z) = x^2y + y^2z + z^2x - 1$。
分别求偏导数 $F'_x$、$F'_y$ 和 $F'_z$：
求某一个变量的偏导时，将另外两个变量视为常数：
对 $x$ 求偏导（把 $y, z$ 当常数）：
$$F'_x = 2xy + z^2$$
对 $y$ 求偏导（把 $x, z$ 当常数）：
$$F'_y = x^2 + 2yz$$
对 $z$ 求偏导（把 $x, y$ 当常数）：
$$F'_z = y^2 + 2zx$$
代入公式 $\frac{\partial z}{\partial x} = -\frac{F'_x}{F'_z}$ 和 $\frac{\partial z}{\partial y} = -\frac{F'_y}{F'_z}$：
$$\frac{\partial z}{\partial x} = -\frac{2xy + z^2}{y^2 + 2zx}$$
$$\frac{\partial z}{\partial y} = -\frac{x^2 + 2yz}{y^2 + 2zx}$$
(注意：此结果成立的前提是分母 $F'_z = y^2 + 2zx \neq 0$)
总结：使用隐函数微分法公式的核心就在于先构造出 $F=0$ 的形式，然后严格按照偏导数的规则求出各变量的偏导，最后套用负号及对应分式的公式即可。如果这个例子有求导的链式法则呢    用求导链式法则做一遍
