# 有界函数 × 无穷大 考研结论汇总表

表格

| 类型  | f(x) 特征                   | g(x)→∞ | 运算结果               |
| :-- | :------------------------ | :----- | :----------------- |
| 1   | 有界，极限存在且 limf(x)=0       | 无穷大    | **仍是无穷大**          |
| 2   | 有界，且 limf(x)=0            | 无穷大    | **0・∞ 未定式**（需具体计算） |
| 3   | 有界、**震荡无极限**（如 sinx,cosx） | 无穷大    | **无界，但不是无穷大**      |
|     |                           |        |                    |

|**有界量 g(x) 的分类**|**g(x) 的极限特征**|**f(x)⋅g(x) 的最终结果**|**核心逻辑与典型例子**|
|---|---|---|---|
|**第一类：极限非零**|$\lim g(x) = A \neq 0$|**必定是无穷大量 ($\infty$)**|无穷大乘以一个稳定的非零数值，其体量依然是无穷大。<br><br>  <br><br>**例：** $x^2 \cdot \frac{2x+1}{x} \to \infty$|
|**第二类：无穷小量**|$\lim g(x) = 0$|$0 \cdot \infty$ 未定式<br><br>  <br><br>（一切皆有可能）|两者发生“量级拔河”，结果可能是 $0$、非零常数、$\infty$ 或发散。<br><br>  <br><br>**例：** $x \cdot \frac{1}{x^2} \to 0$ （无穷小赢）<br><br>  <br><br>**例：** $x \cdot \frac{2}{x} \to 2$ （势均力敌）|
|第三类：震荡无极限<br><br>  <br><br>（包含或跨越 0）|震荡且取值范围包含 $0$<br><br>  <br><br>（如 $\sin x \in [-1, 1]$）|必定发散，<br><br>  <br><br>且【绝不是】无穷大量|乘积会周期性地“砸回” $0$，无法满足无穷大“绝对值无限增大”的严格定义。<br><br>  <br><br>**例：** $x \cdot \sin x$ （极限不存在）|
|第四类：震荡无极限<br><br>  <br><br>（严格远离 0）|震荡但有严格非零下界<br><br>  <br><br>（如 $2+\sin x \in [1, 3]$）|**必定是无穷大量 ($\infty$)**|无论怎么震荡，它的倍率始终托底（例如始终 $\ge 1$ 倍），所以乘积必然也是无穷大。<br><br>  <br><br>**例：** $x \cdot (2+\sin x) \to \infty$|
# 对应经典例子

表格

| 表达式             | 所属类型      | 结果          |
| :-------------- | :-------- | :---------- |
| xsinx (x→∞)     | 震荡有界 ×∞   | 无界非无穷大      |
| x⋅1/x (x→∞)     | 有界趋于 0×∞  | 未定式，结果为常数 1 |
| x(2+sinx) (x→∞) | 有界且远离 0×∞ | 无穷大         |
> 这里的第二行 远离 0  
# 极简背诵口诀

有界非零乘无穷，仍是无穷；

有界趋零乘无穷，未定要算；

震荡有界乘无穷，无界非无穷。
