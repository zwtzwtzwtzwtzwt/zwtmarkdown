# 有界函数 × 无穷大 考研结论汇总表

表格

| 类型  | f(x) 特征                   | g(x)→∞ | 运算结果               |
| :-- | :------------------------ | :----- | :----------------- |
| 1   | 有界，极限存在且 limf(x)=0       | 无穷大    | **仍是无穷大**          |
| 2   | 有界，且 limf(x)=0            | 无穷大    | **0・∞ 未定式**（需具体计算） |
| 3   | 有界、**震荡无极限**（如 sinx,cosx） | 无穷大    | **无界，但不是无穷大**      |

# 对应经典例子

表格

| 表达式             | 所属类型      | 结果          |
| :-------------- | :-------- | :---------- |
| xsinx (x→∞)     | 震荡有界 ×∞   | 无界非无穷大      |
| x(2+sinx) (x→∞) | 有界且远离 0×∞ | 无穷大         |
| x⋅1/x (x→∞)     | 有界趋于 0×∞  | 未定式，结果为常数 1 |
> 这里的第二行 远离 0  
# 极简背诵口诀

有界非零乘无穷，仍是无穷；

有界趋零乘无穷，未定要算；

震荡有界乘无穷，无界非无穷。
