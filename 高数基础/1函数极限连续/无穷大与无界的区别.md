# 有界函数 × 无穷大 分类结论（考研直接背）

设：

f(x) **有界**（∣f(x)∣≤K 恒成立），

x→□lim​g(x)=∞

## 分三种情况

### 情况 1：有界函数 **极限≠0**

有界且 limf(x)=A=0

有界非零极限×∞=∞

### 情况 2：有界函数 **极限 = 0**

有界且 limf(x)=0

0×∞未定式

结果**不一定**：可能是 0、常数、无穷都有可能，要具体计算。

### 情况 3：有界函数 **没有极限**（震荡有界）

比如 sinx,cosx 这种有界但无极限

震荡有界×∞

结果一定是：**无界，但不是无穷大**

# 经典例题秒懂

1. sinx⋅x(x→∞)
    
    sinx 有界震荡无极限，x→∞
    
    → **无界，但不是无穷大**
    
2. (2+sinx)⋅x(x→∞)
    
    2+sinx 有界，且始终在 [1,3] 远离 0
    
    → 直接 = ∞
    
1. x⋅x 1​(x→∞)
    
    x 1​ 有界且极限为 0，x→∞
    
    → 0⋅∞ 未定，结果是常数 1

# 一句话背诵口诀

1. 有界**不为 0**乘无穷 ➜ 还是无穷
2. 有界**趋于 0**乘无穷 ➜ 未定式
3. **震荡有界**乘无穷 ➜ 无界但不是无穷大
