在二维坐标系中，设点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$，直线 $L$ 的一般式方程为 $Ax + By + C = 0$。

- **1. 两点间的距离公式**
    
    用于计算平面上任意两点之间的直线距离：
    
    $$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
    
- **2. 点到直线的距离公式（极其重要）**
    
    设任意一点 $P_0(x_0, y_0)$，它到直线 $L: Ax + By + C = 0$ 的垂直距离：
    
    $$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$
    
    _(注：使用此公式前，必须先将直线方程化为一般式。)_
    
- **3. 两平行直线间的距离公式**
    
    设两条平行直线分别为 $L_1: Ax + By + C_1 = 0$ 和 $L_2: Ax + By + C_2 = 0$ （注意 $A$ 和 $B$ 必须调整为相同系数）：
    
    $$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$$
    
- **4. 直线的斜率与夹角**
    
    已知直线上两点，直线的斜率 $k$：
    
    $$k = \frac{y_2 - y_1}{x_2 - x_1}$$
    
    两相交直线（斜率分别为 $k_1, k_2$）的夹角 $\theta$ 公式：
    
    $$\tan \theta = \left| \frac{k_1 - k_2}{1 + k_1 k_2} \right|$$


### 二、 切线与法线公式（基于显函数 $y = f(x)$）

当直线与曲线相切或垂直时，斜率 $k$ 必须通过**导数**来求解。假设曲线方程为 $y = f(x)$，且在点 $P_0(x_0, y_0)$ 处可导。

- **1. 切线方程 (Tangent Line)**
    
    曲线在点 $P_0(x_0, y_0)$ 处的切线斜率等于该点处的导数值，即 $k = f'(x_0)$。
    
    根据点斜式，**切线方程**为：
    
    $$y - y_0 = f'(x_0)(x - x_0)$$
    
- **2. 法线方程 (Normal Line)**
    
    法线是过切点且与切线垂直的直线。根据垂直直线的斜率关系 $k_1 \cdot k_2 = -1$，法线的斜率为 $k_n = -\frac{1}{f'(x_0)}$ （前提是 $f'(x_0) \neq 0$）。
    
    **法线方程**为：
    
    $$y - y_0 = -\frac{1}{f'(x_0)}(x - x_0)$$
    
    > **注：** 如果 $f'(x_0) = 0$（切线水平），则法线垂直于 x 轴，方程为 $x = x_0$；如果导数趋于无穷大（切线垂直），则法线水平，方程为 $y = y_0$。
