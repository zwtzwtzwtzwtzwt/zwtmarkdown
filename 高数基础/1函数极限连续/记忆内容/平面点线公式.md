在二维坐标系中，设点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$，直线 $L$ 的一般式方程为 $Ax + By + C = 0$。

- **1. 两点间的距离公式**
    
    用于计算平面上任意两点之间的直线距离：
    
    $$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
    
- **2. 点到直线的距离公式（极其重要）**
    
    设任意一点 $P_0(x_0, y_0)$，它到直线 $L: Ax + By + C = 0$ 的垂直距离：
    
    $$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$
    
    _(注：使用此公式前，必须先将直线方程化为一般式。)_
    
- **3. 两平行直线间的距离公式**
    
    设两条平行直线分别为 $L_1: Ax + By + C_1 = 0$ 和 $L_2: Ax + By + C_2 = 0$ （注意 $A$ 和 $B$ 必须调整为相同系数）：
    
    $$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$$
    
- **4. 直线的斜率与夹角**
    
    已知直线上两点，直线的斜率 $k$：
    
    $$k = \frac{y_2 - y_1}{x_2 - x_1}$$
    
    两相交直线（斜率分别为 $k_1, k_2$）的夹角 $\theta$ 公式：
    
    $$\tan \theta = \left| \frac{k_1 - k_2}{1 + k_1 k_2} \right|$$
