# 双曲

| **函数名称**           | **定义式**                                                       | **奇偶性** | **图像特征**                 |
| ------------------ | ------------------------------------------------------------- | ------- | ------------------------ |
| **双曲正弦** $\sinh x$ | $\frac{e^x - e^{-x}}{2}$                                      | **奇函数** | 过原点，在 $\mathbb{R}$ 上单调递增 |
| **双曲余弦** $\cosh x$ | $\frac{e^x + e^{-x}}{2}$                                      | **偶函数** | 悬链线形状，最小值点 $(0,1)$       |
| **双曲正切** $\tanh x$ | $\frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | **奇函数** | 有两条水平渐近线 $y = \pm 1$     |
