这两个对称性是函数图像最核心的几何性质，在高等数学的积分计算、函数作图以及算法分析中经常被当作“隐藏条件”来考察。

为了方便你系统记忆和在做题时快速反应，我将关于点对称（中心对称）**和**关于直线对称（轴对称）的表达式及推导逻辑为你做个全面梳理。

### 一、 轴对称：关于直线 $x = a$ 对称

轴对称的几何直观是“折叠重合”。也就是在对称轴 $x = a$ 的左右两侧，距离相等的两个点，它们的**函数值（纵坐标）相等**。

#### 1. 核心表达式

- **标准形式：**
    
    $$f(x) = f(2a - x)$$
    
- **平移形式：**
    
    $$f(a + x) = f(a - x)$$
    

#### 2. 理解与推导

平移形式 $f(a + x) = f(a - x)$ 最符合直觉：从 $x=a$ 出发，向右走 $x$ 的距离和向左走 $x$ 的距离，得到的高度 $y$ 是一样的。

如果你令 $t = a + x$，那么 $x = t - a$，代入等式右边就变成了 $f(a - (t - a)) = f(2a - t)$。换回变量符号 $x$，就得到了标准形式 $f(x) = f(2a - x)$。

#### 3. 特例退化（偶函数）

当对称轴是 $y$ 轴（即 $x = 0$）时，令 $a = 0$ 代入标准形式，得到：

$$f(x) = f(-x)$$

这正是**偶函数**的定义。

### 二、 中心对称：关于点 $(a, b)$ 对称

中心对称的几何直观是“旋转 180 度重合”。这意味着在对称中心 $(a, b)$ 左右两侧等距的两个点，它们**关于高度 $b$ 互补**（即纵坐标的平均值刚好是 $b$）。

#### 1. 核心表达式

- **标准形式：**
    
    $$f(x) + f(2a - x) = 2b$$
    
- **平移形式：**
    
    $$f(a + x) + f(a - x) = 2b$$
    
- **中点形式：**
    
    $$\frac{f(x) + f(2a - x)}{2} = b$$
    

#### 2. 理解与推导

中点形式最容易记忆：横坐标为 $x$ 和 $2a - x$ 的两点，其中点横坐标为 $a$；由于图像关于 $(a,b)$ 中心对称，这两点的纵坐标 $f(x)$ 和 $f(2a-x)$ 的中点必须刚好落在对称中心的高度 $b$ 上。两边同乘 2 就得到了标准形式。

#### 3. 特例退化（奇函数）

当对称中心是原点 $(0, 0)$ 时，令 $a = 0, b = 0$ 代入标准形式，得到：

$$f(x) + f(-x) = 0 \implies f(-x) = -f(x)$$

这正是**奇函数**的定义。

### 三、 核心对比速查表

在处理综合性数学题或快速判断函数性质时，可以通过等号两边的结构来迅速区分：

|**对称类型**|**几何特征**|**表达式特征 (标准形式)**|**表达式特征 (平移形式)**|**联想特例**|
|---|---|---|---|---|
|**轴对称**<br><br>  <br><br>(关于直线 $x=a$)|左右高度**相等**| $f(x) = f(2a - x)$ | $f(a+x) = f(a-x)$ |偶函数<br><br>  <br><br>($x=0$)|
|**中心对称**<br><br>  <br><br>(关于点 $(a,b)$)|左右高度**相加为常数**| $f(x) + f(2a - x) = 2b$ | $f(a+x) + f(a-x) = 2b$ |奇函数<br><br>  <br><br>($(0,0)$)|

**做题小贴士：**

当你看到题目中给出的抽象方程中，括号里的**两个自变量相加是一个常数**（例如 $x$ 和 $2a-x$ 相加等于 $2a$），这通常就是强烈的暗示：该函数存在对称性。

- 如果是**两个函数值相等**，那就是轴对称；
    
- 如果是**两个函数值相加/相减等于常数**，那就是中心对称。
