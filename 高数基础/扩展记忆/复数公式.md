复数的知识体系非常结构化，主要分为**代数形式**、**三角形式/指数形式**以及它们对应的**运算法则**。

以下是为你整理的复数核心公式与性质总结：

### 1. 基本概念与代数形式

复数的标准代数形式为：

$$z = a + bi$$

其中 $a, b \in \mathbb{R}$，$\text{Re}(z) = a$ 称为实部，$\text{Im}(z) = b$ 称为虚部。

- **虚数单位的周期性：**
    
    $i^2 = -1$，$i^3 = -i$，$i^4 = 1$，$i^5 = i$
    
    一般规律为：$i^{4k} = 1$，$i^{4k+1} = i$，$i^{4k+2} = -1$，$i^{4k+3} = -i$ （$k$ 为整数）。
    

### 2. 共轭与模

设 $z = a + bi$，则：

- **共轭复数：** $\bar{z} = a - bi$
    
- **复数的模（绝对值）：** $|z| = \sqrt{a^2 + b^2}$
    

**核心性质：**

- **模与共轭的关系：** $z \cdot \bar{z} = a^2 + b^2 = |z|^2$ （这是复数除法分母实数化的核心原理）
    
- **共轭的分配律：** $\overline{z_1 \pm z_2} = \bar{z}_1 \pm \bar{z}_2$；$\overline{z_1 z_2} = \bar{z}_1 \bar{z}_2$；$\overline{\left(\frac{z_1}{z_2}\right)} = \frac{\bar{z}_1}{\bar{z}_2}$
    
- **模的乘除法：** $|z_1 z_2| = |z_1| |z_2|$；$\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$
    
- **三角不等式：** $||z_1| - |z_2|| \le |z_1 \pm z_2| \le |z_1| + |z_2|$
    

### 3. 代数形式的四则运算

设 $z_1 = a + bi$，$z_2 = c + di$：

- **加减法：**
    
    $$z_1 \pm z_2 = (a \pm c) + (b \pm d)i$$
    
- **乘法（按多项式展开并应用 $i^2 = -1$）：**
    
    $$z_1 z_2 = (ac - bd) + (ad + bc)i$$
    
- **除法（分子分母同乘分母的共轭复数）：**
    
    $$\frac{z_1}{z_2} = \frac{(a+bi)(c-di)}{(c+di)(c-di)} = \frac{ac+bd}{c^2+d^2} + \frac{bc-ad}{c^2+d^2}i$$
    

### 4. 三角形式、指数形式与欧拉公式

除了代数形式，复数还可以通过复平面上的极坐标 $(r, \theta)$ 来表示。

- **模：** $r = |z| = \sqrt{a^2 + b^2}$
    
- **辐角：** $\theta = \arg(z)$，满足 $\tan\theta = \frac{b}{a}$（需根据点所在的象限确定具体角度）。
    

**三种形式的转换：**

- **三角形式：** $z = r(\cos\theta + i\sin\theta)$
    
- **欧拉公式（神级公式）：** $e^{i\theta} = \cos\theta + i\sin\theta$
    
- **指数形式：** $z = r e^{i\theta}$
    

### 5. 极坐标下的乘除法（模乘除，角加减）

在进行乘除法和乘方运算时，指数形式和三角形式远比代数形式简单：

设 $z_1 = r_1 e^{i\theta_1}$，$z_2 = r_2 e^{i\theta_2}$

- **乘法：** $z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}$ （模相乘，辐角相加）
    
- **除法：** $\frac{z_1}{z_2} = \frac{r_1}{r_2} e^{i(\theta_1 - \theta_2)}$ （模相除，辐角相减）
    

### 6. 棣莫弗定理（乘方与开方）

棣莫弗定理是欧拉公式的直接推论，用于解决复数的高次幂和开根号问题：

- **复数的 $n$ 次方：**
    
    $$z^n = [r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta) = r^n e^{in\theta}$$
    
- **复数的 $n$ 次方根（有 $n$ 个不同的根）：**
    
    $$\sqrt[n]{z} = \sqrt[n]{r} \left( \cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n} \right)$$
    
    其中 $k = 0, 1, 2, \dots, n-1$。在复平面上，这 $n$ 个根均匀地分布在以原点为圆心、半径为 $\sqrt[n]{r}$ 的圆上，构成一个正 $n$ 边形。
    

### 7. 重要的几何意义

- $|z|$：复平面上点到原点的距离。
    
- $|z_1 - z_2|$：复平面上两点 $z_1$ 和 $z_2$ 之间的距离。
    
- 方程 $|z - z_0| = R$：表示复平面上以 $z_0$ 为圆心，$R$ 为半径的圆。
