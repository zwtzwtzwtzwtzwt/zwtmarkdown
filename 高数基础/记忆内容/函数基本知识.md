| **变换类型**       | **对自变量操作 (括号内)**                                                                                                                                                               | **对因变量操作 (括号外)**                                                                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **代数表达**       | $y = f(\text{操作 } x)$                                                                                                                                                          | $y = \text{操作 } f(x)$                                                                                                                                                        |
| **作用方向**       | **水平方向** (左右)                                                                                                                                                                  | **垂直方向** (上下)                                                                                                                                                                |
| **1. 取反 (符号)** | **$y = f(-x)$**<br><br>  <br><br>图像关于 **$y$ 轴**对称翻转。                                                                                                                           | **$y = -f(x)$**<br><br>  <br><br>图像关于 **$x$ 轴**对称翻转。                                                                                                                         |
| **2. 加减 (平移)** | **$y = f(x \pm a)$** $(a > 0)$<br><br>  <br><br>“左加右减”。<br><br>  <br><br>$+a$：整体向**左**平移 $a$ 个单位。<br><br>  <br><br>$-a$：整体向**右**平移 $a$ 个单位。<br><br>  <br><br>_(注：水平平移常常是反直觉的)_ | **$y = f(x) \pm a$** $(a > 0)$<br><br>  <br><br>“上加下减”。<br><br>  <br><br>$+a$：整体向**上**平移 $a$ 个单位。<br><br>  <br><br>$-a$：整体向**下**平移 $a$ 个单位。<br><br>  <br><br>_(注：垂直平移是顺直觉的)_ |
| **3. 绝对值**     | **$y = f(\vert x \vert)$**<br><br>  <br><br>保留 **$y$ 轴右侧** ($x \ge 0$) 的图像，擦除左侧图像，然后将右侧图像关于 $y$ 轴对称复制到左侧。<br><br>  <br><br>_(结果必然是一个偶函数)_                                      | **$y = \vert f(x) \vert$**<br><br>  <br><br>保留 **$x$ 轴上方** ($y \ge 0$) 的图像，将 $x$ 轴下方 ($y < 0$) 的图像关于 $x$ 轴翻折到上方。<br><br>  <br><br>_(结果的函数值永远非负)_                             |
