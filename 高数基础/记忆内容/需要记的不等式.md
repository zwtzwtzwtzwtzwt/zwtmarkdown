## 1. 函数放缩核心不等式（最常用于极限与证明）

这一组不等式在构造夹逼定理、判断级数敛散性以及中值定理证明题中出现频率极高，通常可以通过泰勒公式或单调性推导出来。

- **指数与线性化：**
    
    $$e^x \ge x + 1$$
    
    _(等号成立条件：$x = 0$。这个不等式非常万能，常用来把复杂的指数放缩为多项式)_
    
- **对数与线性化：**
    
    当 $x > 0$ 时：
    
    $$\ln x \le x - 1$$
    
    或者写成等价形式，当 $x > -1$ 时：
    
    $$\ln(1+x) \le x$$
    
- **对数的双边夹逼：**
    
    当 $x > 0$ 时：
    
    $$\frac{x}{1+x} < \ln(1+x) < x$$
    
- **三角函数双边夹逼：**
    
    当 $x \in (0, \frac{\pi}{2})$ 时：
    
    $$\sin x < x < \tan x$$
    
    _(这是推导重要极限 $\lim_{x \to 0} \frac{\sin x}{x} = 1$ 的基础)_
    
- **乔丹不等式（常用在积分估计中）：**
    
    当 $x \in (0, \frac{\pi}{2}]$ 时：
    
    $$\frac{2}{\pi}x \le \sin x \le x$$
    

## 2. 基础代数与绝对值不等式

常用于放缩绝对值、证明数列极限或函数的连续性。

- **绝对值三角不等式：**
    
    $$||a| - |b|| \le |a \pm b| \le |a| + |b|$$
    
- **均值不等式（AM-GM 不等式）：**
    
    对于任意实数 $a, b$：
    
    $$ab \le \frac{a^2 + b^2}{2}$$
    
    对于 $a, b > 0$：
    
    $$\frac{2}{\frac{1}{a} + \frac{1}{b}} \le \sqrt{ab} \le \frac{a+b}{2} \le \sqrt{\frac{a^2+b^2}{2}}$$
    
    _(调和平均 $\le$ 几何平均 $\le$ 算术平均 $\le$ 平方平均)_
    
- **伯努利不等式 (Bernoulli's Inequality)：**
    
    对于 $x > -1$ 且 $n$ 为正整数：
    
    $$(1+x)^n \ge 1 + nx$$
    

## 3. 定积分常见不等式

在证明积分不等式或估计积分值时必用。

- **积分绝对值不等式：**
    
    若 $a < b$，则：
    
    $$\left| \int_a^b f(x) dx \right| \le \int_a^b |f(x)| dx$$
    
    _(先积分后取绝对值，小于等于先取绝对值后积分)_
    
- **积分中值放缩：**
    
    若在 $[a,b]$ 上 $m \le f(x) \le M$，则：
    
    $$m(b-a) \le \int_a^b f(x) dx \le M(b-a)$$
    
- **柯西-施瓦茨积分不等式 (Cauchy-Schwarz)：**
    
    $$\left( \int_a^b f(x)g(x) dx \right)^2 \le \left( \int_a^b f^2(x) dx \right) \left( \int_a^b g^2(x) dx \right)$$
    
    _(当且仅当 $f(x)$ 与 $g(x)$ 线性相关时取等号，考研积分证明题的高频杀器)_
    

> **复习建议**：不要死记硬背第一组的函数不等式。遇到忘记的情况，在草稿纸上画一下 $y = e^x$、$y = \ln x$ 与 $y = x \pm 1$ 的图像，或者对它们写前两项的**泰勒展开**，立刻就能看出大小关系。
