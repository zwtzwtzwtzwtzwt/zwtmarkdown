# 圆
## 1. 圆的基本公式

设圆的半径为 $r$，直径为 $d$。

- **直径：** $d = 2r$
    
- **周长（Circumference）：** $C = 2\pi r = \pi d$
    
- **面积（Area）：** $S = \pi r^2 = \frac{\pi d^2}{4}$
    

## 2. 扇形与圆弧公式

计算时需要注意圆心角是**角度制**（设为 $n^\circ$）还是**弧度制**（设为 $\alpha$）。

- **弧长（$l$）：**
    
    - 角度制：$l = \frac{n\pi r}{180}$
        
    - 弧度制：$l = |\alpha| r$
        
- **扇形面积（$S$）：**
    
    - 角度制：$S = \frac{n\pi r^2}{360}$
        
    - 弧度制：$S = \frac{1}{2} |\alpha| r^2 = \frac{1}{2} l r$
        

## 3. 解析几何中的圆方程

设圆心坐标为 $(a, b)$，半径为 $r$。

- **标准方程：**
    
    可以直接看出圆心和半径。
    
    $$(x - a)^2 + (y - b)^2 = r^2$$
    
- **一般方程：**
    
    $$x^2 + y^2 + Dx + Ey + F = 0$$
    
    （判定为圆的条件：$D^2 + E^2 - 4F > 0$）
    
    - 圆心坐标：$(-\frac{D}{2}, -\frac{E}{2})$
        
    - 半径：$r = \frac{\sqrt{D^2 + E^2 - 4F}}{2}$
        
- **参数方程：**
    
    常用于求极值或参数代换，设参数为 $\theta$（$\theta \in [0, 2\pi)$）。
    
    $$x = a + r\cos\theta$$
    
    $$y = b + r\sin\theta$$
    

## 4. 重要的位置关系公式

### 圆心到直线的距离公式

判断直线 $Ax + By + C = 0$ 与圆心为 $(a, b)$、半径为 $r$ 的圆的位置关系，需计算圆心到直线的距离 $d$：

$$d = \frac{|Aa + Bb + C|}{\sqrt{A^2 + B^2}}$$

- $d < r$：直线与圆**相交**。
    
- $d = r$：直线与圆**相切**。
    
- $d > r$：直线与圆**相离**。
    

### 弦长公式

当直线与圆相交时，截得的弦长 $L$ 可以通过勾股定理（半径 $r$、弦心距 $d$、半弦长）快速求出：

$$L = 2\sqrt{r^2 - d^2}$$
