# ipv 4 过程 h 1 到 h 7  
![](./assets/流程分析/流程分析-1789176237625.webp)  
### H 1 发送数据到 H 7 的网络层与数据链路层转发流程

整个转发路径：**H 1 → 校园二层交换机 → 学校路由器 → 公司路由器 → 公司二层交换机 → H 7** 核心规律：网络层的**源 IP、目的 IP 全程保持不变**，TTL 逐跳递减；数据链路层的源/目的 MAC 地址**每经过一台三层路由器就会重新封装**，二层交换机仅转发、不修改帧地址。

---

#### 1. H 1 主机封装并发送（接入网段）

H 1 判断目的 IP 200.1.1.2 与自身 166.1.0.1 不在同一网段，因此将数据包发往默认网关 166.1.0.5（学校路由器 B 2 接口）。

- **网络层（IP 层）** 封装 IP 数据报：**源 IP = 166.1.0.1（H 1 地址）**，**目的 IP = 200.1.1.2（H 7 地址）**；设置初始 TTL（生存时间，例如 128），计算 IP 首部校验和，完成网络层封装。
- **数据链路层**
    1. 地址解析：若 ARP 缓存中无网关 MAC，H 1 发送 ARP 广播请求，查询 166.1.0.5 对应的物理地址，获得学校路由器 B 2 接口的 MAC 后存入缓存。
    2. 封装以太网帧：**源 MAC = H 1 网卡 MAC**，**目的 MAC = 学校路由器 B 2 接口 MAC**；帧类型字段设为 `0x0800`（标识承载 IP 数据报），并填充帧校验序列 FCS。
    3. 转发：帧被发送到校园局域网，二层交换机根据目的 MAC 转发帧，不修改帧内地址，最终送达学校路由器 B 2 接口。

---

#### 2. 学校路由器转发（B 2 入，B 0 出）

路由器是三层设备，先拆除链路层封装，处理 IP 层后再重新封装链路层。

- **数据链路层（接收侧）** B 2 接口收到以太网帧，确认目的 MAC 是自身接口 MAC 后，拆除帧封装，将内部 IP 数据报上交网络层。
- **网络层（路由决策）**
    1. 校验 IP 首部校验和，将 **TTL 值减 1**（例如从 128 变为 127），重新计算并更新 IP 首部校验和。
    2. 查找路由表：目的 IP 200.1.1.2 匹配条目 `200.1.1.0 → B0`，确定出接口为 B 0，下一跳为直连的公司路由器 C 0 接口。
- **数据链路层（发送侧）**
    1. 地址解析：通过 ARP 获取直连链路上公司路由器 C 0 接口的 MAC 地址。
    2. 重新封装以太网帧：**源 MAC = 学校路由器 B 0 接口 MAC**，**目的 MAC = 公司路由器 C 0 接口 MAC**；帧类型保持 `0x0800`，重新计算 FCS。
    3. 帧从 B 0 接口发出，经学校-公司直连链路送达公司路由器 C 0 接口。

---

#### 3. 公司路由器转发（C 0 入，C 2 出）

- **数据链路层（接收侧）** C 0 接口收到帧，确认目的 MAC 是自身接口 MAC 后，拆除帧封装，取出 IP 数据报上交网络层。
- **网络层（路由决策）**
    1. 校验 IP 首部校验和，将 **TTL 值再减 1**（例如从 127 变为 126），重新计算并更新 IP 首部校验和。
    2. 查找路由表：目的 IP 200.1.1.2 匹配条目 `200.1.1.0 → C2`，确定出接口为 C 2，直连公司内网网段。
- **数据链路层（发送侧）**
    1. 地址解析：若 ARP 缓存无 H 7 的 MAC，C 2 接口发送 ARP 广播请求，查询 200.1.1.2 对应的物理地址，获得 H 7 网卡 MAC。
    2. 重新封装以太网帧：**源 MAC = 公司路由器 C 2 接口 MAC**，**目的 MAC = H 7 网卡 MAC**；帧类型为 `0x0800`，重新计算 FCS。
    3. 帧从 C 2 接口发送到公司内网，经二层交换机转发。

---

#### 4. 公司内网交付到 H 7

- **数据链路层**：公司二层交换机根据目的 MAC 将帧转发到 H 7 对应端口；H 7 网卡校验目的 MAC 与自身一致、FCS 无误后，拆除以太网帧封装。
- **网络层**：H 7 网络层校验目的 IP 与自身一致，处理 IP 首部后，将数据上交上层协议，完成端到端交付。
