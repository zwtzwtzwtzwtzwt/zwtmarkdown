## 最短帧长  


CSMA/CD 协议设定最短帧长限制的根本原因，是为了保证发送方能够准确地检测到数据是否发生了碰撞（冲突）。

在 CSMA/CD 的机制中，网卡只有在处于发送状态时，才会去监听信道上的电压变化以检测碰撞。一旦数据发送完毕，网卡就会认为发送成功，并停止针对该帧的碰撞监听。

如果没有最短帧长限制，就会导致一种致命的“误判”：

### 1. 致命的“短帧误判”场景

假设没有帧长限制，节点 A 发送了一个非常短的数据帧（比如只发了 1 个字节）：

- **发送过快：** 因为数据极短，节点 A 可能在 1 微秒内就发完了，然后满意地关闭了发送状态，认为数据已经成功送达。
    
- **途中相撞：** 实际上，这个短帧在电缆上飞驰时，在最远端的节点 B 处碰巧和节点 B 发送的数据撞车了。
    
- **碰撞信号返回：** 碰撞产生的异常电压信号（冲突信号）顺着电缆往回传，需要花费时间才能传回到节点 A。
    
- **错过检测：** 当冲突信号终于传回节点 A 时，<font color="#ff0000">节点 A 早已经发完数据并结束了监听状态。它会把这个冲突信号当成别人的噪音丢弃（不会认为是冲突信号了）</font>，完全不知道自己的数据已经被撞毁了，因此也不会重传。

## 为什么无线网不用 csma/cd 协议  

![](./assets/随机访问（CSMA%20CD%20协议重点）/随机访问（CSMA%20CD%20协议重点）-1783567915170.webp)
这三个原因非常精准地指出了无线物理环境与有线物理环境的本质差异。我们可以用一些通俗易懂的原理和比喻来逐一拆解这些概念。

### 1. 硬件实现极其困难：发射信号带来的“致盲效应”

在有线以太网中，CSMA/CD 要求网卡“边发送边监听”。网卡发出的电信号和收到的电信号在同一根电缆里，电压差异在可控范围内。

但在无线电磁波环境中，存在一个巨大的物理鸿沟：**信号衰减极快**。

- **能量差异悬殊：** 当你的手机天线向外发射数据时，它自身天线周围的电磁波能量是极其巨大的。而远处的另一个设备发给你的信号，经过空气衰减后，到达你天线时已经非常微弱了。
    
- **通俗比喻：** 想象你正拿着一个超级高音喇叭在操场上疯狂大喊（发送数据），同时你还被要求去听清操场另一头某个人对你的轻声耳语（监听其他节点的信号）。你自己的吼声会直接让你的耳朵“致盲”，根本听不见别人的声音。
    
- **硬件瓶颈：** 要想在如此巨大的自身发射功率下，精准过滤掉自己的信号去提取极微弱的外部冲突信号，对无线收发硬件的动态范围和消噪能力要求高得离谱，在消费级民用设备上几乎不可能实现。
    

### 2. 信号极不稳定：缺乏判断冲突的“基准线”

在有线 CSMA/CD 中，判断冲突的标准非常简单粗暴：**看电压有没有异常翻倍**。因为有线环境是封闭的，正常发信号电压是 5 V，两台机器一起发叠加成 10 V，硬件瞬间就能判定撞车了。

但在无线环境中，空气是一个极其复杂、充满变数的开放介质。

- **环境干扰多：** 无线电波在传输时会遇到墙壁阻挡（衰减）、金属反射（多径效应）、甚至有人从路由器前走过，都会导致信号强度瞬间发生剧烈波动。
    
- **无法定义阈值：** 如果你接收到的信号突然变强或变弱，网卡根本无法判断这到底是“发生了数据碰撞”，还是“有人关上了一扇门”，亦或是“两道反射波刚好抵消了”。既然连冲突的判断标准（基准线）都无法稳定建立，冲突检测（CD）也就无从谈起了。
    

### 3. 隐蔽站（隐藏终端）问题：局部监听无法代表全局安全

CSMA（载波监听）的核心前提是：我听一下信道，如果是安静的，就说明大家都没在发数据。这在有线网络（一根线连着所有人）里是成立的。

但在无线网络中，信号是有**物理覆盖半径**的。这会导致“你以为的空闲，只是你局部的空闲”。

- **场景还原：** 假设你的宿舍很长，路由器（AP）在宿舍正中间。节点 A 在最左侧阳台，节点 C 在最右侧门口。A 和 C 都能连上 AP，但 A 和 C 之间的距离太远，超出了彼此的信号覆盖范围。
    
- **致命误判：** A 想要发数据给 AP，A 竖起耳朵听了听，没听到 C 的声音（因为 C 离得太远），A 判定“信道空闲”，开始发送。与此同时，C 也想发数据，C 也听不到 A 的声音，C 也判定“信道空闲”，开始发送。
    
- **接收端车祸：** A 和 C 都在放心地发数据，但这些电磁波会在中间的路由器（AP）处相遇并发生物理叠加。结果就是 AP 收到了两堆乱码，数据发生冲突被毁。而 A 和 C 此时依然觉得信道很通畅。
    

**总结**

正是由于“自己喊声太大听不见别人”、“空气环境太复杂无法定标准”以及“互相看不见导致盲目自信”这三个不可跨越的物理障碍，无线网络不得不彻底放弃“冲突检测（CD）”，转而采用依靠预约和确认机制的“冲突避免（CA）”策略。
