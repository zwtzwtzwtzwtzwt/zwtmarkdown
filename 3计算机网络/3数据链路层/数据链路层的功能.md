
#  数据链路层所在地位
![](./assets/数据链路层的功能/数据链路层的功能-1783338926970.webp)  ![](./assets/数据链路层的功能/数据链路层的功能-1788844964754.webp)
发送：上一层的 pdu 传下来 当做自己的 sdu  加上当前层的 pci 形成当前层的 pdu  ，然后再传给下一层称为下一层的 sdu,下一层重复操作
接受： 接受到当前层的 pdu 恢复为上一层对应的 sdu ，上一层接受到 sdu ，即等价于接受到当层 pdu，重复操作
