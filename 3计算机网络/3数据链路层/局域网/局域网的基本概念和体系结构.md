
这份文本详细梳理了局域网的基础概念、体系结构以及核心硬件部件。以下为您提取的重点知识总结：

### 局域网的基本特点

- **覆盖范围较小：** 通常局限于家庭、学校或企业内部。
    
- **通信质量高：** 节点间距离近，拥有较高的带宽，因此传输时延较低且误码率较低。
    
- **以“帧”为传输单位：** 数据链路层将网络层传来的 IP 数据报封装成帧进行传输。
    
- **支持三种通信模式：** 单播（一对一）、广播（一对全体）、多播（一对部分特定分组）。
    
- **物理寻址：** 依赖 **MAC 地址（物理地址/硬件地址）** 标识节点，长度为 48 比特，全球唯一。
    

### 局域网的三大核心要素对比

在分析任何一种局域网技术时，都需要重点关注其拓扑结构、传输介质和介质访问控制方式。

| **网络技术分类**                    | **拓扑结构**           | **传输介质**        | **介质访问控制方式**                          |
| ----------------------------- | ------------------ | --------------- | ------------------------------------- |
| **令牌环网** (已淘汰)                | 环形                 | 同轴电缆或双绞线        | 令牌传递协议                                |
| **早期以太网** (如 10 Base 5)       | 物理/逻辑均为总线型         | 同轴电缆            | CSMA/CD                               |
| **光纤以太网** (如 10 Base-F)       | 点对点 (常连接中间设备  中继器) | 光纤 (至少两根 实现全双工) | **无需使用** (支持全双工，无冲突)                  |
| **集线器 + 双绞线以太网**(如 10 Base-T) | 物理星型 / 逻辑总线型       | 双绞线             | CSMA/CD (仅支持半双工)                      |
| **交换机 + 双绞线以太网**(如 10 Base-T) | 物理/逻辑均为星型          | 双绞线             | 半双工下用 CSMA/CD，全双工下**无需使用**（由双绞线的数量决定） |
| **无线局域网** (IEEE 802.11)       | 星型 (AP + 多个移动设备)   | 无线电磁波           | CSMA/CA                               |

### 有线局域网与无线局域网演进要点

- **以太网（IEEE 802.3）的统治地位：** 目前几乎所有的有线局域网均采用以太网技术，其物理层统一采用**曼彻斯特编码**。
    
- **光纤以太网的定位：** 主要用于扩大网络覆盖范围，常用于连接中继器、集线器、交换机等中间节点，通常不直接连接终端计算机。
    
- **介质访问控制的核心逻辑：** 只要网络工作在**全双工模式**下（如光纤、或支持全双工的交换机+双绞线），由于不存在信道争用，就**绝对不需要**使用 CSMA/CD 协议。
    
- **无线局域网（IEEE 802.11）：** 核心设备为无线接入点（AP，如路由器）。由于电磁波在空间中容易相互干扰，因此必须使用 **CSMA/CA** 协议来避免冲突。
    

### 核心硬件：网络适配器（网卡 / NIC）

- **两大核心功能：** 负责将帧发送到局域网上，以及从局域网上接收帧。
    
- **串并行转换：** 主机内部通过 IO 总线并行传输数据，而局域网线路上采用串行传输（逐比特），适配器负责这两种方式的数据转换。
    
- **ROM 芯片固化 MAC 地址：** 内部存储全球唯一的 48 比特 MAC 地址。前 24 比特由 IEEE 统一分配给厂商，后 24 比特由厂商自行指派。
    
- **RAM 芯片实现帧缓冲：** 用于暂存即将发送到网络上，或刚刚从网络上接收下来但尚未交给 CPU 的帧数据。
    
- **协议栈的底层实现：** 适配器内部以硬件/微代码的形式，直接实现了特定局域网标准（如 802.3 或 802.11）所要求的数据链路层（MAC 子层）和物理层功能。
    
- **接收帧的完整工作流：** 帧进入 RAM 缓冲区 -> 核对 MAC 地址匹配且无差错 -> 向 CPU 发出中断请求 -> CPU 控制将其通过 IO 总线写入主存 -> 主机软件拆解 IP 数据报交由网络层。
