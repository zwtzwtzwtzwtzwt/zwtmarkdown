主机的**公网 IP（Public IP）**并不是凭空产生的，也不是设备自己生成的，而是通过一个**自顶向下的严格层级分配体系**，最终由你的网络服务提供商（ISP）租借给你的。

我们可以从“宏观分配”和“微观获取”两个视角来彻底理清这个过程：

### 一、 宏观视角：公网 IP 的全球分配链条

公网 IP 是全球互联网中极其珍贵的稀缺资源（特别是 IPv 4），必须保证全球唯一。它的分配就像土地批复一样，有严格的上下级机构：

1. **全球总管：ICANN / IANA**
    
    互联网名称与数字地址分配机构（ICANN）下属的 IANA 负责掌管全球所有的 IP 地址池。它是最顶层的源头。
    
2. **洲际分配：RIR（区域互联网注册管理机构）**
    
    IANA 会把 IP 地址按大段分配给全球五大区域机构。例如，负责中国乃至整个亚太地区的是 **APNIC**（亚太互联网络信息中心）。
    
3. **国家/运营商分配：NIR / LIR (ISP)**
    
    亚太 APNIC 会再把地址段分配给各国的管理机构（如中国的 CNNIC），或者直接分配给大型的**互联网服务提供商（ISP）**，也就是我们熟悉的三大运营商（中国电信、联通、移动），以及大型云服务商（如阿里云、腾讯云、华为云）。
    

**总结：** 运营商花巨资向国际机构“买”（或者说租）下了一大批公网 IP 段，这批 IP 就成了运营商的资产。

### 二、 微观视角：你的主机是如何“拿到”公网 IP 的？

到了我们具体的设备层面，主机获取公网 IP 通常分为以下几种场景：

#### 1. 家庭宽带 / 光纤入户（PPPoE 拨号）

当你的光猫或家庭路由器开机并向运营商发起 **PPPoE 拨号**请求时：

- 运营商机房里的宽带接入服务器（BRAS）会验证你的宽带账号和密码。
    
- 验证通过后，运营商会从它所拥有的公网 IP 池中，**动态抽取一个当前空闲的公网 IP**，下发给你的路由器（WAN 口）。
    
- **注意：** 每次重启路由器，你获取到的公网 IP 通常都会发生变化（动态 IP）。
    

#### 2. 云服务器（静态分配 / 弹性公网 IP）

对于做后端开发部署的服务器（比如阿里云 ECS）：

- 云服务商的机房已经拥有海量的公网 IP。
    
- 当你购买服务器时，云平台会利用 NAT 网关技术，将一个固定的公网 IP（通常叫 EIP，弹性公网 IP）通过后台路由表，静态绑定到你服务器的虚拟网卡上。这个 IP 只要你不释放，就永远是你的。
    

#### 3. 校园网 / 企业网（NAT 转换，主机本身没有公网 IP）

结合你上一问中查到的 `10.10.52.207` 这种私有地址，**在绝大多数情况下，你的个人电脑/手机根本拿不到公网 IP。**

- 真正拿到公网 IP 的，是你们学校或企业的**总出口路由器/防火墙**。
    
- 你的主机向公网发送数据时，数据包到达出口路由器，路由器会利用 **SNAT（源网络地址转换）** 技术，把你数据帧里的私有源 IP（`10.10.52.207`）替换成路由器所拥有的**公网 IP**，然后再发给互联网。
    
- 等外网数据返回时，路由器再根据 NAT 映射表，把公网 IP 翻译回你的私有 IP，交还给你的电脑。
    

### 💡 核心考点总结（408 网络层必考点）

- **公网 IP**：全球唯一，可以在互联网上直接被路由，必须向 ISP 申请获取。
    
- **私网 IP**：只在局域网内部唯一，**绝对不能**出现在互联网的公共路由器中。想要上网，必须在出口边界处通过 **NAT 协议** 借用出口路由器的公网 IP 来进行通信。
    
- **IPv 4 枯竭的现状**：现在很多家庭宽带拨号获取的也不再是真正的公网 IP，而是运营商内部的大型局域网 IP（比如 `100.64.x.x` 开头的 CGNAT 地址），这也意味着你家路由器外层还套着运营商的一个超级大 NAT。







**内网 IP（Private IP）**，也叫私有 IP、局域网 IP 或本地 IP，是指仅在一个封闭的局域网（LAN）内部使用的 IP 地址。

你可以把它理解为“企业内部的员工工号”**或**“学校宿舍的房间号”。这个号码只在你们公司或宿舍楼内部有效，一旦出了这个大门（进入互联网），别人是不认识这个号码的。

以下是关于内网 IP 的几个核心特点：

### 1. 为什么需要内网 IP？

在早期的互联网设计中，IPv 4 地址的总量只有约 43 亿个。随着计算机和智能设备的爆炸式增长，这些地址很快就不够分了。为了解决**IP 地址枯竭**的问题，互联网工程任务组（IETF）预留了几段特殊的 IP 地址，专门给局域网内部使用。

这样一来，全世界成千上万个家庭、学校和企业，都可以**重复使用**这几段相同的内网 IP，从而极大地节省了宝贵的公网 IP 资源。

### 2. 国际标准规定的内网 IP 范围

当你在电脑或手机上查 IP 时，只要看到是下面这三个网段开头的，那它**100% 就是内网 IP**：

- **A 类私有地址：`10.0.0.0` ～ `10.255.255.255` **
    
    - **特点：** 容量极大，通常用于大型企业内网、校园网或运营商的大型局域网。
        
- **B 类私有地址：`172.16.0.0` ～ `172.31.255.255` **
    
    - **特点：** 中等容量，常用于中型企业网络、Docker 容器的默认虚拟网段等。
        
- **C 类私有地址：`192.168.0.0` ～ `192.168.255.255` **
    
    - **特点：** 最常见的内网段。你家里的家用无线路由器，默认分配给手机和电脑的绝大多数都是 `192.168.1.x` 或 `192.168.0.x`。
        

### 3. 内网 IP 的通信规则

- **内网互通：** 在同一个局域网（比如连着同一个 Wi-Fi 的两台手机）内，设备之间可以直接通过内网 IP 互相访问、传文件。
    
- **外网隔离：** 内网 IP **绝对不允许**出现在互联网的公共路由器上。如果公网路由器收到了目标地址是内网 IP 的数据包，会直接将其丢弃。
    
- **如何上网（NAT 技术）：** 既然内网 IP 上不了网，那我们的手机是怎么看视频的呢？这就是 NAT（网络地址转换）的功劳。当你访问外网时，你的数据包会先发给家里的路由器或学校的出口网关，网关会把你的“内网 IP”抹掉，替换成网关自己的“公网 IP”发出去；等服务器把数据传回来后，网关再根据记录，把数据准确地交还给你的内网 IP。
    

### 💡 总结对比

- **内网 IP：** 可以在不同局域网中无数次重复使用，免费，无法直接连接互联网，主要用于内部设备互联。
    
- **公网 IP：** 全球唯一，不可重复，需要向运营商付费申请，可以直接在互联网上被访问。
