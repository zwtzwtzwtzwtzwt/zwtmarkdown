# 带宽的另外一种含义  
![](./assets/计算机网路的性能指标/计算机网路的性能指标-1783225796600.webp)  
**可用 Hz 越多 $\rightarrow$ 物理波形切换得越快（周期越密集） $\rightarrow$ 每秒能发送的码元就越多 $\rightarrow$ 最终能换算出的比特率（bps）就越高。** 这正是通信原理和计算机网络物理层中最核心的底层逻辑。
