# 重点分组交换  
![](./assets/电路%20报文%20分组%20交换/电路%20报文%20分组%20交换-1783214942055.webp)  

![](./assets/电路%20报文%20分组%20交换/电路%20报文%20分组%20交换-1783215073319.webp)
在分组交换（特别是基于数据报的现代 IP 网络）中，分组的重组是在目的主机（接收端）完成的。

网络中的中间节点（如路由器或交换机）**只负责独立转发各个分组，绝不参与分组的重组**。
