# 一句话理清三者关系

**IEEE 802.3 是以太网的标准；以太网是局域网（LAN）最主流的一种实现；局域网是一类网络的统称。**

> 范围大小：**局域网 > 以太网 = IEEE 802.3（标准对应的实体网络）**

## 1. 定义拆解

### 局域网（LAN，Local Area Network）

是**地理范围小**的网络的统称（概念，不是某一种协议）。 特点：覆盖房间/楼宇，低延迟，由机构/个人管理。 ✅ 例子：以太网、令牌环网、FDDI 都属于局域网。

> 局域网是“大类”，以太网是局域网里面最出名的一个成员。

### 以太网（Ethernet）

一种局域网技术，**最初由 Xerox、Intel、DEC 开发（DIX Ethernet V 2）**。 后来 IEEE 基于它制定了 **IEEE 802.3 标准**。

### IEEE 802.3

IEEE 制定的**以太网官方标准文档**，规定了物理层 + MAC 子层（数据链路层下半部分）。

> 注意：802 标准把数据链路层拆成两层：
> 
> - **MAC（介质访问控制子层）**：802.3 定义，CSMA/CD、帧格式
> - **LLC（逻辑链路控制子层）**：802.2 定义，屏蔽底层差异，向上提供服务

## 2. 以太网 V 2 和 IEEE 802.3 的帧区别（408 高频考点）

原始 DIX 以太网 V 2 帧 和 IEEE 802.3 帧**头部有一处差异**：

- 以太网 V 2：长度字段位置是**类型字段**（0 x 0800 代表 IP，0 x 0806 代表 ARP）
- IEEE 802.3：这里是**长度字段**，表示后面数据部分字节数，必须搭配 802.2 LLC 头

> 现代网卡都兼容两者，现在日常说的以太网，大多是兼容 802.3 的以太网。

## 3. 层级关系图

```
局域网(LAN)
├─ 以太网（IEEE802.3） ✅ 现在最常用
├─ 令牌环(IEEE802.5) ❌ 淘汰
└─ FDDI等 ❌ 淘汰
```

## 4. 考点必背要点

1. **IEEE 802.3 标准 = 以太网标准**，工作在**物理层 + MAC 子层**。
2. IEEE 802 系列拆分：**802.2 是 LLC 子层，802.3 是 MAC+物理层**。
3. 局域网是**网络分类（按覆盖范围）**；以太网是**局域网的具体技术**。
4. 介质访问控制：IEEE 802.3 采用 **CSMA/CD**（载波监听多点接入/碰撞检测）。
    
    > 补充：现在交换机全双工以太网，**不再需要 CSMA/CD**，标准保留，但实际不使用。
    

## 5. 易混辨析

- ❌ 错误：局域网就是以太网
- ✅ 正确：以太网属于局域网，局域网还有别的过时技术
- ❌ 错误：以太网和 IEEE 802.3 完全一模一样
- ✅ 正确：802.3 是 IEEE 标准化后的以太网，早期帧格式有区别，现代基本混用

## 6. 和前面知识点串起来（桥接/交换机）

交换机（多端口网桥）工作在**MAC 子层**，就是 IEEE 802.3 定义的这一层，基于 MAC 地址转发以太网帧。
