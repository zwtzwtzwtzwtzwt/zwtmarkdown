# VPN（虚拟专用网）核心原理（谢希仁教材版本，408 考点）

> **VPN = 隧道封装 + 加密 + 身份认证**。 本质：**在不安全的公网（互联网）上，搭建一条逻辑的、加密的虚拟通道，让异地设备像在同一个内网里通信**。 虚拟：没有单独拉一根物理专线，复用互联网线路；专用：隧道内数据加密，外人无法读取。

## 一、核心：隧道技术（封装，最关键）

> **隧道 = 把完整的原始 IP 报文，当作载荷，封装进一个新的外层 IP 包**

举例子：你在家电脑（`10.0.0.10`）访问学校机房内网服务器 `192.168.10.100`

1. **原始内层 IP 包** 源 IP：`10.0.0.10`，目的 IP：`192.168.10.100`（内网私网 IP，公网不能直接路由）
2. VPN 客户端**把整个内层 IP 包加密**，再套一层**新的外层 IP 头部** 外层源 IP：你家里电脑的公网 IP；外层目的 IP：**学校 VPN 网关的公网 IP**
3. 这个封装后的大包，在互联网上传输；公网路由器只看**外层公网 IP**转发，完全看不懂里面加密的内层报文。
4. 数据包到达学校 VPN 网关：**拆外层头、解密，取出原始内网 IP 包**，转发到学校内网的服务器。

> 通俗比喻： 原始信件（内网 IP 包）放进带锁的信封（加密），再装进一个快递盒（外层 IP 头）。快递盒写的收件地址是 VPN 网关公网地址；路上所有人只能看到快递盒地址，打不开里面带锁的信。到达网关拆开盒子、开锁，取出原始信件，投递到内网目标主机。

## 二、完整工作步骤（远程接入 VPN，学生在家连校园内网）

1. 客户端和 VPN 网关先协商：身份认证（账号密码/证书）、协商加密算法、交换密钥，**建立隧道**。
2. 电脑生成**虚拟网卡（TUN）**，分配一个校园内网网段的虚拟 IP（例如 `192.168.10.105`），修改本机路由表：访问校园内网网段的流量全部交给这个虚拟网卡。
3. 发往校园内网的 IP 包 → 交给 VPN 客户端 → 加密 + 封装外层 IP 头 → 公网传输。
4. 到达学校 VPN 网关：解封装、解密，得到原始内网 IP 包，转发进学校内网（机房网段）。
5. 回程流量反向走隧道，回到你的电脑。

## 三、两大类 VPN（考试重点）

### 1. IPsec VPN（网络层，谢希仁教材重点）

工作在**网络层**，保护整个 IP 报文。

- 隧道模式：**加密整个原始 IP 包**，用来**站点到站点**（比如学校总校 ↔ 分校两个局域网互联），两个网关之间建立隧道。
- 传输模式：只加密 IP 的数据部分，保留原始 IP 头，用于主机到主机。
    
    > 特点：对操作系统底层改动，一般需要安装客户端或者在路由器/防火墙上配置。
    

### 2. SSL/TLS VPN（传输层，现在学校远程访问最常用）

基于 HTTPS 的 SSL/TLS，工作在**应用层/传输层**。

- 很多时候**浏览器直接就能登录**，不用装专用客户端；
- 适合个人远程接入（在家访问学校机房、教务系统）；
- 两种模式：门户模式（只访问网页应用）、全隧道模式（所有内网流量都走隧道，和 IPsec 效果一样）。

## 四、和你前面校园网络知识点联动

学校 VPN 网关一般部署在**校园出口防火墙/出口路由器**上：

1. VPN 网关有**公网 IP**，暴露在互联网；
2. 隧道解密之后，原始内网数据包交给校园核心三层交换机；
3. 核心交换机根据 VLANIF 网关，把数据包转发到机房内网电脑；
4. 机房接入二层交换机只做二层 MAC 转发，**完全感知不到 VPN**。

> 👉 在家电脑通过 VPN 访问机房电脑： 家用电脑 → 互联网 → 学校 VPN 网关（解密拆包）→ 校园核心三层交换机 → 楼宇汇聚交换机 → 机房接入二层交换机 → 机房 PC

## 五、关键考点&易错点

1. VPN 隧道**不是物理线路**，是逻辑虚拟通道，复用互联网。
2. 私网 IP（机房内网 192.168.x.x）本身不能在公网路由，**靠隧道封装，把内网 IP 包藏在外层公网 IP 包里面**，实现跨公网内网互通。
3. 三层隧道（IPsec）封装**整个 IP 报文**；二层隧道（L 2 TP）封装以太网帧。
4. VPN 三大安全能力：**加密（防窃听）、完整性校验（防篡改）、身份认证（防冒充服务器）**。

## 极简一句话总结

VPN 利用**隧道封装**，把内网 IP 包加密，套上外层公网 IP 包头，在互联网传输；到达 VPN 网关后拆包解密，让异地设备如同在同一个局域网通信。

# 访问国外的  

# 重要前置说明

**在我国，未经批准私自搭建、使用 VPN 访问境外互联网属于违法行为。** 下面仅从**计算机网络原理角度**讲解 VPN 技术本身的工作机制，**不代表支持、鼓励翻墙行为**。

> 技术上：原理和校园远程 VPN 是同一套 VPN 隧道技术，区别只在于 VPN 网关的位置在境外。

## 原理（技术层面）

VPN 本质依旧是**隧道封装+加密**。

1. 你的电脑发出访问国外网站的 IP 包，目的 IP 是境外服务器 IP。
2. VPN 客户端捕获这个数据包，**加密整个原始 IP 报文**，再在外层封装一个新 IP 头：
    - 外层源 IP：你本机的国内公网 IP
    - 外层目的 IP：**境外 VPN 网关的公网 IP**
3. 这个封装后的数据包，走国内互联网线路，穿过国内骨干网、国际海底光缆，送到境外 VPN 网关。
4. 境外 VPN 网关：拆掉外层 IP 头、解密，取出里面原始的 IP 包，**在境外公网把包转发给目标国外网站**。
5. 国外网站返回的响应包，发给境外 VPN 网关；网关再次加密封装，原路通过隧道传回你的电脑，解包展示网页。

### 路由变化（关键）

开启 VPN 后，操作系统修改本机路由表：访问境外网段的流量，全部交给 VPN 虚拟网卡，走隧道发给境外 VPN 网关，而不是直接由国内运营商网关转发。

## 和校园 VPN 的对比

|类型|VPN 网关位置|用途|
|---|---|---|
|校园合法 VPN|学校出口防火墙（国内）|在家访问**校内内网资源**（机房、教务系统）|
|非法翻墙 VPN|境外服务器（国外）|绕过国内网络管控访问境外互联网（违法）|

## 技术易错点

1. 不是“把 IP 改成国外 IP”这么简单：**外层数据包是正常公网 IP 在互联网传输，内层才是你真正的业务流量**。国外网站看到的源 IP，是**境外 VPN 网关的 IP**，而不是你本机 IP。
2. 流量仍然会经过国内运营商网络：封装后的数据包依然要先走国内互联网，再通过国际出口光缆出海，**不是直接跳过国内网络**。
3. 技术上常见类型：IPsec、SSL VPN、WireGuard 等，只是隧道协议不同，封装思想一致。

## 法律提醒

根据《中华人民共和国网络安全法》，个人和单位**必须使用经过国家有关部门批准的专用 VPN**，仅用于企业跨境办公等合规业务。私自使用未备案 VPN 访问境外网站，属于违规行为，会承担相应法律责任。
