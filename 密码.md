使用 Docker Compose 来统一管理这些高频中间件是非常棒的做法，一键启动，互不干扰，而且它们之间可以通过内部网络直接相互通信。

下面为你量身定制的 `docker-compose.yml` 文件。我已经为你配置好了持久化目录（防止数据丢失）、时区（Asia/Shanghai），并将你要求的密码 `zxcvbnm` 应用到了对应的服务中。

### 1. 创建文件

在你的服务器或本地电脑上新建一个空文件夹，在里面创建一个名为 `docker-compose.yml` 的文件，将以下内容复制进去：

YAML

``` yaml
version: "3.8"

  

# 定义一个通用的日志配置模板

x-logging: &default-logging

  driver: "json-file"

  options:

    max-size: "10m"

    max-file: "3"

  

services:

  # 1. MySQL 8.0 服务

  mysql:

    image: mysql:8.0

    container_name: dev-mysql

    logging: *default-logging

    environment:

      MYSQL_ROOT_PASSWORD: ${DEV_PASSWORD} # <-- 动态引入变量

      TZ: Asia/Shanghai

    ports:

      - "3307:3306"

    volumes:

      - ./data/mysql:/var/lib/mysql

      - ./mysql-init:/docker-entrypoint-initdb.d

    networks:

      - dev_network

    # --- 健康检查命令也同步支持变量密码 ---

    healthcheck:

      test:

        [

          "CMD",

          "mysqladmin",

          "ping",

          "-h",

          "localhost",

          "-u",

          "root",

          "-p${DEV_PASSWORD}",

        ]

      interval: 5s

      timeout: 5s

      retries: 5

  

  # 2. Redis 服务

  redis:

    image: redis:7-alpine

    container_name: dev-redis

    logging: *default-logging

    command: redis-server --requirepass ${DEV_PASSWORD} # <-- 动态引入变量

    ports:

      - "6379:6379"

    volumes:

      - ./data/redis:/data

    networks:

      - dev_network

  

  # 3. RabbitMQ 服务

  rabbitmq:

    image: rabbitmq:3-management

    container_name: dev-rabbitmq

    logging: *default-logging

    environment:

      RABBITMQ_DEFAULT_USER: admin

      RABBITMQ_DEFAULT_PASS: ${DEV_PASSWORD} # <-- 动态引入变量

      TZ: Asia/Shanghai

    ports:

      - "5672:5672"

      - "15672:15672"

    volumes:

      - ./data/rabbitmq:/var/lib/rabbitmq

    networks:

      - dev_network

  

  # 4. Nacos 服务

  nacos:

    image: nacos/nacos-server:v2.3.2

    container_name: dev-nacos

    logging: *default-logging

    environment:

      MODE: standalone

      TZ: Asia/Shanghai

      JVM_XMS: 256m

      JVM_XMX: 256m

      NACOS_AUTH_ENABLE: "true"

      NACOS_AUTH_TOKEN: ${NACOS_TOKEN} # <-- 动态引入安全密钥

      NACOS_AUTH_IDENTITY_KEY: "nacos"

      NACOS_AUTH_IDENTITY_VALUE: "nacos"

    ports:

      - "8848:8848"

      - "9848:9848"

      - "9849:9849"

    volumes:

      - ./data/nacos:/home/nacos/data

    networks:

      - dev_network

  

  # 5. XXL-JOB 任务调度中心

  xxl-job-admin:

    image: xuxueli/xxl-job-admin:2.4.1

    container_name: dev-xxl-job

    logging: *default-logging

    ports:

      - "9090:8080"

    environment:

      # --- 多行字符串中同样完美支持变量解析 ---

      PARAMS: "

        --spring.datasource.url=jdbc:mysql://dev-mysql:3306/xxl_job?useUnicode=true&characterEncoding=UTF-8&autoReconnect=true&serverTimezone=Asia/Shanghai

        --spring.datasource.username=root

        --spring.datasource.password=${DEV_PASSWORD}

        "

    networks:

      - dev_network

    depends_on:

      mysql:

        condition: service_healthy

  

networks:

  dev_network:

    driver: bridge
```

.env 文件

```
# ==========================================
# 微服务基础环境统一变量配置
# ==========================================

# 统一通用密码 (应用于 MySQL、Redis、RabbitMQ、XXL-JOB)
DEV_PASSWORD=zxcvbnm

# Nacos 核心安全 Token (必须大于 32 位字符串)
NACOS_TOKEN=SecretKey012345678901234567890123456789012345678901234567890123456789
```

### 💡 核心配置串（开发速查参考）

#### 1. 如果你在 Windows 本地用 IDEA 跑 Spring Boot 代码：

- **MySQL 驱动连接串**：
    
    Properties
    
    ```
    spring.datasource.url=jdbc:mysql://localhost:3307/你的数据库名?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    spring.datasource.password=【你在.env里设定的密码】
    ```
    
- **Nacos 注册/配置中心地址**：`localhost:8848`
    

#### 2. 如果你未来把 Spring Boot 代码也打包成 Docker 镜像，并加入同一个 `dev_network`：

- **MySQL 驱动连接串**（注意端口和 IP 的改变）：
    
    Properties
    
    ```
    spring.datasource.url=jdbc:mysql://dev-mysql:3306/你的数据库名?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    ```
    
- **Nacos 注册/配置中心地址**：`dev-nacos:8848`
