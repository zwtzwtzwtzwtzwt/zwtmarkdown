# 日语人称代词（N 5～N 4，分礼貌/普通/粗鲁）

> 重点提醒：日语**能不说人称就尽量不说**，靠语境省略，频繁说「あなた」会显得生硬甚至失礼。

## 第一人称（我）

|日文|读音|使用场景|备注|
|---|---|---|---|
|私|わたし|通用、礼貌（男女都能用）|最安全，课堂、陌生人、正式场合首选|
|私|わたくし|非常郑重、商务/正式|偏书面，女性用得多，男性正式场合也可用|
|僕|ぼく|男生常用、偏年轻|学生、少年；对长辈、上司不能用|
|俺|おれ|男性口语、随意|朋友同辈之间，**对长辈绝对禁用**|
|あたし|あたし|女生口语、可爱随意|非正式，不适合正式场合|

## 第二人称（你）

|日文|读音|使用场景|备注|
|---|---|---|---|
|あなた|あなた|通用礼貌；妻子称呼丈夫|⚠️ 尽量少用！当面称呼长辈、上级不要用|
|君|きみ|上级对下级、长辈对晚辈、同辈好友|男生用得多；不要对上司说「きみ」|
|お前|おまえ|很随意、粗鲁|熟人、哥们之间，容易冒犯，慎用|
|あんた|あんた|口语简略版「あなた」|偏随意，有点不客气|

✅ 更推荐的替代方式（日本人真实用法）： 直接叫 **～さん / ～くん / ～ちゃん**，比あなた自然得多 例：田中さんはどこへ行きますか。田中先生去哪里？

## 第三人称（他 / 她）

|日文|读音|中文|备注|
|---|---|---|---|
|彼|かれ|他；男朋友|かれ＝他 / 男友|
|彼女|かのじょ|她；女朋友|かのじょ＝她 / 女友|
|あの人|あのひと|那个人（礼貌）|最稳妥，不分男女，正式场合推荐|
|あの方|あのかた|那位（敬语）|对长辈、上位者，非常礼貌|
|この人|このひと|这个人|近的人|
|その人|そのひと|那个人（离听话人近）||

## 复数（们）

后缀：**～たち / ～ら**

- 私たち（わたしたち）我们（通用）
- 僕たち（ぼくたち）我们（男生）
- 俺たち（おれたち）我们（男生随意）
- 彼ら（かれら）他们（可男女混合）
- 彼女たち（かのじょたち）她们
- あの人たち（あのひとたち）那些人

> 注意：「きみたち」你们；「おまえたち」你们（粗鲁）

## 易错重点总结

1. 日语**没有固定的“你”**，优先称呼姓氏+さん，而不是あなた
2. かれ、かのじょ 有「男女朋友」的含义，单纯指人优先用 あの人
3. 人称自带尊卑，对老师、上司：不用僕、俺、きみ、お前
4. 句子里经常省略： （私は）りんごを食べます。我吃苹果。 （あなたは）何をしますか。你在做什么？

## 补充：特殊称呼

- 自分（じぶん）：自己；部分男生用作第一人称（偏体育/军队风）
- わし：老爷爷、年长男性口语「我」
