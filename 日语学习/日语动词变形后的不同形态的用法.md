# 日语动词六大形态用法笔记

> 整理日期：2026-11-23
> 关联：[[日语动词变形规则]]（动词分类、各类变形表、助词与助动词）
> 本笔记只讲**用法场景**，变形细节查 [[日语动词变形规则]]；两份配合看。

---

## 0. 总览：六个形态各管什么

| 形态 | 语法名 | 核心功能 | 例（書く） |
| --- | --- | --- | --- |
| ます | 敬体（丁寧形） | 决定**对谁说话**（礼貌度） | 書きます |
| て | 连用形音便 | 把两个小句**接起来** | 書いて |
| た | 完成形 | 表示**完了·确认**（不等于过去） | 書いた |
| ない | 否定形（未然形＋ない） | 表示**否定** | 書かない |
| う・よう | 意志形 | 表示**意志·劝诱** | 書こう |
| ば | 假定形 | 表示**条件** | 書けば |

一句话记：**ます 管礼貌，て 管接续，た 管完了，ない 管否定，う・よう 管意志，ば 管条件。**

---

## 1. ます形（敬体）

### 变形
- 五段：词尾变 i 段 ＋ ます（書く→書きます）
- 一段：去る ＋ ます（食べる→食べます）
- する→します、来る→きます

### 四种形式
| 现在肯定 | 现在否定 | 过去肯定 | 过去否定 |
| --- | --- | --- | --- |
| ます | ません | ました | ませんでした |

### 使用场景

**① 礼貌体（最核心用途）** 对上级、客户、陌生人、不熟的人。

- 部長、少しお時間をいただけますか。（部长，能占用您一点时间吗？）
- すみません、駅はどこにありますか。（不好意思，车站在哪里？）
- 昨日は会議に出席しませんでした。（昨天没有出席会议。）

**② 习惯、反复动作** 常与 毎日／毎朝／いつも／よく／週に〜回 搭配。

- 毎朝七時に起きます。（每天早上七点起床。）
- 父は毎日新聞を読みます。（父亲每天看报。）
- 週に二回ジムへ行きます。（一周去两次健身房。）

**③ 将来的动作、预定、意志**

- 来週、大阪へ出張します。（下周去大阪出差。）
- 私がやります。（我来做。）
- 会議は三時に始まります。（会议三点开始。）

**④ 一般真理、客观陈述**（解说、说明书、教材、试题）

- 地球は太陽の周りを回ります。（地球围绕太阳转。）
- 水は百 度で沸騰します。（水在100度沸腾。）
- このボタンを押すと、ドアが開きます。（按这个按钮，门就会开。）

**⑤ 邀请、劝诱**（`ませんか` 比 `ましょう` 更委婉）

- 一緒に昼ご飯を食べませんか。（要不要一起吃午饭？）—— 不是"你不吃吗"
- そろそろ始めましょう。（差不多开始吧。）
- お茶でも飲みませんか。（要不要喝杯茶什么的？）

### 易错点
- **ます ≠ 敬语**：只是礼貌形。尊敬/自谦另加：先生が**おっしゃいます**、私が**申します**。
- **ます形不能修饰名词**：❌ 昨日買いました本 → ✅ 昨日買った本。
- **ます后不能再接 て／た**：❌ 食べますて → ✅ 食べて。
- ます的**词干**可接 ながら／たい／方／始める（食べ+ながら），但那已经不是「ます」，别再补一个 ます（❌ 食べますたい）。

## 2. て形（接续形）

> 本质：て形是「连接形」，本身不带时态、不带礼貌，只把两个小句缝起来。缝的关系（先后／原因／手段／状态）由上下文判断。

### 变形（音便）
| 词尾 | て形 | 例 |
| --- | --- | --- |
| う・つ・る | って | 買う→買って、待つ→待って、帰る→帰って |
| む・ぶ・ぬ | んで | 飲む→飲んで、遊ぶ→遊んで、死ぬ→死んで |
| く | いて | 書く→書いて |
| ぐ | いで | 泳ぐ→泳いで |
| す | して | 話す→話して |
| 一段 | 去る＋て | 食べる→食べて |
| する・来る | して・きて | する→して、来る→きて |
| **例外** | **行って** | 行く→行って（不是"行いて"） |

### 三层用途

**A. 连接两个动作**

- **相继发生**：朝起きて、顔を洗って、朝ご飯を食べます。（起床、洗脸、吃早饭）
- **原因·理由**：風邪をひいて、会社を休みました。（因为感冒没上班）
　> ⚠️ 原因用法的后半句**不能是意志、命令、劝诱**：❌ 風邪をひいて、休みましょう
- **手段·方法**：歩いて駅へ行きます。／電車に乗って会社へ行きます。
- **附带状态·方式**：眼鏡をかけて本を読みます。（戴着眼镜看书）／座って話しましょう。


 **B. 构成固定句型**

|句型|意思|例|翻译|
|---|---|---|---|
|てください|请求|ちょっと待ってください。|请稍等一下。|
|てもいい|许可|ここに座ってもいいですか。|可以坐在这里吗？|
|てはいけない|禁止|ここで写真を撮ってはいけません。|不可以在这里拍照。|
|てから|之后|手を洗ってから食べます。|洗完手之后吃饭。|
|ても|即使|雨が降っても行きます。|即使下雨也要去。|
|ている|进行 / 状态|今、本を読んでいます。  <br>東京に住んでいます。|现在正在看书。  <br>住在东京。|

---

**** C. 接补助动词

|补助动词|意思|例|翻译|
|---|---|---|---|
|てしまう|完成 / 遗憾|ケーキを全部食べてしまいました。  <br>財布を落としてしまった。|把蛋糕全部吃完了。  <br>钱包弄丢了。|
|ておく|预先准备|ビールを冷やしておきます。|提前把啤酒冰镇好。|
|てみる|试着做|この服を着てみてもいいですか。|可以试穿这件衣服吗？|
|てある|人为结果的存续|窓が開けてあります。|窗户（人为）开着。|
|てくる / ていく|方向·变化|持ってきます。  <br>だんだん暖かくなってきました。|拿过来。  <br>渐渐变暖了。|

> 小提示：这一组全部都是**动词て形**后面接续的，是 N 5 核心语法。 要不要我给你出几道て形填空小题巩固一下？
### 易错点
- **て形没有时态**，时态由最后那个动词决定。
- **ています 有两个意思**：继续动词＝正在进行（読んでいます）；瞬间动词＝结果状态（結婚しています、知っています、死んでいます）。
- **帰る／食べる／行く** 最容易混：帰って／食べて／行って。
- 口语里て形能单独收尾表轻请求：「ちょっと待って。」

## 3. た形（完成形）

### 变形
**て→た、で→だ**，其余音便规则与て形完全一致。
買って→買った／飲んで→飲んだ／書いて→書いた／話して→話した／食べて→食べた／来て→きた

### 核心认识：た = 完了，不是"过去"
| 时间落点 | 例 | 说明 |
| --- | --- | --- |
| 过去的事实 | 昨日、雨が降った。 | 动作在过去发生 |
| 现在刚刚成立 | あ、バスが来た。 | 瞬间动词＝已达成 |
| 将来的完成 | 着いたら電話する。 | 完成之后才做 |

**① 过去的事实**

- 子供の頃、ここに大きな川があった。（小时候这里有條大河。）
- 会議は三時に終わった。（会议三点结束了。）

**② 现在刚刚成立**（最能说明た≠过去）

- あ、バスが来た。（啊，车来了！）
- わかった。（明白了。）
- あった！（找到了！）
- 昼ご飯、食べた？（你吃过饭了吗？）—— 问完成，不是问过去

**③ 将来的完成**（从句里的た）

- 明日、駅に着いたら電話します。（明天到车站给你打电话。）
- 宿題が終わったら、ゲームをしてもいいよ。
- 食事が済んだあとで、話しましょう。

**④ た形修饰名词**（定语从句，必须用普通形）

- 昨日買った本はとても面白い。（昨天买的那本书很有意思。）
- 壊れた時計を捨てた。
- 眼鏡をかけた人が先生です。

**⑤ 常用句型**

| 句型 | 意思 | 例 |
| --- | --- | --- |
| たことがある | 经历 | 富士山に登ったことがある。 |
| たほうがいい | 建议 | 早く寝たほうがいいですよ。 |
| たり〜たりする | 列举 | 休みの日は本を読んだり、散歩したりします。 |
| たばかり | 刚（主观） | 今、帰ってきたばかりです。 |
| たら | 条件／做了之后发现 | 時間があったら、遊びに来てください。 |
| たところ | 刚刚（客观） | 今、駅に着いたところです。 |
| たものだ | 回忆过去习惯 | 子供の頃、よくこの公園で遊んだものだ。 |
| 〜ば／たら よかった | 后悔·反事实 | もっと早く来ればよかった。 |

口语感叹：やった！（太好了）／しまった！（糟了）／よし、決めた！

### 易错点
- **た≠过去**：瞬间动词＋た＝已达成；继续动词＋た＝过去的一段时间。
- **修饰名词绝不能用ます**：❌ 昨日買いました本 → ✅ 昨日買った本。
- **过去礼貌形是 ました**，不是"たです"。
- 形容词/名词的过去：い形 高かった；な形·名词 静かだった／学生だった。
- **た ≠ ていた**：読んだ（读了）／読んでいた（当时正在读）。

## 4. ない形（否定形）

### 变形
| 类别 | 规则 | 例 |
| --- | --- | --- |
| 五段 | a段＋ない | 書く→書かない、飲む→飲まない、話す→話さない |
| 五段（う结尾） | う→わ＋ない | 買う→買わない、会う→会わない |
| 一段 | 去る＋ない | 食べる→食べない、見る→見ない |
| する・来る | しない・こない | する→しない、来る→こない |
| **例外** | **ある→ない** | お金がない、時間がない |

### 关键认识
`ない` 本身按**い形容词**活用（ない→なかった→なくて→ないです），所以能修饰名词、能接です。它只管否定，不管时间。

### 使用场景

**① 普通体的否定陈述**（朋友、家人、独白、日记、SNS）

- 今日は行かない。（今天不去。）
- わたしはお酒を飲まない。（我不喝酒。）
- 教室に誰もいない。（教室里没有人。）
- 昨日は雨が降らなかった。（昨天没下雨。）

**② 否定修饰名词**（ます做不到的事）

- 分からない問題がある。（有不懂的问题。）
- 行かない人は手を挙げてください。（不去的人请举手。）
- 時間がない日は、コンビニで済ませる。（没时间的日子就在便利店解决。）

**③ 否定疑问表邀请·确认**（口语高频）

- 一緒に行かない？（要不要一起去？）—— 不是"你不去吗"
- ちょっと寒くない？（你不觉得有点冷吗？）
- これ、おかしくない？（这不奇怪吗？）

**④ 常用句型**

| 句型       | 意思        | 例                |
| -------- | --------- | ---------------- |
| ないでください  | 请不要       | ここに入らないでください。    |
| なければならない | 必须        | 明日までに出さなければならない。 |
| なくてもいい   | 不必        | 今日は来なくてもいいです。    |
| ないほうがいい  | 最好不要      | 無理をしないほうがいいですよ。  |
| ないで      | 不做A就做B    | 朝ご飯を食べないで学校へ行った。 |
| ないように    | 为了不…      | 忘れないようにメモしておきます。 |
| ないうちに    | 趁着还没…     | 暗くならないうちに帰ろう。    |
| ないことにする  | 决定不…      | 今年は海外に行かないことにした。 |
| ないわけではない | 双重否定·部分肯定 | 行きたくないわけではない。    |
| ずに       | ないで 的书面形  | 何も言わずに帰った。       |

### ないで 与 なくて（高频考点）
- **ないで**：方式、附带状态，同一主体"不做A而做B"。
　`朝ご飯を食べないで出かけた。`（没吃早饭就出门了。）
- **なくて**：原因、并列。
　`雨が降らなくて、よかった。`（没下雨，太好了。）
　`この店は安くなくて、おいしくない。`（又贵又不好吃。）

> 判断法：后半句是"主语接下来做的动作"→ないで；后半句是"由此产生的结果或评价"→なくて。

### 易错点
- **ある→ない**，没有"あらない"；但 いる→いない 正常。
- ない修饰名词**不加の**：❌ 行かないの人 → ✅ 行かない人。
- 过去否定是 **なかった／ませんでした**，没有"ないでした"。
- 形容词不接ない：い形 高くない；な形·名词 ではない／じゃない。
- ないで 与 なくて 不能互换。

## 5. う・よう（意志形 / 意向形）

> 定位：`ましょう` 的**普通体**，语气相同、礼貌度不同。

### 变形
| 类别        | 规则      | 例                    |
| --------- | ------- | -------------------- |
| 五段        | o段＋う    | 書く→書こう、飲む→飲もう、話す→話そう |
| 五段（う・つ・る） |         | 買う→買おう、待つ→待とう、帰る→帰ろう |
| 一段        | ＋よう     | 食べる→食べよう、見る→見よう      |
| する・来る     | しよう・こよう | する→しよう、来る→こよう        |

> 底层规则是「a段未然形＋う」，发音合并成 o 段长音（書か＋う→書こう）。
> 判断词类仍关键：帰る・入る・走る・知る 虽是「-る」结尾但是五段 → 帰ろう、入ろう、走ろう。

### 三类用途

**① 自己的意志·决心**（独白、宣言、主动承担；**只限第一人称**）

- 明日から早く起きよう。（从明天开始早起吧。）
- よし、やろう。（好，干吧。）
- 私が説明しよう。（我来解释吧。）
- 二度と行くまい。（再也不去了。）—— まい 是书面否定意志

**② 邀请对方·提议**（对朋友、同事、家人）

- そろそろ行こう。（差不多该走了。）
- 一緒に昼ご飯を食べよう。（一起吃午饭吧。）
- 疲れたね。少し休もうか。（累了吧，歇会儿？）
- 对上级：そろそろ行きましょう。

**③ 派生句型**

| 句型 | 意思 | 例 |
| --- | --- | --- |
| ようとする | 试图／正要 | ドアを開けようとしたが、開かなかった。 |
| ようとしている | 正在试图／即将 | 日が沈もうとしている。 |
| ようと思う／考えている | 打算 | 来年、日本へ行こうと思っています。 |
| ようとしない | 不肯（第三人称） | 彼はなかなか話をしようとしない。 |
| ようが／ようと | 无论…都 | 雨が降ろうが、試合は行う。 |
| ようか〜まいか | 犹豫不决 | 行こうか行くまいか、迷っている。 |
| ようにも〜ない | 想…也做不到 | 動こうにも動けない。 |
| ようではないか | 号召（书面/演讲） | さあ、新しい一歩を踏み出そうではないか。 |

### 易错点
- **五段是 o段＋う**：❌ 書かう、❌ 買あう → ✅ 書こう、買おう。
- **一段/五段别混**：帰ろう / 食べよう。
- **意志形只用于第一人称**：❌ 彼は行こう → ✅ 彼は行こうとしている／行くつもりだ。
- 对上级不用 う・よう，用 ましょう。
- **ようとする（试图做一次）／ようとしている（正在试图或即将）**。

## 6. ば形（假定形）

> 语感：偏逻辑、"只要满足条件，后面自然成立"。比 たら 更书面、更讲道理。

### 变形
| 类别 | 规则 | 例 |
| --- | --- | --- |
| 五段 | e段＋ば | 書く→書けば、飲む→飲めば、話す→話せば |
| 五段（う・つ・る） | | 買う→買えば、待つ→待てば、帰る→帰れば |
| 一段 | ＋れば | 食べる→食べれば、見る→見れば |
| する・来る | すれば・くれば | する→すれば、来る→くれば |
| 否定 | ない→なければ | 行かない→行かなければ |
| い形容词 | い→ければ | 高い→高ければ |
| な形容词·名词 | なら | 静かなら、学生なら（不加ば） |

### 四类场景

**① 假定条件**

- お金があれば、買います。（有钱就买。）
- 明日、雨が降れば、試合は中止です。（明天下雨比赛就取消。）
- 分からなければ、聞いてください。（不懂就问。）—— 前件是状态，后件可接请求

**② 恒常条件·反复·必然**（自然规律、机械操作、习惯）

- 春になれば、桜が咲く。（一到春天樱花就开。）
- このボタンを押せば、お釣りが出ます。（按这个按钮就出零钱。）
- 雨が降れば、道が濡れる。

**③ 〜ば〜ほど**：越…越…

- 練習すればするほど、上手になる。（越练越熟练。）
- 考えれば考えるほど、分からなくなる。（越想越不明白。）
- 高ければ高いほど、いいとは限らない。（越贵不一定越好。）

**④ 反事实·遗憾**：〜ばよかった

- もっと早く来ればよかった。（早点来就好了。）
- お金があれば、買ったのに。（有钱的话就买了。）

**⑤ 高频固定搭配**

- 〜なければならない：必须（ば 最日常的用法）
- 〜ばいい：…就行／该怎么办。`どうすればいいですか。`
- 〜も〜ば〜も：既…又…。`彼は歌も歌えば、ダンスも踊る。`
- 〜ばこそ：正因为…才…。`愛すればこそ、厳しく言う。`

### ば / と / たら / なら 对比
| 形式 | 语感 | 后件限制 | 例 |
| --- | --- | --- | --- |
| と | 必然·自动（规律、机械） | 不能接意志·命令 | ボタンを押すと、ドアが開く。 |
| たら | 最自由，兼表"之后""发现" | 几乎不限 | 駅に着いたら電話します。／家に帰ったら、誰もいなかった。 |
| なら | 承接对方话题提条件 | 较自由 | 安いなら買います。／日本へ行くなら、春がいい。 |
| ば | 逻辑、书面、恒常 | 一般不能接命令·依赖·劝诱 | 春になれば桜が咲く。 |

### 易错点
- **五段是 e段＋ば**：❌ 書かば → ✅ 書けば。
- **否定是 〜なければ**，不是"なくば"（文语）。
- **い形容词不加ば**：❌ 高いば → ✅ 高ければ；な形·名词用 なら。
- **后件限制**：❌ 駅に着けば、電話してください → ✅ 駅に着いたら。前件是状态性表达时可放宽。
- **ば 不能表示"发现"**：❌ 家に帰れば、誰もいなかった → ✅ 帰ったら。

## 7. 骨架：五段动词的四个接续底座

所有形态其实只是"换一个段 ＋ 接一个词"。记住这个骨架，变形就不用背表。

| 底座     | 语法名     | 接什么           | 例（書く）       |
| ------ | ------- | ------------- | ----------- |
| **a段** | 未然形     | ない・れる・せる      | 書か＋ない       |
| **i段** | 连用形     | ます・たい・ながら・なさい | 書き＋ます       |
| **e段** | 假定形／命令形 | ば・命令・（可能）     | 書け＋ば／書け／書ける |
| **o段** | 意志      | う             | 書こ＋う        |
| 连用形＋て  | 音便      | て／た           | 書い＋て／書い＋た   |

三个值得记的"同源"关系：
1. **て 与 た**：て→た、で→だ，同一套音便。
2. **ない 与 う**：都出自未然形，一个接 a 段（書かない），一个接 o 段（書こう）。
3. **ば 与 命令形、可能形**：五段的 e 段同时养出 書け（命令）、書けば（条件）、書ける（可能）。

## 8. 易错点总清单

1. ます形不能修饰名词 → 用 た形／辞书形／ない形。
2. ます后不接 て／た → 用 て形。
3. て形没有时态，时态在句尾。
4. ています 有"进行"和"结果状态"两义，看动词性质。
5. た ≠ 过去：瞬间动词＋た＝已达成（来た、わかった）。
6. 过去礼貌形是 ました，不是"たです"。
7. ある→ない，不是"あらない"。
8. ない修饰名词不加 の。
9. ないで（方式）≠ なくて（原因）。
10. 意志形只用于第一人称；第三人称用 ようとしている／つもりだ。
11. ば 后件一般不接命令·依赖·劝诱；拿不准就用 たら。
12. 形容词不要硬套动词规则：い形 くない／かった／ければ；な形 じゃない／だった／なら。

## 9. 建议的学习顺序

1. 先吃透**动词分类**（五段／一段／する・来る）——所有变形的前提。→ [[日语动词变形规则]]
2. **ます形**：先建立"礼貌层级"的概念。
3. **て形**：从句子的"单句"跨到"复句"，关键一步。
4. **た形**：理解"完了 ≠ 过去"。
5. **ない形**：否定，同时接触未然形。
6. **う・よう**：未然形的第二副面孔。
7. **ば形**：条件句；此时要把 と／たら／なら 一起对比着学。
8. 之后再进 **可能形、被动态、使役态**——它们都长在未然形和 e 段上，衔接着最省力。
