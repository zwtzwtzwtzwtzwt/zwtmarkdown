# 日语名词与形容词变化规则

> [!tip] 一句话抓住本质
> 名词和な形容词共用一套，变的是词尾的断定助动词 **だ／です**；い形容词单独一套，变的是 **い 本身**。
> 口诀：**だ型变尾巴，い型砍尾巴。**

以下是截图里这张日语活用表的完整内容（按原图四块分区整理，敬体形／簡体形两列对照）：

## 1. 名詞（名词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 学生です | 学生だ |
| 過去 | 学生でした | 学生だった |
| 否定 | 学生ではありません<br>じゃありません | 学生ではない<br>じゃない |
| 過去否定 | 学生ではありませんでした<br>じゃありませんでした | 学生ではなかった<br>じゃなかった |

## 2. 二類形容詞（な形容词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 静かです | 静かだ |
| 過去 | 静かでした | 静かだった |
| 否定 | 静かではありません<br>じゃありません | 静かではない<br>じゃない |
| 過去否定 | 静かではありませんでした<br>じゃありませんでした | 静かではなかった<br>じゃなかった |

## 3. 一類形容詞（い形容词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 暑いです | 暑い |
| 過去 | 暑かったです | 暑かった |
| 否定 | 暑くないです<br>くありません | 暑くない |
| 過去否定 | 暑くなかったです<br>くありませんでした | 暑くなかった |

## 4. 動詞（动词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 行きます | 行く |
| 過去 | 行きました | 行った |
| 否定 | 行きません | 行かない |
| 過去否定 | 行きませんでした | 行かなかった |

补充两点原图里的规律（方便记忆）：
- **名词、な形容词**：否定和过去否定都用「では／じゃ」起头，简体去「です」后接「ない／なかった」。
- **い形容词、动词**：变形发生在词尾本身（暑い→暑くない、行く→行かない），敬体只是再挂「です／ます」。

## 一、两套体系：だ型 vs い型

| 体系 | 成员 | 变化位置 |
|---|---|---|
| **だ型（名词式）** | 名词、な形容词 | 词干完全不动，只换だ／です |
| **い型（形容词式）** | い形容词 | 砍掉「い」，接新词尾 |

> [!note] 为什么名词和な形容词是一伙的
> 「な」其实是「だ」的**连体形**：静かだ（结句）→ 静かな人（修饰名词）。
> 名词修饰名词则用「の」：学生の田中さん。
> 两者都能接だ／です、都能用「で」连接，所以变化规则完全重合。

---

## 二、だ型：名词和な形容词

核心是断定助动词 **だ**，它自己会变，词干不参与。

- だ → **だった**（过去）
- だ → **で＋は＋ない**（否定，は表强调；口语用じゃ）
- だった → **で＋は＋なかった**（过去否定）

| 形式 | 简体 | 敬体 |
|---|---|---|
| 现在肯定 | だ | です |
| 过去肯定 | だった | でした |
| 现在否定 | ではない・じゃない | ではありません・じゃありません |
| 过去否定 | ではなかった・じゃなかった | ではありませんでした・じゃありませんでした |

例句：

- 学生だ → 学生だった → 学生ではない → 学生ではなかった
- 静かです → 静かでした → 静かではありません → 静かではありませんでした

> [!warning] 语序陷阱
> **否定先变「で」，时态挂在最后**。过去否定永远是「で（は）＋なかった」，
> 不是「なかっただ」「でしたない」。

---

## 三、い型：い形容词

「い」是词的一部分，不是独立助动词，所以必须先切掉，再接词尾。

| 形式 | 变化 | 例（暑い） | 敬体 |
|---|---|---|---|
| 现在肯定 | 原形 | 暑い | 暑いです |
| 过去肯定 | い → **かっ＋た** | 暑かった | 暑かったです |
| 现在否定 | い → **く＋ない** | 暑くない | 暑くないです・暑くありません |
| 过去否定 | い → **く＋なかった** | 暑くなかった | 暑くなかったです・暑くありませんでした |

拆解示例：

```
暑い   = 暑 + い          ← い 是要切掉的部分
暑くない = 暑 + く + ない   ← 否定用「く」
暑かった = 暑 + かっ + た   ← 过去用「かっ」
```

实际上只要记两个词尾：**く（否定）、かっ（过去）**。かっ 就是 く 的促音化变体，「い→く」是同一件事的两种落地方式。

补充：「く」同时也是い形容词的**连用形（副词用法）**——暑くなる、早く起きる。

---

## 四、例外与易错点

1. **いい → 全部按「よい」变**：よくない、よかった、よくなかった。不能说「いくない」「いかった」。
2. **长得像い形容词的な形容词**：きれい、嫌い、有名。判断标准是能否接「な」——きれいな人 ✓ / 暑いな人 ✗。
3. **い形容词不接「だ」**：暑いだ ✗。简体以「い」结句，敬体才加「です」。
4. **特殊い形容词**：ない → なかった（否定助动词也走同一套）；多い／少ない 修饰名词用「多くの人」。
5. **敬体否定两个版本别混**：名词・な形容词用「ではありません／じゃありません」，い形容词用「くないです／くありません」，前者更正式。
6. **现在形也表将来**：日语「非过去」不等于「现在进行」，明天的事也用现在形。

## 五、速查对照

| | 词干 | 现在 | 过去 | 否定 | 过去否定 |
|---|---|---|---|---|---|
| 名词・な形容词 | 不动 | だ／です | だった／でした | で（は）ない | で（は）なかった |
| い形容词 | 砍掉い | い／いです | かっ＋た | く＋ない | く＋なかった |

## 六、自测 6 题（填空）

1. 昨天不是休息日。（敬体）→ 昨日は休み（　　　）。
2. 小时候这里很安静。（简体）→ 子供の頃、ここは静か（　　　）。
3. 那家店的拉面不好吃。（简体）→ あの店のラーメンはおいしく（　　　）。
4. 昨天不热。（敬体）→ 昨日は暑く（　　　）。
5. 这个房间不干净。（简体）→ この部屋はきれい（　　　）。
6. 天气不好。（过去・简体，いい）→ 天気が（　　　）。

<details>
<summary>答案</summary>

1. ではありませんでした（或 じゃありませんでした）
2. だった
3. なかった
4. ありませんでした（或 なかったです）
5. ではない（じゃない）——きれい是な形容词
6. よかった（いい→よい）

</details>
