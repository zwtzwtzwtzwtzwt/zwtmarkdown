以下是截图里这张日语活用表的完整内容（按原图四块分区整理，敬体形／簡体形两列对照）：

## 1. 名詞（名词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 学生です | 学生だ |
| 過去 | 学生でした | 学生だった |
| 否定 | 学生ではありません<br>じゃありません | 学生ではない<br>じゃない |
| 過去否定 | 学生ではありませんでした<br>じゃありませんでした | 学生ではなかった<br>じゃなかった |

## 2. 二類形容詞（な形容词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 静かです | 静かだ |
| 過去 | 静かでした | 静かだった |
| 否定 | 静かではありません<br>じゃありません | 静かではない<br>じゃない |
| 過去否定 | 静かではありませんでした<br>じゃありませんでした | 静かではなかった<br>じゃなかった |

## 3. 一類形容詞（い形容词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 暑いです | 暑い |
| 過去 | 暑かったです | 暑かった |
| 否定 | 暑くないです<br>くありません | 暑くない |
| 過去否定 | 暑くなかったです<br>くありませんでした | 暑くなかった |

## 4. 動詞（动词）

| | 敬体形 | 簡体形 |
|---|---|---|
| 現在 | 行きます | 行く |
| 過去 | 行きました | 行った |
| 否定 | 行きません | 行かない |
| 過去否定 | 行きませんでした | 行かなかった |

补充两点原图里的规律（方便记忆）：
- **名词、な形容词**：否定和过去否定都用「では／じゃ」起头，简体去「です」后接「ない／なかった」。
- **い形容词、动词**：变形发生在词尾本身（暑い→暑くない、行く→行かない），敬体只是再挂「です／ます」。
