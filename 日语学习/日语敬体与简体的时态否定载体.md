# 日语敬体与简体的时态否定载体

> 一句话：**敬体（ます体）里时态和否定基本都由助动词承担，动词本体只变形一次就固定不动；但「です体系」和「イ形容词」要单独拆开看**——前者靠助动词です，后者靠形容词自身活用。

---

## 0. 核心结论

| 词类 | 谁扛时态 / 否定 | 本体变不变 |
| --- | --- | --- |
| 动词（ます体） | 助动词 **ます・ました・ません・ませんでした** | 变一次词干后**固定不动** |
| イ形容词（敬体） | **形容词自身词尾活用**（い→かった／く） | 自己在变，**です 不扛时态否定** |
| 名词・ナ形容词（敬体） | 助动词 **です・でした・ではありません** | **本体完全不动** |

> 关键分歧点：都叫「敬体」，但**动词的礼貌标记是助动词「ます」，イ形容词的礼貌标记只是后缀「です」**——前者扛时态，后者不扛。

---

## 1. 总表：四类 × 四形式（简体 / 敬体对照）

### 动词（書く）

| 形式 | 简体 | 敬体 |
| --- | --- | --- |
| 现在肯定 | 書く | 書き**ます** |
| 过去肯定 | 書**いた** | 書き**ました** |
| 现在否定 | 書か**ない** | 書き**ません** |
| 过去否定 | 書か**なかった** | 書き**ませんでした** |

### イ形容词（暑い）

| 形式   | 简体         | 敬体           |
| ---- | ---------- | ------------ |
| 现在肯定 | 暑い         | 暑い**です**     |
| 过去肯定 | 暑**かった**   | 暑**かった**です   |
| 现在否定 | 暑**くない**   | 暑**くない**です   |
| 过去否定 | 暑**くなかった** | 暑**くなかった**です |

> 敬体那一列，**只有「です」这四个字从头到尾没变**——变的全是形容词自己。

### ナ形容词（静か）

| 形式 | 简体 | 敬体 |
| --- | --- | --- |
| 现在肯定 | 静か**だ** | 静か**です** |
| 过去肯定 | 静か**だった** | 静か**でした** |
| 现在否定 | 静か**ではない** | 静か**ではありません** |
| 过去否定 | 静か**ではなかった** | 静か**ではありませんでした** |

### 名词（学生）

| 形式 | 简体 | 敬体 |
| --- | --- | --- |
| 现在肯定 | 学生**だ** | 学生**です** |
| 过去肯定 | 学生**だった** | 学生**でした** |
| 现在否定 | 学生**ではない** | 学生**ではありません** |
| 过去否定 | 学生**ではなかった** | 学生**ではありませんでした** |

> ナ形容词和名词的变形**完全同构**，可以合成一栏记：本体不动，全靠 だ／です 这一套。

---

## 2. 动词：ます敬体

**分两层看：第一层是动词自己变词干（只做一次），第二层是助动词扛一切。**

書く → **書き**（ます形词干，此后不再改动）

- 書き + **ます** → 现在肯定
- 書き + **ました** → 过去肯定（ます 的过去式）
- 書き + **ません** → 现在否定（ます 的否定）
- 書き + **ませんでした** → 过去否定（ません 的过去）

✅ **词干不变，时态/否定全交给ます系列助动词。**

> 对比一下简体：書く → 書**いた**／書か**ない**／書か**なかった**。简体里动词也要先做词尾活用，再挂助动词 た・ない；敬体里是先变出一段"ます形词干"，后面全是助动词的事。

---

## 3. 动词：简体

动词原形 = 现在肯定，其余靠"词尾活用 + 助动词"。

| 形式 | 构成 | 例 |
| --- | --- | --- |
| 现在肯定 | 原形（动词本身） | 書く |
| 过去肯定 | 活用 + 助动词 **た** | 書いた ← 时态由 た 扛 |
| 现在否定 | 活用 + 助动词 **ない** | 書かない ← 否定由 ない 扛 |
| 过去否定 | ない → なかった | 書かなかった ← なかった 是 ない 的过去形 |

> 重点：动词本体**只做一次词尾变形**，时态/否定交给 た・ない 两个助动词。

---

## 4. イ形容词：敬体

一类形容词**不靠ます**，它自己有词尾活用（属于词本身的活用，不是助动词）；后面加「です」只是礼貌标记。

- 暑い**です**（现在肯定）
- 暑**かった**です（过去肯定：い→かった）
- 暑**くない**です（现在否定：い→く＋ない）
- 暑**くなかった**です（过去否定：い→く＋なかった）

> **です 在这里只是礼貌后缀，去掉就是简体；时态、否定是形容词自己变的，不是 です 变的。**

### 两个变体（口语 / 正式）

| 形式 | 口语常用 | 更正式 |
| --- | --- | --- |
| 现在否定 | 暑くないです | 暑く**ありません** |
| 过去否定 | 暑くなかったです | 暑く**ありませんでした** |

> 「ありません」这一支其实是走了「ある」的敬体否定，所以看起来像"动词式"处理；但它仍然不改变"イ形容词靠自己活用"这条主线。

---

## 5. イ形容词：简体

**没有助动词扛时态否定，全是形容词自己词尾活用**（只有否定用到助动词 ない）。

- 现在肯定：暑い（原形）
- 过去肯定：暑**かった**（い→かった，自身活用）
- 现在否定：暑**くない**（い→く，再加助动词 ない）
- 过去否定：暑**くなかった**

---

## 6. 名词 / ナ形容词：敬体

**です 本身就是助动词，时态否定全部由 です 一套承载；词本体不动。**

学生／静か：

- 学生**です**　静か**です**（现在肯定）
- 学生**でした**　静か**でした**（过去肯定）
- 学生**ではありません**　静か**ではありません**（现在否定）
- 学生**ではありませんでした**　静か**ではありませんでした**（过去否定）

口语变体：ではありません → **じゃありません／じゃないです**（越低越口语）。

---

## 7. 名词 / ナ形容词：简体

简体判定助动词是 **だ**（です 的简体），本体不变：

- 现在肯定：静か**だ** / 学生**だ**
- 过去肯定：静か**だった** / 学生**だった**（だ→だった）
- 现在否定：静か**ではない** / 学生**ではない**（ない 是否定助动词）
- 过去否定：静か**ではなかった** / 学生**ではなかった**

---

## 8. 一句话区分（三条）

1. ✅ **动词ます敬体**：动词只变一次词干，时态否定由助动词 **ます／ました／ません／ませんでした** 承载
2. ❌ **イ形容词敬体**：时态否定是**形容词自身词尾活用**，です 只负责礼貌，不扛时态否定
3. ✅ **名词・ナ形容词敬体**：本体不动，时态否定全部由 **です／でした／ではありません** 这一套承载

对应的简体版：

1. 动词 → 词尾活用，时态靠 **た**、否定靠 **ない**
2. イ形容词 → 自己变，**只有否定才加 ない**
3. 名词／ナ形容词 → 靠 **だ** 一套（だ・だった・ではない・ではなかった）

**一句话总结：简体里，动词和名词/ナ形容词的时态否定主要靠助动词 た・ない・だ；一类形容词大部分变化是自身词尾活用。**

---

## 9. 容易混淆的地方

### ① 语法身份：谁算助动词

- 「ます」「です」**都是助动词**
- 「ない」「た」在简体里**也是助动词**（形容詞型 / 过去助动词）
- イ形容词的「かった」「く」**是形容词本身的活用形，不属于助动词**

> 判断口径沿用 [[助词和助动词]]：能活用（能变形）→ 助动词。

### ② 最高频的错误：暑いでした ❌

「です」接イ形容词时**没有时态能力**，过去必须由形容词自己变成 かった：

- ❌ 暑いでした → ✅ 暑**かった**です
- ❌ 暑いじゃないです → ✅ 暑**くない**です

反过来，名词句里「です」是有时态的，所以「学生でした」完全正确。**同样一个「です」，在イ形容词后面是哑巴，在名词后面是主力。**

### ③ 名词否定的"两个ありません"别混

- 学生**ではありません** ← 名词否定（ではない 的敬体化）
- 学生**ではありませんでした** ← 名词否定 + 过去
- 静か**ではありません** 与 学生**ではありません** 结构一致，都是 で＋は＋ありません

### ④ 不规则：いい

いい 的活用全走 **よ** 词干：よくない／よかった／よくなかった（敬体同：よかったです、よくなかったです）。不要写成 いかった。

### ⑤ 动词「ある」的否定

ある 的否定是 **ない**（不是 あらない），敬体 ありません；过去否定 ありませんでした。

### ⑥ ナ形容词修饰名词时加 な，句尾不加

静か**な**部屋（定语）／この部屋は静か**です**（句尾）。别把定语那个 な 带到句尾去。

---

## 10. 口诀

**动词换词干再挂ます；イ形容词自己变、です 只站岗；名词ナ形容词一动不动、全交给 だ／です。**

做题三步走：

1. 这句的谓语是 **动词 / イ形容词 / 名词・ナ形容词** 哪一类？
2. 是**现在还是过去**、**肯定还是否定**？（四格定位）
3. 敬体还是简体？（敬体挂 ます／です 体系，简体挂 た／ない／だ）
