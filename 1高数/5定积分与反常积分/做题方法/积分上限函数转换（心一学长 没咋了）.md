## 例二 被积函数有上限变量 分离方法  
![](./assets/积分上限函数转换（心一学长%20没咋了）/file-20260608171112464.webp)
[区间再现](定积分的计算方法.md#^5e3eaf)
![](./assets/积分上限函数转换（心一学长%20没咋了）/file-20260608171112444.webp)  
这道题正是我们之前反复剖析过的“被积函数混叠求导变量 $x$”的经典题型！在考研数学的历年真题中，这种变限积分求导是绝对的基础且高频的考点。

面对 $F(x) = \int_{0}^{x} f(x-t)dt$，由于积分号内部既有积分变量 $t$，又潜伏着求导变量 $x$，我们**绝对不能直接求导**。必须先剥离 $x$。

你有两种方法可以轻松拿下它：

### 方法一：利用“区间再现”公式（秒杀法）

根据我们之前总结的变上限积分区间再现技巧：直接将积分变量 $t$ 替换为 $(积分下限 + 积分上限 - t)$，也就是 $(0 + x - t) = x - t$。

$$F(x) = \int_{0}^{x} f(x-t) dt = \int_{0}^{x} f(x - (x-t)) dt = \int_{0}^{x} f(t) dt$$

现在被积函数里干干净净只有 $t$ 了，直接套用基本定理对 $x$ 求导：

$$F'(x) = f(x)$$

### 方法二：标准换元法（严谨推导）

如果需要写详细的解答步骤，标准换元法是最稳妥的展示方式：

1. **设新变量：** 令 $u = x - t$。注意，在这个定积分运算中，是对 $t$ 进行积分，$x$ 只是一个常数参数。所以两边对 $t$ 微分得到 $dt = -du$。
    
2. **换积分限：**
    
    - 当 $t = 0$ 时，$u = x - 0 = x$。
        
    - 当 $t = x$ 时，$u = x - x = 0$。
        
3. **代入原式化简：**
    
    $$F(x) = \int_{x}^{0} f(u) (-du)$$
    
    利用定积分的性质，用负号把上下限颠倒回来：
    
    $$F(x) = \int_{0}^{x} f(u) du$$
    
4. **最终求导：**
    
    $$F'(x) = \frac{d}{dx} \int_{0}^{x} f(u) du = f(x)$$
    

**最终答案：**

$$F'(x) = f(x)$$
