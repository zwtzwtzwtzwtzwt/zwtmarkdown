## 求解多元函数极限的“看次数”法则

在求解多元函数极限（特别是当 $(x,y)\to(0,0)$ 时），我们常常会遇到 $\frac{0}{0}$ 型未定式。“看次数”是一种判断极限存在性及求解方向的高效经验法则。

**核心概念：**

- **次数：** 指多项式每一项中 $x$ 和 $y$ 的指数之和（例如 $x^2y$ 的次数为 2+1=3）。
    
- **本质：** 极限是否存在，取决于分子和分母**谁趋近于 0 的速度更快**。
    

### 一、 分子次数 = 分母次数

- **结论：** 极限一般**不存在**。
    
- **原理：** 分子和分母同速趋于 0。如果从不同方向（例如不同斜率的直线）靠近原点，由于各自系数比例不同，会得到不同的极限值，这违背了“多元函数极限值必须与路径无关”的定理。
    
- **常用验证方法：** 设定直线路径 $y=kx$ 代入计算。
    

**【举例解析】** 求 $\lim_{(x,y)\to(0,0)}\frac{xy}{x^2+y^2}$

1. **观察：** 分子 $xy$ 次数为 2，分母 $x^2+y^2$ 次数也为 2，猜测极限不存在。
    
2. **证明：** 令 $y=kx$ （即沿着任意一条过原点的直线靠近），代入原式：
    
    $$\lim_{x\to0}\frac{x(kx)}{x^2+(kx)^2}=\lim_{x\to0}\frac{kx^2}{x^2(1+k^2)}=\frac{k}{1+k^2}$$
    
3. **结论：** 结果依赖于路径斜率 $k$。例如沿 $y=x$ 时极限为 1/2，沿 $y=2x$ 时极限为 2/5。因不同路径极限不同，故原极限**不存在**。
    

### 二、 分子次数 < 分母次数

- **结论：** 极限一般**不存在**（常发散为无穷大）。
    
- **原理：** 分母趋近于 0 的速度远快于分子。一个微小的数除以一个极其微小（接近于 0）的数，结果会呈爆炸式增长，趋向于 $\infty$。
    
- **常用验证方法：** 设定沿某条坐标轴（如 $y=0$）靠近原点。
    

**【举例解析】** 求 $\lim_{(x,y)\to(0,0)}\frac{x}{x^2+y^2}$

1. **观察：** 分子 $x$ 次数为 1，分母 $x^2+y^2$ 次数为 2，分子 < 分母。
    
2. **证明：** 令 $y=0$ （即沿着 x 轴靠近），代入原式：
    
    $$\lim_{x\to0}\frac{x}{x^2+0}=\lim_{x\to0}\frac{1}{x}=\infty$$
    
3. **结论：** 函数值发散至无穷，故原极限**不存在**。
    

### 三、 分子次数 > 分母次数

- **结论：** 极限通常**存在**，且等于 **0**。
    
- **原理：** 分子趋近于 0 的速度压倒性地快于分母，强大的“趋零”力量最终将整个分式拉向 0。
    
- **常用证明方法：** 极坐标代换法、夹逼定理放缩法。
    

**【举例解析】** 求 $\lim_{(x,y)\to(0,0)}\frac{x^2y}{x^2+y^2}$

1. **观察：** 分子 $x^2y$ 次数为 3，分母 $x^2+y^2$ 次数为 2。分子 > 分母，猜测极限存在且为 0。
    
2. **证明方法 A（夹逼定理）：**
    
    $$\left|\frac{x^2y}{x^2+y^2}\right|=|y|\cdot\frac{x^2}{x^2+y^2}$$
    
    因为对于任意不全为 0 的 $x, y$，均有 $\frac{x^2}{x^2+y^2}\le1$。
    
    所以 $0\le\left|\frac{x^2y}{x^2+y^2}\right|\le|y|\cdot1=|y|$。
    
    当 $(x,y)\to(0,0)$ 时，$|y|\to0$。根据夹逼定理，原极限为 **0**。
    
3. **证明方法 B（极坐标法）：**
    
    令 $x=r\cos\theta, y=r\sin\theta$。当 $(x,y)\to(0,0)$ 时，即 $r\to0$。代入原式：
    
    $$\lim_{r\to0}\frac{(r\cos\theta)^2(r\sin\theta)}{(r\cos\theta)^2+(r\sin\theta)^2}=\lim_{r\to0}\frac{r^3\cos^2\theta\sin\theta}{r^2}=\lim_{r\to0}r\cos^2\theta\sin\theta$$
    
    由于 $\cos^2\theta\sin\theta$ 是有界函数，乘上趋于 0 的 $r$，极限结果显然为 **0**。
    

### ⚠️ 陷阱提醒：非齐次多项式与曲线路径法

“看次数”法则在面对**齐次多项式**（每一项次数整齐划一）时非常有效，但如果遇到**非齐次多项式**（分母各项的次数不统一），简单的看最低次可能引发误判。这时需要尝试用 $y=kx^m$ （抛物线等曲线路径）进行验证。

> **易错案例：** 求 $\lim_{(x,y)\to(0,0)}\frac{x^2y}{x^4+y^2}$

- **直觉误判：** 分子总次数为 3。分母由 4 次项和 2 次项组成，看最低次是 2。似乎满足“分子 > 分母”，容易误判极限为 0。
    
- **正确证明：** 令路径为抛物线 $y=kx^2$ 代入：
    
    $$\lim_{x\to0}\frac{x^2(kx^2)}{x^4+(kx^2)^2}=\lim_{x\to0}\frac{kx^4}{x^4+k^2x^4}=\frac{k}{1+k^2}$$
    
- **分析：** 计算结果中仍然保留了斜率参数 $k$。这意味着沿着不同开口大小的抛物线靠近原点时，会得到截然不同的极限值。因此，该极限实际上**不存在**。
    

### 💡 核心总结与应用策略

| **步骤** | **观察判断**          | **应对策略**                                 | **预期结果**                        |
| ------ | ----------------- | ---------------------------------------- | ------------------------------- |
| **1**  | **分子次 > 分母次**     | 优先使用极坐标变换 $(r, \theta)$，或提取绝对值用夹逼定理放缩。   | 证明存在且等于 **0**                   |
| **2**  | **分子次 $\le$ 分母次** | 优先引入直线路径 $y=kx$ 或坐标轴代入。                  | 证明含有参数 $k$ 或 $\infty$，极限**不存在** |
| **3**  | **非齐次特殊情况**       | 若分母各项次数差距悬殊，尝试配凑曲线路径 $y=kx^m$ 让各项次数强行统一。 | 证明含有参数 $k$，极限**不存在**            |
