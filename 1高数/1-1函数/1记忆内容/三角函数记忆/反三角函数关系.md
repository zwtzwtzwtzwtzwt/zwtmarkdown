在微积分和考研数学中，反三角函数的恒等变形是化简积分和极限的重要工具。除了您提到的 $\arctan(x) + \arctan\left(\frac{1}{x}\right) = \frac{\pi}{2}$ $(x > 0)$ 之外，还有很多类似的“成对”或“互补”的结论。

  

以下为您系统总结反三角函数中最常用的几类恒等式，并附带了成立的定义域条件（这一点在解题时极其重要）：

  

### 1. 倒数关系（自变量互为倒数）

这是您提到的那个结论的扩展。它主要反映了函数值与倒数自变量之间的联系。

  

- **反正切与反正切：**
    
      
    - 当 $x > 0$ 时，$\arctan(x) + \arctan\left(\frac{1}{x}\right) = \frac{\pi}{2}$
        
          
        
    - 当 $x < 0$ 时，$\arctan(x) + \arctan\left(\frac{1}{x}\right) = -\frac{\pi}{2}$
        
          
        
- **反正弦与反余割：**
    
      
    - $\arcsin\left(\frac{1}{x}\right) = \text{arccsc}(x)$ $(\vert{}x\vert{} \ge 1)$
        
          
        
- **反余弦与反正割：**
    
      
    - $\arccos\left(\frac{1}{x}\right) = \text{arcsec}(x)$ $(\vert{}x\vert{} \ge 1)$
        
          
        
- **反正切与反余切：**
    
      
    - 当 $x > 0$ 时，$\arctan\left(\frac{1}{x}\right) = \text{arccot}(x)$
        
          
        

### 2. 余角关系（函数值求和为 $\frac{\pi}{2}$）

这一组公式在定积分的“区间再现”或换元时经常被用来凑项消除，非常关键。

  

- **正弦与余弦：**
    
      
    
    $$\arcsin(x) + \arccos(x) = \frac{\pi}{2} \quad (x \in [-1, 1])$$
    
- **正切与余切：**
    
      
    
    $$\arctan(x) + \text{arccot}(x) = \frac{\pi}{2} \quad (x \in \mathbb{R})$$
    
- **正割与余割：**
    
      
    
    $$\text{arcsec}(x) + \text{arccsc}(x) = \frac{\pi}{2} \quad (\vert{}x\vert{} \ge 1)$$
    

### 3. 奇偶性与负变量关系（关于原点或 $y$ 轴的对称性转换）

用于将负号从反三角函数的自变量中提取出来，特别是在处理对称区间积分 $\int_{-a}^a f(x) dx$ 时必用。

  

- **奇函数类（直接提负号）：**
    
      
    - $\arcsin(-x) = -\arcsin(x)$
        
          
        
    - $\arctan(-x) = -\arctan(x)$
        
          
        
- **非奇非偶类（需要补 $\pi$）：**
    
      
    
    - $\arccos(-x) = \pi - \arccos(x)$
        
          
        
    - $\text{arccot}(-x) = \pi - \text{arccot}(x)$
        
          
        
    
    > **注意：** $\arccos(x)$ 的值域是 $[0, \pi]$，因此 $\arccos(-x)$ 绝不是 $-\arccos(x)$，千万不要当成奇函数处理。
    > 
    >   
    

### 4. 反正切的加减法公式

在计算不定积分的拆项，或者级数求和（如裂项相消）时，反正切的加减法公式是核心考点。

  

- **和公式：**
    
      
    
    $$\arctan(x) + \arctan(y) = \arctan\left(\frac{x + y}{1 - xy}\right) \quad (\text{当 } xy < 1 \text{ 时})$$
    
- **差公式：**
    
      
    
    $$\arctan(x) - \arctan(y) = \arctan\left(\frac{x - y}{1 + xy}\right) \quad (\text{当 } x > 0, y > 0 \text{ 时})$$
    

### 总结应用口诀：

- 遇到 $\frac{1}{x}$ 想到 **倒数关系**。
    
      
    
- 遇到 $\arcsin$ 和 $\arccos$ 同时出现，想到 ** $\frac{\pi}{2}$ 互余关系**。
    
      
    
- 遇到自变量带负号，马上判定 **奇偶性（$\arccos$ 记得用 $\pi$ 减）**。
