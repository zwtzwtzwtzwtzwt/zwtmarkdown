这份资料系统地梳理了函数奇偶性的核心概念、构造方法以及在考试中常考的特殊函数形式。以下是为你合并总结的核心要点：

### 一、 核心定义与图形性质

奇偶性是函数在对称区间上的基本代数特征，对应着直观的几何对称性：

- **偶函数**：满足 $f(-x) = f(x)$。其图形关于 $y$ 轴对称。
    
- **奇函数**：满足 $f(-x) = -f(x)$。其图形关于原点对称。
    
    - **重要性质**：若奇函数 $f(x)$ 在 $x = 0$ 处有定义，则必然有 $f(0) = 0$。
        

### 二、 黄金构造与分解法则

对于任意一个定义在对称区间上的函数 $f(x)$，无论其本身是否具有奇偶性，都可以通过以下“黄金构造法则”提取出纯粹的奇/偶函数：

- **必为偶函数**：$f(x) + f(-x)$。
    
- **必为奇函数**：$f(x) - f(-x)$。
    
- **任意函数的奇偶分解**：任何函数都可以拆分为一个偶函数与一个奇函数之和，公式表达为 $f(x) = \frac{f(x) + f(-x)}{2} + \frac{f(x) - f(-x)}{2}$。
    

### 三、 高频考点：超越函数的奇偶性盘点

单纯的指数函数 $e^x$ 或对数函数 $\ln x$ 没有奇偶性，但通过巧妙组合可以构造出考试命题人最青睐的特殊奇偶函数。

#### 1. 常见偶函数

- **基础幂/三角类**：$x^2$、$\vert{}x\vert{}$、$\cos x$。
    
- **双曲余弦**：$\cosh x = \frac{e^x + e^{-x}}{2}$。
    
- **指数平方型**：$e^{x^2}$、$e^{-x^2}$。
    
- **特殊对数类**：$\ln\vert{}x\vert{}$、$\ln(\vert{}x\vert{} + \sqrt{x^2 + 1})$。
    

#### 2. 常见奇函数（需重点记忆）

- **基础三角/反三角类**：$\sin x$、$\tan x$、$\arcsin x$、$\arctan x$。
    
- **双曲正弦**：$\sinh x = \frac{e^x - e^{-x}}{2}$。
    
- **对数分式型**：$\ln \frac{1 - x}{1 + x}$ 或扩展形式 $\ln(\frac{a - x}{a + x})$。
    
- **对数根式型**：$\ln(x + \sqrt{1 + x^2})$ 或扩展形式 $\ln(x + \sqrt{x^2 + a^2})$。
    
- **指数分式型**：$\frac{e^x - 1}{e^x + 1}$。
