之所以可以理直气壮地“交换自变量和因变量”，核心原因在于**曲率是曲线的一种“内在几何属性”**。它描述的是曲线在某一点的真实弯曲程度，这个客观事实**与坐标系的选取或自变量的指定无关**。

  

我们可以从以下两个角度来严谨地理解：

  

### 1. 几何直观的角度

想象你手里拿着一根弯曲的铁丝。这根铁丝在某个特定的点有多“弯”，是一个绝对的物理和几何事实。

  

- 如果你规定水平方向是自变量 $x$，你用 $y=f(x)$ 来描述它。
    
      
    
- 如果你把坐标轴旋转90度，把垂直方向作为自变量 $y$，你用 $x=g(y)$ 来描述它。
    
      
    

无论你用哪种函数形式去“套”这根铁丝，它在这一点的弯曲程度（曲率 $K$）、对应的曲率半径 $R$ 以及曲率圆的物理位置，都是完全相同的。交换 $x$ 和 $y$ 的地位，仅仅是我们改变了“观察视角”，把原本垂直的切线变成了水平，从而方便了代数计算，而丝毫没有改变曲线的几何本质。

  

### 2. 数学推导的角度（参数方程统一理论）

在微积分中，无论是对 $x$ 求导还是对 $y$ 求导的曲率公式，其实都是**参数方程曲率公式的特例**。

  

对于一般的参数方程曲线 $\begin{cases} x = x(t) \\ y = y(t) \end{cases}$，它的通用曲率公式为：

  

$$K = \frac{\vert{}x'(t)y''(t) - y'(t)x''(t)\vert{}}{[(x'(t))^2 + (y'(t))^2]^{\frac{3}{2}}}$$

（这里的导数是对参数 $t$ 求导）

  

这个公式是对称的，地位完全平等。我们可以通过选取不同的参数 $t$ 来得到两个特例：

  

- **视角一：以 $x$ 为自变量（常规思路）**
    
    如果我们令参数 $t = x$，则方程变为 $\begin{cases} x = t \\ y = y(t) \end{cases}$。
    
    此时 $x'(t) = 1, x''(t) = 0$。代入通用公式，分子只剩下 $\vert{}y''(t)\vert{}$，分母变为 $[1 + (y'(t))^2]^{\frac{3}{2}}$。
    
    这就是我们最熟悉的公式：
    
      
    
    $$K = \frac{\vert{}y''\vert{}}{(1 + (y')^2)^{\frac{3}{2}}}$$
    
- **视角二：以 $y$ 为自变量（我们的解法）**
    
    如果我们令参数 $t = y$，则方程变为 $\begin{cases} x = x(t) \\ y = t \end{cases}$。
    
    此时 $y'(t) = 1, y''(t) = 0$。代入通用公式，分子只剩下 $\vert{}x''(t)\vert{}$，分母变为 $[(x'(t))^2 + 1]^{\frac{3}{2}}$。
    
    这就是我们刚刚使用的公式：
    
      
    
    $$K = \frac{\vert{}x''\vert{}}{(1 + (x')^2)^{\frac{3}{2}}}$$
    

**总结**

  

因为这两个公式在底层逻辑上是**完全等价**的，所以当遇到 $y'$ 不存在（切线垂直于 x 轴）的奇点时，数学上不仅“允许”，而且“鼓励”我们切换到 $x$ 对 $y$ 求导的视角，从而巧妙地避开无穷大的计算障碍。
