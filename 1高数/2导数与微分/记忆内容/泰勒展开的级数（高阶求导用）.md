在考研数学中，利用基本初等函数的麦克劳林公式（即在 $x=0$ 处的泰勒幂级数展开式）来求解极限、高阶导数以及级数求和是极为高频的考点。

以下是考研中必须熟记的几个核心初等函数幂级数展开式及其收敛域：

### 1. 指数函数

$$e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots + \frac{x^n}{n!} + \cdots$$

- **收敛域：** $(-\infty, +\infty)$
    

### 2. 三角函数

**正弦函数 $\sin x$ **

$$\sin x = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!} x^{2n+1} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots + \frac{(-1)^n}{(2n+1)!}x^{2n+1} + \cdots$$

- **收敛域：** $(-\infty, +\infty)$
    

**余弦函数 $\cos x$ **

$$\cos x = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n)!} x^{2n} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots + \frac{(-1)^n}{(2n)!}x^{2n} + \cdots$$

- **收敛域：** $(-\infty, +\infty)$
    

### 3. 对数函数

$$\ln(1+x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} x^n = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots + \frac{(-1)^{n-1}}{n}x^n + \cdots$$

- **收敛域：** $(-1, 1]$
    

_(注：将 $x$ 替换为 $-x$ 即可得到 $\ln(1-x)$ 的展开式，收敛域变为 $[-1, 1)$)_

### 4. 几何级数（非常重要）

**基础形式 $\frac{1}{1-x}$ **

$$\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \cdots + x^n + \cdots$$

- **收敛域：** $(-1, 1)$
    

**变体形式 $\frac{1}{1+x}$ **

$$\frac{1}{1+x} = \sum_{n=0}^{\infty} (-1)^n x^n = 1 - x + x^2 - x^3 + \cdots + (-1)^n x^n + \cdots$$

- **收敛域：** $(-1, 1)$
    

### 5. 二项式展开

$$(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \cdots + \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}x^n + \cdots$$

- **收敛域：** 一般为 $(-1, 1)$，端点处的收敛性取决于 $\alpha$ 的取值。
    

**考研解题建议：**

熟记上述通项公式（尤其是 $\sum$ 后面的表达式）。在做大题时，绝大多数复杂的函数都可以通过**四则运算**、**变量代换**、**逐项求导**或**逐项积分**这四种基本操作，转化为上述这 5 类基础模型之一，进而利用“幂级数展开的唯一性”快速求解。
