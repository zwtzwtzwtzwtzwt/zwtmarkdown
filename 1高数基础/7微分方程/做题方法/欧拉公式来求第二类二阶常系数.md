# 常规方法  
这是一个非常典型的二阶常系数线性非齐次微分方程。题目要求求解

$$y'' - 2y' + 5y = e^x \sin 2x$$

的通解。

通解的结构为 ** $y = y_c + y_p$ **（齐次通解 + 非齐次特解）。这两种方法在求齐次通解时是完全一样的，核心的区别在于**如何求特解 $y_p$ **。

我们先求齐次通解 $y_c$：

写出对应的特征方程：

$$r^2 - 2r + 5 = 0$$

解得特征根为一对共轭复根：

$$r_{1,2} = 1 \pm 2i$$

因此，齐次方程的通解为：

$$y_c = e^x(C_1 \cos 2x + C_2 \sin 2x)$$

接下来，我们分别用常规方法（待定系数法）和欧拉公式法（复指数法）来求特解 $y_p$，并做对比。注意观察题目右端项 $f(x) = e^x \sin 2x$，它对应的特征参数 $\alpha + i\beta = 1 + 2i$，**刚好等于特征根，这就发生了“共振”（属于单重根情形），因此特解前面必须多乘一个 $x$。**

### 方法一：常规方法（待定系数法）

按照传统规则，我们需要同时设出正弦和余弦项，并乘上 $x$：

设特解为：

$$y_p = x e^x (A \cos 2x + B \sin 2x)$$

这使得求导过程变得极其繁琐，因为包含了三个函数的乘积（$x$、$e^x$、三角函数）。

**求一阶导：**

$$y_p' = e^x (A \cos 2x + B \sin 2x) + x e^x (A \cos 2x + B \sin 2x) + x e^x (-2A \sin 2x + 2B \cos 2x)$$

整理合并同类项：

$$y_p' = e^x [ (A + Ax + 2Bx) \cos 2x + (B + Bx - 2Ax) \sin 2x ]$$

**求二阶导（过程非常容易出错）：**

$$y_p'' = e^x [ (A + Ax + 2Bx) \cos 2x + (B + Bx - 2Ax) \sin 2x ] + e^x [ (A + 2B) \cos 2x + (B - 2A) \sin 2x ] + 2e^x [ -(A + Ax + 2Bx) \sin 2x + (B + Bx - 2Ax) \cos 2x ]$$

再次极其耐心地整理合并：

$$y_p'' = e^x \cos 2x [ 2A + 4B + x(-3A + 4B) ] + e^x \sin 2x [ 2B - 4A + x(-3B - 4A) ]$$

**代入原方程 $y'' - 2y' + 5y = e^x \sin 2x$：**

将 $y_p''$、$-2y_p'$、$5y_p$ 对应的 $\cos 2x$ 和 $\sin 2x$ 前的系数分别相加，包含 $x$ 的项会奇迹般地全部抵消。

- $\cos 2x$ 的系数：$(2A + 4B) - 2(A) + 0 = 4B$
    
- $\sin 2x$ 的系数：$(2B - 4A) - 2(B) + 0 = -4A$
    

等式左边化简为：

$$e^x (4B \cos 2x - 4A \sin 2x)$$

对比右端项 $e^x \sin 2x$，得方程组：

$$4B = 0 \implies B = 0$$

$$-4A = 1 \implies A = -\frac{1}{4}$$

所以，特解为：

$$y_p = -\frac{1}{4} x e^x \cos 2x$$

### 方法二：欧拉公式法（复指数法）

利用欧拉公式，我们知道 $e^x \sin 2x$ 是复指数函数 $e^{(1+2i)x}$ 的**虚部**。

因此，我们可以构造一个复数微分方程：

$$z'' - 2z' + 5z = e^{(1+2i)x}$$

只要解出这个方程的特解 $z_p$，那么原方程的特解 $y_p$ 就是 $z_p$ 的虚部，即 $y_p = \text{Im}(z_p)$。

因为 $r = 1+2i$ 是特征方程的单根，我们设特解为：

$$z_p = A x e^{(1+2i)x}$$

这里的求导要简单得多，因为指数函数的求导形式具有高度一致性：

$$z_p' = A e^{(1+2i)x} [1 + (1+2i)x]$$

$$z_p'' = A e^{(1+2i)x} [(1+2i) + (1+2i) + (1+2i)^2 x] = A e^{(1+2i)x} [2 + 4i + (-3 + 4i)x]$$

**代入复数方程 $z'' - 2z' + 5z = e^{(1+2i)x}$：**

提取公因式 $A e^{(1+2i)x}$，括号内为：

$$[2 + 4i + (-3 + 4i)x] - 2[1 + (1+2i)x] + 5x$$

计算括号里的常数项和 $x$ 项：

常数项：$2 + 4i - 2 = 4i$

$x$ 项：$-3 + 4i - 2 - 4i + 5 = 0$

于是等式左边极其清爽地变成了：

$$A e^{(1+2i)x} \cdot (4i) = e^{(1+2i)x}$$

直接解出复系数 $A$：

$$4i A = 1 \implies A = \frac{1}{4i} = -\frac{1}{4}i$$

将 $A$ 代回 $z_p$，并用欧拉公式展开：

$$z_p = -\frac{1}{4}i x e^{(1+2i)x} = -\frac{1}{4}i x e^x (\cos 2x + i \sin 2x)$$

$$z_p = \frac{1}{4} x e^x \sin 2x - i \frac{1}{4} x e^x \cos 2x$$

取虚部，直接得到特解：

$$y_p = \text{Im}(z_p) = -\frac{1}{4} x e^x \cos 2x$$

### 最终结论与对比评析

将齐次通解和特解相加，这道题的最终通解为：

$$y = e^x(C_1 \cos 2x + C_2 \sin 2x) - \frac{1}{4} x e^x \cos 2x$$

**方法对比：**

1. **计算量与容错率**：常规方法在遇到“多项式 × 指数 × 三角函数”且发生共振（需乘 $x$）时，求一阶导和二阶导的过程是一场灾难，极易在加减号和合并同类项中算错。欧拉公式法将三角函数降维成了指数函数，求导规则极其机械且不易出错，$x$ 的项在代入时也会瞬间自动抵消。
    
2. **本质降维**：常规方法是在实数域里用三角函数的导数循环（正弦变余弦，余弦变正弦）去硬凑系数；欧拉公式法则是利用复数域里指数函数求导的“自身相似性”，将微积分问题彻底降维成了一个简单的代数方程运算。
