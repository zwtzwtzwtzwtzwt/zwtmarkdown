这四道题堪称考研多元微积分的“四大名捕”！它们分别精准地击破了我们之前讨论的那个“连续、偏导、可微”三角关系图中的每一个“红叉”（即不能推导的方向）。

把这四个反例吃透，你的多元微分学概念就彻底无敌了。我们用之前讲过的**定义法**，一个一个来硬核证明。

### 反例 1：连续 $\nrightarrow$ 可偏导

**目标函数：** $f(x,y) = |x| + |y|$

**几何直观：** 这是一个倒扣的四棱锥，原点 $(0,0)$ 是最底下的尖点。

**1. 证明连续：**

直接求极限：$\lim_{(x,y) \to (0,0)} (|x| + |y|) = 0 + 0 = 0$。

因为极限值等于函数值 $f(0,0)$，所以**在 $(0,0)$ 点连续**。

**2. 证明偏导数不存在：**

用偏导数定义求对 $x$ 的偏导：

$$f'_x(0,0) = \lim_{x \to 0} \frac{f(x, 0) - f(0, 0)}{x} = \lim_{x \to 0} \frac{|x| + 0 - 0}{x} = \lim_{x \to 0} \frac{|x|}{x}$$

这个一元极限我们太熟悉了：从右边趋近时值为 $1$，从左边趋近时值为 $-1$。左右极限不等，故**偏导数 $f'_x(0,0)$ 不存在**。（同理 $f'_y$ 也不存在）。

既然偏导数连“候选人”都没有，自然也**不可微**。

### 反例 2：可偏导 $\nrightarrow$ 连续

**目标函数：** $f(x,y) = \frac{xy}{x^2+y^2}$ （分母为 0 时定义为 0）

**几何直观：** 这是个典型的“折纸模型”，沿着坐标轴很平坦，但沿着对角线被撕裂了。

**1. 证明偏导数存在：**

死磕定义，求对 $x$ 的偏导：

$$f'_x(0,0) = \lim_{x \to 0} \frac{f(x, 0) - f(0, 0)}{x}$$

注意，当算 $f(x,0)$ 时，把 $y=0$ 代入原式，分子变成了 $x \cdot 0 = 0$。

所以：$f'_x(0,0) = \lim_{x \to 0} \frac{0 - 0}{x} = \lim_{x \to 0} 0 = 0$。

同理，求对 $y$ 的偏导也是 $0$。**偏导数存在！**

**2. 证明不连续：**

这就用到了我们一开始讲的“换路径法”。令 $y = kx$ 趋近原点：

$$\lim_{x \to 0} \frac{x(kx)}{x^2+(kx)^2} = \lim_{x \to 0} \frac{kx^2}{x^2(1+k^2)} = \frac{k}{1+k^2}$$

极限值随路径斜率 $k$ 改变而改变，说明二元极限不存在。极限都不存在，当然**不连续**。

### 反例 3：可偏导 $\nrightarrow$ 可微

**目标函数：** $f(x,y) = \frac{xy}{\sqrt{x^2+y^2}}$ （分母为 0 时定义为 0）

**1. 证明偏导数存在：**

和反例 2 一模一样，算 $f(x,0)$ 时分子是 $0$，所以：

$$f'_x(0,0) = \lim_{x \to 0} \frac{0 - 0}{x} = 0$$

同理 $f'_y(0,0) = 0$。**偏导数存在（候选斜率 $A=0, B=0$）**。

**2. 证明不可微：**

祭出我们刚才学的“可微判定两步走”的第二步算误差极限：

$$\lim_{(x,y) \to (0,0)} \frac{f(x,y) - f(0,0) - (Ax + By)}{\sqrt{x^2 + y^2}}$$

代入 $f(x,y)$ 和 $A=0, B=0$：

$$= \lim_{(x,y) \to (0,0)} \frac{\frac{xy}{\sqrt{x^2+y^2}} - 0 - 0}{\sqrt{x^2+y^2}}$$

把分子里的分母放下来，神奇的事情发生了：

$$= \lim_{(x,y) \to (0,0)} \frac{xy}{x^2 + y^2}$$

你看！**算误差算出来的极限，居然就是反例 2 的那个函数！**

我们已经知道，这个函数的极限是**不存在**的（依赖于 $k$）。既然极限不等于 $0$，那么切平面误差就不是高阶无穷小，所以**不可微**。

### 反例 4：可微 $\nrightarrow$ 偏导数连续

**目标函数：** $f(x,y) = (x^2+y^2)\sin\frac{1}{x^2+y^2}$ （原点为 0）

**几何直观：** 这是一个在原点附近疯狂震荡的曲面，但震荡的幅度被前面的 $(x^2+y^2)$ 强行压扁到了 0。

**1. 证明可微：**

_先找偏导数（第一步）：_

$f'_x(0,0) = \lim_{x \to 0} \frac{x^2\sin(1/x^2) - 0}{x} = \lim_{x \to 0} x\sin\frac{1}{x^2} = 0$ （无穷小乘有界等于 0）。同理 $B=0$。

_算误差极限（第二步）：_

$$\lim_{(x,y) \to (0,0)} \frac{(x^2+y^2)\sin\frac{1}{x^2+y^2} - 0 - 0}{\sqrt{x^2+y^2}}$$

令距离 $\rho = \sqrt{x^2+y^2}$，上面的式子就变成了：

$$= \lim_{\rho \to 0} \frac{\rho^2 \sin\frac{1}{\rho^2}}{\rho} = \lim_{\rho \to 0} \rho \sin\frac{1}{\rho^2} = 0$$

极限完美等于 0，所以**该点绝对可微！**（曲面被死死压平了，可以放上一个水平的切平面）。

**2. 证明偏导数不连续：**

既然可微，为什么偏导不连续呢？我们来看看原点周围其他点的偏导数长什么样。

当 $(x,y) \neq (0,0)$ 时，用公式硬求导（前导后不导+前不导后导）：

$$f'_x(x,y) = 2x\sin\frac{1}{x^2+y^2} + (x^2+y^2)\cos\left(\frac{1}{x^2+y^2}\right) \cdot \frac{-2x}{(x^2+y^2)^2}$$

化简得到：

$$f'_x(x,y) = 2x\sin\frac{1}{x^2+y^2} - \frac{2x}{x^2+y^2}\cos\frac{1}{x^2+y^2}$$

现在我们来看看，当 $(x,y)$ 逼近 $(0,0)$ 时，这个导函数会不会乖乖趋近于 $f'_x(0,0) = 0$。

我们让点沿着 $x$ 轴逼近（令 $y=0$）：

$$\lim_{x \to 0} f'_x(x,0) = \lim_{x \to 0} \left[ 2x\sin\frac{1}{x^2} - \frac{2}{x}\cos\frac{1}{x^2} \right]$$

- 前面那一项 $2x\sin(1/x^2)$ 极限是 $0$。
    
- **致命的后面一项：** $\frac{2}{x} \to \infty$，而 $\cos(1/x^2)$ 在 $[-1, 1]$ 之间疯狂震荡。无穷大乘震荡因子，极限根本**不存在**！
    
    既然原点周围的导函数连极限都没有，当然就不等于原点的导数值，所以**偏导数在 $(0,0)$ 处不连续**。
    

**总结：**

这四个例子完美证明了：

1. **连续不一定可偏导**（尖点：有皮没骨架）。
    
2. **可偏导不一定连续**（十字架：骨架好好的，皮撕裂了）。
    
3. **可偏导不一定可微**（也是皮撕裂了，放不平切面）。
    
4. **可微不一定偏导连续**（皮是好的也能放切面，但周围的斜率变化像疯狗一样跳跃）。
