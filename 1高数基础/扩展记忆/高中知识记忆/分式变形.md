比例式 $\frac{a}{b} = \frac{c}{d}$ （前提是分母 $b \neq 0, d \neq 0$）在代数中有许多非常实用的等价变形，这些变形统称为**比例的性质**。

以下是常见的几种等价变形方式：

### 1. 交叉相乘（比例的基本性质）

这是最基础、最常用的变形，可以将分式转化为整式形式，便于解方程：

$$ad = bc$$

### 2. 反比性质（分子分母同时颠倒）

等式两边同时取倒数（前提是分子 $a \neq 0, c \neq 0$）：

$$\frac{b}{a} = \frac{d}{c}$$

### 3. 更比性质（交换项的位置）

你可以对角线交换比例式中的项，等式依然成立：

- **交换内项**（交换 $b$ 和 $c$，前提是 $c \neq 0$）：
    
    $$\frac{a}{c} = \frac{b}{d}$$
    
- **交换外项**（交换 $a$ 和 $d$，前提是 $a \neq 0$）：
    
    $$\frac{d}{b} = \frac{c}{a}$$
    

### 4. 合分比性质

通过对分子和分母进行加减运算，可以推导出以下变形：

- **合比/分比性质**（等式两边同时加 $1$ 或减 $1$）：
    
    $$\frac{a + b}{b} = \frac{c + d}{d}$$
    
    $$\frac{a - b}{b} = \frac{c - d}{d}$$
    
- **合分比性质**（将上面两式相除，前提是 $a \neq b, c \neq d$）：
    
    $$\frac{a + b}{a - b} = \frac{c + d}{c - d}$$
    

### 5. 等比性质与设 $k$ 法

在解决复杂的比例问题（尤其是涉及多个比例相等）时，引入一个参数 $k$ 是非常高效的手段：

令 $\frac{a}{b} = \frac{c}{d} = k$，则可以转化为：

$$a = bk$$

$$c = dk$$

此外，如果将分子分母分别相加（前提是 $b + d \neq 0$），比例的值不变：

$$\frac{a + c}{b + d} = \frac{a}{b} = \frac{c}{d}$$
