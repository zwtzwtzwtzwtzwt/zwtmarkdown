这个问题直指微积分极限运算的底层逻辑。核心原因可以用四个字概括：**精度丢失**（主部抵消导致高阶误差暴露）。

要彻底理解这个问题，我们不能仅仅停留在“等价”这两个字上，而必须引入泰勒公式中的“高阶无穷小（误差项）”概念。

在极限 $x \to 0$ 时，如果 $f(x) \sim g(x)$，它的严格数学表达其实是：

$$f(x) = g(x) + o(g(x))$$

这里的 $g(x)$ 是**主要部分（主部）**，$o(g(x))$ 是被忽略的**高阶误差项**。等价代换的本质，就是**扔掉误差项，只保留主部**。

### 一、 为什么乘除法可以替换？（误差被同比例缩小）

在乘除法中，扔掉高阶误差项是安全的，因为误差项在乘除运算后，依然是高阶无穷小，不会影响极限的最终定值。

假设我们需要计算 $\lim \frac{f(x) \cdot h(x)}{F(x)}$，并且已知 $f(x) = g(x) + o(g(x))$。

代入后得到：

$$\frac{[g(x) + o(g(x))] \cdot h(x)}{F(x)} = \frac{g(x)h(x)}{F(x)} + \frac{o(g(x))h(x)}{F(x)}$$

- 第一项 $\frac{g(x)h(x)}{F(x)}$ 是替换后的目标计算式。
    
- 第二项 $\frac{o(g(x))h(x)}{F(x)}$ 相较于第一项，分子多了一个高阶无穷小的因子。因此在求极限时，第二项必定趋近于 $0$。
    
- **结论**：在乘除法中，被丢弃的误差 $o(g(x))$ 不会翻起风浪，直接替换是绝对成立的。
    

### 二、 为什么加减法不能替换？（主部抵消，误差成为主导）

在加减法中，极其容易发生**主部相互抵消**的情况。一旦主部抵消，那些原本被你当作“等价代换”丢弃的高阶误差项，就会“篡位”成为决定极限真实结果的核心部分。

假设我们需要计算 $\lim \frac{f(x) - k(x)}{H(x)}$，并且已知 $f(x) \sim g(x)$，$k(x) \sim g(x)$。

如果我们盲目使用等价代换，分子会变成：

$$g(x) - g(x) = 0$$

这就导致结果变成了 $0$。但这往往是**假象**。

回到带误差项的严格表达：

$f(x) = g(x) + o_1(g(x))$

$k(x) = g(x) + o_2(g(x))$

真正的减法结果应该是：

$$f(x) - k(x) = [g(x) - g(x)] + [o_1(g(x)) - o_2(g(x))] = o_1(g(x)) - o_2(g(x))$$

- **结论**：主部 $g(x)$ 确实抵消了，但剩下的真实结果是两个高阶无穷小之差！如果你一开始就用了等价代换，相当于你把真正决定结果的 $o_1 - o_2$ 给人为清零了，计算自然会出错。
    

### 三、 经典反例验证

计算极限：

$$\lim_{x \to 0} \frac{x - \sin x}{x^3}$$

**1. 错误的等价代换（精度丢失）：**

看到 $\sin x \sim x$，直接把分子换成 $x - x = 0$。最终得出极限为 $0$。这就是因为抵消了主部，丢失了精度。

**2. 正确的泰勒展开（保留精度）：**

根据泰勒展开，$\sin x$ 在 $0$ 处的精确表达式为：

$$\sin x = x - \frac{1}{6}x^3 + o(x^3)$$

将它代入原式：

$$\lim_{x \to 0} \frac{x - (x - \frac{1}{6}x^3 + o(x^3))}{x^3} = \lim_{x \to 0} \frac{\frac{1}{6}x^3 - o(x^3)}{x^3} = \frac{1}{6}$$

**总结**：等价无穷小代换实际上是**一阶泰勒展开**的简写。乘除法对阶数要求不高，一阶足够；但加减法往往需要更高的阶数（更高的精度）来防止同阶项相减归零。因此，加减法中严禁无脑使用等价代换，必须老老实实用泰勒展开补足精度。
