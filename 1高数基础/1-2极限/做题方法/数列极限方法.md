根据你提供的视频文案，针对图片中的经典数列极限问题

$$x_1 = 1, x_{n+1} = 1 + \frac{x_n}{1+x_n}$$

，文案中一共详细讲解了 **6 种顶级解法**（外加一个作为反面教材的“方法零”）。

以下是为你提取并整理的 6 种方法的完整核心逻辑：

### **前期准备：寻找初步界限（基础操作）**

在应用以下方法前，通常需要先通过**数学归纳法**找到数列的一个粗略界限。

- 观察得知 $x_n > 0$。
    
- 由于分子小于分母，$\frac{x_n}{1+x_n} < 1$，因此 $x_{n+1} < 2$。
    
- 通过数学归纳法可初步证明数列有界：** $0 < x_n < 2$ **。
    

### **方法一：先求极限找“精准界”，再做差证明单调性**

**核心思想：** 粗略的界（如 $0 < x_n < 2$）在直接做差比较时可能无法保证恒正或恒负（即文案中失败的“方法零”）。需要利用极限值作为最精准的上界。

1. **先假设极限存在并求值（草纸操作）：** 假设 $\lim_{n \to \infty} x_n = A$。对递推式两边取极限，得到 $A = 1 + \frac{A}{1+A}$。解得 $A = \frac{1+\sqrt{5}}{2}$（负根舍去）。
    
2. **重新证明精准界：** 将求出的极限值 $A = \frac{1+\sqrt{5}}{2}$ 作为新的上界。利用数学归纳法严格证明：$0 < x_n < \frac{1+\sqrt{5}}{2}$。（可利用“糖水不等式”思想快速判断单调性辅助证明）。
    
3. **做差比较：** 计算 $x_{n+1} - x_n = 1 + \frac{x_n}{1+x_n} - x_n$。将式子通分后，由于此时使用了精准界，可以保证该差值恒大于 0，从而得出数列**单调递增**。
    
4. **得出结论：** 由单调有界定理可知极限存在，极限值为 $\frac{1+\sqrt{5}}{2}$。
    

### **方法二：递推式同时变形做差，利用“同号传递性”**

**核心思想：** 不需要精准界，利用相邻两项差值的递推关系来判断单调性。

1. **同时变形做差：** 构造 $x_{n+1} - x_n = \left(1 + \frac{x_n}{1+x_n}\right) - \left(1 + \frac{x_{n-1}}{1+x_{n-1}}\right)$。
    
2. **寻找同号关系：** 通分化简后会发现，$x_{n+1} - x_n$ 的结果等于 $(x_n - x_{n-1})$ 乘以一个含有 $x_n, x_{n-1}$ 的分式。因为已知 $x_n > 0$，所以该分式恒正。
    
3. **代代相传：** 这意味着 $(x_{n+1} - x_n)$ 与 $(x_n - x_{n-1})$ **永远同号**。即“一代强则代代强，一代弱则代代弱”。由此可证数列一定是**单调**的。
    
4. **判断增减性：** 只需要计算迭代起点，若 $x_2 > x_1$ 则单增，若 $x_2 < x_1$ 则单减。结合初步界限，利用单调有界定理求出极限。
    

### **方法三：构造函数求导法（方法二的 Pro 版）**

**核心思想：** 将方法二中的“同号传递”转化为更具普适性的导数判别定理（二级结论）。

1. **构造函数：** 令 $f(x) = 1 + \frac{x}{1+x}$，则有 $x_{n+1} = f(x_n)$。
    
2. **求导判别：** 对 $f(x)$ 求导，得到 $f'(x)$。
    
    - 若 ** $f'(x) > 0$ **，则数列 $\{x_n\}$ **单调**（由于拉格朗日中值定理，可保证差值同号）。
        
    - 若 ** $f'(x) < 0$ **，则数列 $\{x_n\}$ **不单调**（差值异号，数列震荡）。
        
3. **得出结论：** 本题求导后显然 $f'(x) > 0$，故数列单调。再比较 $x_2$ 和 $x_1$ 确定是单增。结合初步有界性，由单调有界定理求出极限。
    

### **方法四：构造 $\vert{}x_n - A\vert{}$，利用放缩与夹逼准则**

**核心思想：** 绕开单调性，直接证明通项 $x_n$ 与目标极限 $A$ 的距离趋于 0。

1. **假设极限：** 设极限为 $A$，满足 $A = 1 + \frac{A}{1+A}$。
    
2. **构造绝对值差：** 计算 $\vert{}x_n - A\vert{}$。将 $x_n$ 用递推式替换，将 $A$ 用 $1 + \frac{A}{1+A}$ 替换（同时变形）。
    
3. **凑出下一项并放缩：** 化简绝对值内的式子，提取出 $\vert{}x_{n-1} - A\vert{}$，得到 $\vert{}x_n - A\vert{} = \text{系数} \times \vert{}x_{n-1} - A\vert{}$。利用已知界限（如 $x_n > 1$ 或 $x_n > 0$），找到一个**小于 1 的常数 $q$ **（如 $1/4$）作为放缩系数，即 $\vert{}x_n - A\vert{} < q\vert{}x_{n-1} - A\vert{}$。
    
4. **递推与夹逼：** 持续利用该不等式往下递推，得到 $\vert{}x_n - A\vert{} < q^{n-1}\vert{}x_1 - A\vert{}$。当 $n \to \infty$ 时，$q^{n-1} \to 0$。由夹逼准则可知 $\lim_{n \to \infty} \vert{}x_n - A\vert{} = 0$，从而证明 $\lim_{n \to \infty} x_n = A$。
    

### **方法五：利用无穷级数比值判别法处理 $\vert{}x_n - A\vert{}$ **

**核心思想：** 利用考研数一/数三的无穷级数知识，通过证明级数收敛来推导通项极限。

1. **重复方法四的前置步骤：** 构造并放缩得到递推不等式 $\vert{}x_n - A\vert{} < q\vert{}x_{n-1} - A\vert{}$（其中常数 $q < 1$）。
    
2. **转化为比值：** 将式子变形为 $\frac{\vert{}x_n - A\vert{}}{\vert{}x_{n-1} - A\vert{}} < q < 1$。
    
3. **级数判别：** 根据无穷级数的**比值判别法**，后一项与前一项之比小于一个严格小于 1 的常数，说明正项级数 $\sum \vert{}x_n - A\vert{}$ **收敛**。
    
4. **必要条件推导极限：** 级数收敛的必要条件是其通项必须趋于 0。因此 $\lim_{n \to \infty} \vert{}x_n - A\vert{} = 0$，从而直接推导出 $x_n$ 以 $A$ 为极限。
    

### **方法六：构造级数 $\sum (x_n - x_{n-1})$ 结合比值判别法（2016 年数一母题法）**

**核心思想：** 巧妙构造差分级数，将数列极限的存在性转化为级数的收敛性问题。

1. **构造相邻项绝对值差：** 构造 $\vert{}x_n - x_{n-1}\vert{}$，并将两项同时用递推式展开。
    
2. **放缩找系数：** 类似于方法四和五，化简后进行放缩，找到一个常数 $q < 1$，使得 $\vert{}x_n - x_{n-1}\vert{} < q\vert{}x_{n-1} - x_{n-2}\vert{}$。
    
3. **比值判别法证明收敛：** 变形得 $\frac{\vert{}x_n - x_{n-1}\vert{}}{\vert{}x_{n-1} - x_{n-2}\vert{}} < q < 1$。由比值判别法知，级数 $\sum \vert{}x_n - x_{n-1}\vert{}$ 收敛。
    
4. **去绝对值推导极限存在：** 加绝对值的级数收敛（绝对收敛），则去绝对值的级数 $\sum (x_n - x_{n-1})$ 必然**更收敛**。
    
5. **展开级数求和：** 将级数 $\sum_{k=2}^n (x_k - x_{k-1})$ 展开，即 $(x_n - x_{n-1}) + (x_{n-1} - x_{n-2}) + \dots + (x_2 - x_1)$，抵消后等于 $x_n - x_1$。既然级数收敛，说明 $\lim_{n \to \infty} (x_n - x_1)$ 存在，从而证明 ** $\lim_{n \to \infty} x_n$ 存在**。
    
6. **计算极限：** 既然已经证明极限存在，设极限为 $A$，代入原递推式解方程求出具体数值即可。
