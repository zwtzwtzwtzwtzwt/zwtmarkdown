在考研 408 数据结构中，判断图中是否存在回路（环）是一个非常高频的考点。无论是选择题中的概念辨析，还是算法综合题中的代码实现，都需要熟练掌握。

判断图是否有回路的方法主要有以下几种，在复习时必须**严格区分它们适用的是“有向图”还是“无向图”**。

### 一、 拓扑排序 (Topological Sort)

- **适用范围**：**仅限有向图**。
    
- **核心原理**：拓扑排序的核心是不断删除入度为 $0$ 的顶点及其发出的边。如果图中存在回路，那么回路上的顶点入度永远不可能减为 $0$，因此永远无法被输出。
    
- **判断条件**：如果在拓扑排序结束后，**输出的顶点总数小于图的总顶点数 $n$**，则说明原有向图中必定存在回路。
    
- **考点延伸**：基于 Kahn 算法（维护入度数组和队列）的拓扑排序本质上就是一种广度优先搜索（BFS）的应用。
    

### 二、 深度优先搜索 (DFS)

- **适用范围**：**有向图、无向图均可**。
    
- **核心原理与判断条件**：
    
    - **对于有向图**：在 DFS 遍历的过程中，如果遇到一个**已经访问过，且当前仍在递归调用栈中**的顶点（即遇到了一条指向祖先节点的“后向边”/“回边”），则说明存在回路。
        
    - **对于无向图**：在 DFS 遍历的过程中，如果遇到一个已经访问过的顶点，且**这个顶点不是当前顶点的直接前驱（父节点）**，则说明存在回路。
        
- **代码实现细节**：通常需要一个 `visited` 数组。对于有向图，还需要额外维护一个 `onStack` 或通过设置 `visited` 状态为不同整数（如 0未访问，1访问中，2已访问）来追踪递归栈。
    

### 三、 并查集 (Disjoint Set / Union-Find)

- **适用范围**：**无向图**。
    
- **核心原理**：将图的顶点看作不同的集合。遍历图中的每一条边 $(u, v)$，判断顶点 $u$ 和 $v$ 是否属于同一个集合。
    
- **判断条件**：在处理边 $(u, v)$ 时，如果 `Find(u) == Find(v)`（即这两个顶点**在合并前就已经连通**），则说明加上这条边之后一定会形成回路。
    
- **考点延伸**：这是 Kruskal（克鲁斯卡尔）最小生成树算法中用来防止生成环的核心机制。


### 四、 广度优先搜索 (BFS)

- **适用范围**：**无向图均可**。
    
- **核心原理与判断条件**：
    
    - **对于无向图**：与 DFS 类似，在 BFS 队列层序遍历时，记录每个节点的入队前驱（父节点）。如果遍历到某条边 $(u, v)$ 时发现 $v$ 已经被访问过，且 $v$ 不是 $u$ 的父节点，则存在回路。
        
    - **对于有向图**：直接使用上述第一点的“拓扑排序”逻辑，因为利用队列维护入度为 $0$ 的节点本身就是 BFS 的过程。
        **D. 广度优先遍历算法 (BFS)**： 这是一个极易混淆的陷阱。在**无向图**中，BFS 确实可以用来判断是否有环（如果遇到已访问且不是前驱的节点，就有环）。但在**有向图**中，普通的 BFS（不统计入度）很难区分出一条边到底是导致回路的“回边”，还是仅仅是殊途同归的“交叉边”（Cross Edge）。 有向图中利用 BFS 判环的唯一有效方式，就是每次寻找入度为 0 的节点并剥离——但这恰恰就是**拓扑排序**的 Kahn 算法实现！题目明确说了“除可以利用拓扑排序外”，所以纯粹的普通 BFS 不能选。

### 五、 顶点与边数的度量关系 (图论性质)

- **适用范围**：**无向图**（主要用于选择题快速判断）。
    
- **判断条件**：在一个包含 $n$ 个顶点的无向图中，**如果边数 $\vert{}E\vert{} \ge n$**，则该图必定存在回路。
    
- **逻辑支撑**：$n$ 个顶点构成无环的连通图（即一棵树）最多只能有 $n-1$ 条边。一旦边数达到或超过 $n$，无论图是否连通，都必然会产生回路。
    

### 总结与复习速查表

| **判断方法** | **适用图类型** | **判定有环的条件**                                        | **408 关联考点**  |
| -------- | --------- | -------------------------------------------------- | ------------- |
| **拓扑排序** | 仅有向图      | 输出的顶点数 $< n$                                       | AOV 网、关键路径    |
| **DFS**  | 无向图       | 有向：遇到回边（在递归栈中的节点）<br><br>  <br><br>无向：遇到非父节点的已访问节点 | 图的遍历、连通性      |
| **并查集**  | 仅无向图      | 连边前，两端点属于同一集合 (`Find(u)==Find(v)`)                 | Kruskal 最小生成树 |
| **边数判断** | 无向图       | 总边数 $\vert{}E\vert{} \ge n$                        | 树与图的性质界限      |



# 例题  
![](./assets/判断图是否有回路的方法/判断图是否有回路的方法-1784548741396.webp)这张图片 `image_303784.png` 的正确答案是 **C. 深度优先遍历算法**。

在应对计算机统考的图论题目时，区分不同遍历算法在特定场景下的“边界能力”非常重要。以下是详细的选项拆解：

**为什么选 C（深度优先遍历算法）？**

在有向图的深度优先搜索（DFS）中，如果从某个顶点出发进行递归遍历，在递归返回之前（即该节点仍在当前递归调用栈中），又一次访问到了这个顶点，就说明图中存在一条指向祖先节点的“回边”（Back Edge）。**有向图中只要存在回边，就必然存在回路。** 因此，DFS 是除拓扑排序外，检测有向图环路最标准、最直接的方法。

**为什么其他选项不合适？**

- **A. 求关键路径的方法**：
    
    求关键路径（AOE 网）的前提条件是这个图**必须已经是一个有向无环图（DAG）**。实际上，在计算关键路径之前，往往需要先跑一遍拓扑排序来确保无环。如果图里有环，关键路径的推导逻辑（事件的最早/最晚发生时间）直接就崩溃了。因此它不能作为“判断”是否有环的普适方法。
    
- **B. 求最短路径的 Dijkstra 算法**：
    
    Dijkstra 算法的核心是贪心策略，用于寻找单源最短路径。它的运行机制是通过维护一个已确定最短路径的顶点集合来进行松弛操作。它并不关心图的整体结构是否存在回边，遇到环也无法直接报告“这里有一个环”，不能用于回路检测。
    
- **D. 广度优先遍历算法 (BFS)**：
    
    这是一个极易混淆的陷阱。在**无向图**中，BFS 确实可以用来判断是否有环（如果遇到已访问且不是前驱的节点，就有环）。但在**有向图**中，普通的 BFS（不统计入度）很难区分出一条边到底是导致回路的“回边”，还是仅仅是殊途同归的“交叉边”（Cross Edge）。
    
    有向图中利用 BFS 判环的唯一有效方式，就是每次寻找入度为 0 的节点并剥离——但这恰恰就是**拓扑排序**的 Kahn 算法实现！题目明确说了“除可以利用拓扑排序外”，所以纯粹的普通 BFS 不能选。
