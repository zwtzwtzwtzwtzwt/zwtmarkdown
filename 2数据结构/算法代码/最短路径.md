最短路径问题是图论中的“压轴戏”，也是考研大题和计算题（填表题）的重灾区。

在考研标准中，这三种算法有明确的适用边界：**BFS** 只能用于无权图（或所有边权相等的图）；**Dijkstra** 用于带权图的单源最短路径（不能有负权边）；**Floyd** 用于带权图的多源（任意两点间）最短路径（可以有负权边，但不能有负权回路）。

为了方便书写代码，我们统一规定使用宏定义 `INF` 表示无穷大（图不连通或无边的情况）。在实际手写代码时，推荐用 `0x3f3f3f3f` 代替 `INF`，因为它相加不会导致 `int` 溢出。

### 1. 基于 BFS 的单源最短路径 (无权图)

**考点提示：** 广度优先搜索天然自带“最短路径”属性。因为它是一层一层往外扩展的，第一次找到目标顶点时，经过的边数一定是最少的。通常配合**邻接表**使用。

需要引入两个辅助数组：

- `d[i]`：记录从起点到顶点 `i` 的最短距离。
    
- `path[i]`：记录从起点到顶点 `i` 的最短路径上的前驱顶点（方便最后顺藤摸瓜打印出完整路径）。
    

C

```C
#define INF 0x3f3f3f3f

void BFS_MinDistance(ALGraph G, int u) {
    int d[MaxVertexNum];    // 最短距离数组
    int path[MaxVertexNum]; // 前驱节点数组
    Queue Q;
    InitQueue(&Q);

    // 1. 初始化数组
    for (int i = 0; i < G.vexnum; i++) {
        d[i] = INF;         // 初始距离设为无穷大
        path[i] = -1;       // 初始前驱设为-1
        visited[i] = false; // 借用全局访问数组
    }

    // 2. 起点入队并初始化
    d[u] = 0;               // 自己到自己的距离为0
    visited[u] = true;
    EnQueue(&Q, u);

    // 3. 开始 BFS 扩展
    while (!isEmpty(Q)) {
        int v;
        DeQueue(&Q, &v);

        // 遍历 v 的所有邻接点
        ArcNode *p = G.vertices[v].firstarc;
        while (p != NULL) {
            int w = p->adjvex;
            if (!visited[w]) {
                visited[w] = true;
                d[w] = d[v] + 1;    // 核心：子节点的距离 = 父节点距离 + 1
                path[w] = v;        // 记录前驱节点
                EnQueue(&Q, w);
            }
            p = p->nextarc;
        }
    }
}
```

### 2. Dijkstra 算法 (带权图 - 单源最短路)

**考点提示：** 考研中 $99\%$ 要求基于**邻接矩阵**手写 Dijkstra。它的核心思想和 Prim 算法极其相似，都是贪心策略：维护一个集合，每次挑一个离起点最近的顶点加入集合，并用它来“松弛”其他顶点的距离。

需要三个核心数组：

- `final[i]`：标记顶点 `i` 是否已经找到最短路径（加入了集合）。
    
- `dist[i]`：起点到顶点 `i` 的当前最短路径长度。
    
- `path[i]`：路径上的前驱顶点。
    

C

```C
void Dijkstra(MGraph G, int v0) {
    int dist[MaxVertexNum];
    int path[MaxVertexNum];
    bool final[MaxVertexNum];

    // 1. 初始化
    for (int i = 0; i < G.vexnum; i++) {
        final[i] = false;
        dist[i] = G.Edge[v0][i];           // 获取初始权值
        if (G.Edge[v0][i] < INF && i != v0) 
            path[i] = v0;                  // 若直接有边，则前驱设为v0
        else 
            path[i] = -1;
    }
    
    final[v0] = true; // 起点自己已找到最短路
    dist[v0] = 0;

    // 2. 循环 n-1 次，找出其余 n-1 个顶点的最短路径
    for (int i = 1; i < G.vexnum; i++) {
        int min = INF;
        int v = -1;

        // (1) 在未确定的顶点中，找一个离起点距离 dist 最小的顶点 v
        for (int j = 0; j < G.vexnum; j++) {
            if (!final[j] && dist[j] < min) {
                min = dist[j];
                v = j;
            }
        }

        if (v == -1) break; // 若找不到，说明剩下的顶点与起点不连通

        final[v] = true;    // 标记顶点 v 已经找到最短路径

        // (2) 核心步骤：以新加入的 v 为中转点，松弛周围的顶点
        for (int j = 0; j < G.vexnum; j++) {
            // 如果 j 没找到最终最短路，且经过 v 中转比原来更近
            if (!final[j] && (dist[v] + G.Edge[v][j] < dist[j])) {
                dist[j] = dist[v] + G.Edge[v][j]; // 更新最短距离
                path[j] = v;                      // 更新前驱为 v
            }
        }
    }
}
```

> **避坑指南：** 考研大题非常喜欢出填表题，让你写出每一趟 `dist` 数组的变化过程。切记：Dijkstra 绝对**不能处理带有负权边**的图，一旦出现负权边，贪心策略就会失效。

### 3. Floyd 算法 (带权图 - 多源最短路)

**考点提示：** Floyd 本质上是动态规划，代码极其简单（三层 `for` 循环），但也是最容易写错的。**最外层循环必须是中转点 $k$！**

需要两个二维数组：

- `A[i][j]`：记录从 `i` 到 `j` 的当前最短距离。
    
- `path[i][j]`：记录从 `i` 到 `j` 路径上的直接中转点（也有教材用来记录前驱，这里采用考研主流的记录中转点法：若没有中转点，设为 -1）。
    



```C
void Floyd(MGraph G) {
    int A[MaxVertexNum][MaxVertexNum];
    int path[MaxVertexNum][MaxVertexNum];

    // 1. 初始化矩阵 A 和 path
    for (int i = 0; i < G.vexnum; i++) {
        for (int j = 0; j < G.vexnum; j++) {
            A[i][j] = G.Edge[i][j];
            path[i][j] = -1; // 初始时，所有两点间均没有中间结点
        }
    }

    // 2. 核心的三重循环 (动态规划过程)
    // ⚠️ 极其重要：k 必须在最外层，代表允许经过的中转点集合 {0, 1, ..., k}
    for (int k = 0; k < G.vexnum; k++) {
        for (int i = 0; i < G.vexnum; i++) {
            for (int j = 0; j < G.vexnum; j++) {
                // 如果经过 k 中转，比 i 直接到 j 更短
                if (A[i][k] + A[k][j] < A[i][j]) {
                    A[i][j] = A[i][k] + A[k][j]; // 更新最短路径长度
                    path[i][j] = k;              // 记录中转点为 k
                }
            }
        }
    }
}
```

> **避坑指南：** 考研选择题常考 Floyd 的时间复杂度，不要犹豫，直接选 $O(|V|^3)$。另外，虽然它可以处理带有负权边的图，但**绝对不能有负权回路**（即一圈加起来是负数），否则在这个圈里无限循环，路径可以无限短。

### 🌟 考研核心对比总结表

复习时，将这三种算法和上面的表格放在一起对比记忆：

|**算法名称**|**解决问题**|**时间复杂度**|**空间复杂度**|**能否处理负权边？**|**核心数据结构**|
|---|---|---|---|---|---|
|**BFS**|单源最短路 (仅限无权图)|$O(\vert V \vert + \vert E \vert)$|$O(\vert V \vert)$|不能|队列、`d[]` 数组|
|**Dijkstra**|单源最短路 (带权图)|$O(\vert V \vert^2)$|$O(\vert V \vert)$|**不能**|贪心、`dist[]` 数组|
|**Floyd**|多源最短路 (任意两点)|$O(\vert V \vert^3)$|$O(\vert V \vert^2)$|**能** (但不能有负权回路)|DP、二维矩阵 `A[][]`|
