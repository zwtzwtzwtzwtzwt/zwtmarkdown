用数组模拟链表（通常被称为**静态链表**）是算法竞赛和底层开发中非常常见且实用的一种技巧。

它的核心优势在于**速度极快**。在某些对运行时间要求严格的场景下（如几百万次插入操作），频繁调用动态分配内存的语法（如 `new Node()` 或 `malloc`）会耗费大量时间并可能导致超时，而使用预先分配好的大数组来模拟内存池，可以做到几乎 $O(1)$ 常数级别的极限效率。

### 核心原理解析

在标准的动态链表中，一个节点包含“值”和“指向下一个节点的指针”。在数组模拟中，我们用**两个平行的数组**和一个**指针变量**来代替：

1. `e[i]` (element)：存储节点 $i$ 的**值**。
    
2. `ne[i]` (next)：存储节点 $i$ 的**下一个节点的下标**。
    
3. `head`：存储**头结点的下标**。
    
4. `idx`：充当内存分配器，记录**当前用到了数组的哪个位置**（即下一个可用的空闲节点的下标）。
    

### 代码实现 (C++ 示例)

以下是实现单链表最核心的四个操作：初始化、插入头部、插入指定位置和删除操作。

C++

```
#include <iostream>

using namespace std;

const int N = 100010; // 预估的最大节点数量

// head 存储链表头，e[] 存储节点的值，ne[] 存储节点的 next 指针，idx 表示当前用到了哪个节点
int head, e[N], ne[N], idx;

// 1. 初始化
void init() {
    head = -1; // -1 代表空集（也就是 NULL 的含义）
    idx = 0;   // 从数组的第 0 个位置开始分配
}

// 2. 将 x 插到头结点
void add_to_head(int x) {
    e[idx] = x;        // 步骤1：把新值放入当前的空闲节点
    ne[idx] = head;    // 步骤2：新节点的 next 指向目前的头节点
    head = idx;        // 步骤3：更新头节点指针，指向这个新节点
    idx++;             // 步骤4：空闲指针后移，准备下一次分配
}

// 3. 将 x 插到下标是 k 的节点后面
void add(int k, int x) {
    e[idx] = x;        // 步骤1：存值
    ne[idx] = ne[k];   // 步骤2：新节点的 next 指向 k 的下一个节点
    ne[k] = idx;       // 步骤3：k 的 next 指向新节点
    idx++;             // 步骤4：空闲指针后移
}

// 4. 将下标是 k 的节点后面的点删掉
void remove(int k) {
    // 直接让 k 的 next 指向它下一个的下一个节点
    ne[k] = ne[ne[k]]; 
}
```

为了让你更直观地理解 `idx` 是如何分配内存，以及 `e` 和 `ne` 数组是如何维持逻辑链表结构的，我为你生成了一个交互式的模拟器。你可以尝试向其中插入数据，观察底层数组的变化。  
遍历用数组模拟的链表（静态链表）非常直观。由于我们用 `head` 记录了头结点的下标，并用 `ne` 数组记录了每个节点下一个指向的下标，我们只需要像经典的 `for` 循环一样，顺藤摸瓜地往下找即可。

### 遍历代码实现 (C++ 示例)

C++

```
// 遍历并打印整个链表
void traverse() {
    // 从头节点 head 开始；只要还没走到空指针 -1；每次走向下一个节点 ne[i]
    for (int i = head; i != -1; i = ne[i]) {
        cout << e[i] << " "; // 输出当前节点的值
    }
    cout << endl;
}
```

### 核心步骤拆解

这短短的一行 `for (int i = head; i != -1; i = ne[i])` 完美对应了标准动态链表（如 `Node* p = head`）的遍历逻辑：

- ** `int i = head;` ** 相当于 `Node* p = head;`。我们声明一个游标 `i`，初始位置定位在链表的第一个有效节点的下标。
    
- ** `i != -1;` ** 相当于 `p != NULL;`。在初始化时，我们约定了 `-1` 代表链表的终点（空集）。只要 `i` 没有变成 `-1`，说明当前节点是真实存在的。
    
- ** `i = ne[i];` ** 相当于 `p = p->next;`。当前节点处理完后，我们通过查 `ne` 数组，获取下一个节点的物理下标，并赋值给 `i`，从而实现游标的后移。
    

这种遍历方式的时间复杂度依然是标准的 $O(N)$，但因为底层内存是连续的数组，它在现代 CPU 的缓存机制（Cache 命中率）下，实际运行速度往往比在内存中碎片化分布的动态链表还要快。****
