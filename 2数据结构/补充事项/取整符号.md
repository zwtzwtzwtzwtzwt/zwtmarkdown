在数学和计算机科学中，取整操作有几种不同的方式，每种方式都有其特定的数学符号和定义。尤其在处理负数时，不同的取整方式会导致完全不同的结果。

以下是四种最常见的取整数学符号及其定义：

### 1. 向下取整（Floor Function）

- **数学符号**：$\lfloor x \rfloor$ （只有下半部分有脚的方括号，俗称“地板函数”）。
    
- **定义**：表示不大于 $x$ 的最大整数。在数轴上，它是向**左**寻找最近的整数。
    
- **示例**：$\lfloor 2.4 \rfloor = 2$ ； $\lfloor -2.4 \rfloor = -3$。
    

### 2. 向上取整（Ceiling Function）

- **数学符号**：$\lceil x \rceil$ （只有上半部分有钩的方括号，俗称“天花板函数”）。
    
- **定义**：表示不小于 $x$ 的最小整数。在数轴上，它是向**右**寻找最近的整数。
    
- **示例**：$\lceil 2.4 \rceil = 3$ ； $\lceil -2.4 \rceil = -2$。
    

### 3. 向零取整 / 截断取整（Truncate）

- **数学符号**：通常写作 $\text{int}(x)$、$\text{trunc}(x)$，在某些传统教材中也用普通方括号 $[x]$ 表示（但 $[x]$ 有时也泛指高斯函数，即向下取整，容易混淆）。
    
- **定义**：直接舍弃小数部分，只保留整数部分。在数轴上，它是向**零**的方向靠拢。
    
- **示例**：$\text{trunc}(2.4) = 2$ ； $\text{trunc}(-2.4) = -2$。
    

### 4. 四舍五入（Round）

- **数学符号**：数学上常写作 $\text{round}(x)$，或利用向下取整表示为 $\lfloor x + 0.5 \rfloor$（主要适用于正数）。
    
- **定义**：结果是距离 $x$ 最近的整数。如果小数部分恰好是 0.5，通常向绝对值更大的方向进位（不同领域有细微差异，如银行家舍入）。
    
- **示例**：$\text{round}(2.4) = 2$ ； $\text{round}(2.6) = 3$ ； $\text{round}(-2.6) = -3$。
