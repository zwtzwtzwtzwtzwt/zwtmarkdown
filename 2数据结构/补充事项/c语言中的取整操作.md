在 C 语言中，除了我们刚刚讨论过的 `floor`（向下取整）和 `ceil`（向上取整），其实还有另外几种常见的取整方式。它们在处理正数和负数时，行为会有明显的差异。

为了给你一个完整的知识体系，C 语言中的取整操作可以归纳为四大类：

### 1. 强制类型转换与整数除法 —— **向零取整 (截断)**

这是 C 语言最原生、最默认的取整方式。无论你是把浮点数强制转换为 `int`，还是进行两个整数的除法（如 `5 / 2`），C 语言都会**直接抹去小数部分**，这种行为被称为“向零截断”。

- **正数：** `(int)3.9` 结果是 `3`
    
- **负数：** `(int)-3.9` 结果是 `-3`
    

### 2. `floor()` —— **向下取整 (向负无穷方向)**

需要包含 `<math.h>`。无论正负，总是寻找**小于等于**该数的最大整数。

- **正数：** `floor(3.9)` 结果是 `3.0`
    
- **负数：** `floor(-3.1)` 结果是 `-4.0`（注意这里变得更小了）
    

### 3. `ceil()` —— **向上取整 (向正无穷方向)**

需要包含 `<math.h>`。无论正负，总是寻找**大于等于**该数的最小整数。

- **正数：** `ceil(3.1)` 结果是 `4.0`
    
- **负数：** `ceil(-3.9)` 结果是 `-3.0`
    

### 4. `round()` —— **四舍五入**

这是 C 99 标准引入的函数，同样需要包含 `<math.h>`。它会寻找**最接近**该数的整数。如果小数部分刚好是 0.5，它会向偏离零的方向取整。

- **正数：** `round(3.4)` 结果是 `3.0`，`round(3.5)` 结果是 `4.0`
    
- **负数：** `round(-3.4)` 结果是 `-3.0`，`round(-3.5)` 结果是 `-4.0`
