# 时间复杂度   
| **操作名称**  | **最好情况** | **最坏情况** | **平均情况**   | **核心原因**                    |
| --------- | -------- | -------- | ---------- | --------------------------- |
| **按位序查找** | $O(1)$   | $O(1)$   | **$O(1)$** | 连续存储，支持数学公式直接计算地址 (随机访问)    |
| **按值查找**  | $O(1)$   | $O(n)$   | **$O(n)$** | 需要从头到尾进行线性遍历对比              |
| **插入**    | $O(1)$   | $O(n)$   | **$O(n)$** | 平均需要向后移动表中一半的元素 ($n/2$)     |
| **删除**    | $O(1)$   | $O(n)$   | **$O(n)$** | 平均需要向前移动表中一半的元素 ($(n-1)/2$) |
