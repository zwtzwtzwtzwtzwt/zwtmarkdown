删除外键
ALTER  TABLE student DROP FOREIGN KEY PK_grade_id;
同时删除索引
ALTER TABLE student DROP INDEX PK_grade_id;  

**外键约束 和 索引是两个完全独立的东西：外键是【参照完整性规则】，索引是【加速查询的数据结构】。** 创建外键时，如果**外键列没有现成可用索引，InnoDB 会自动帮你新建一个普通索引（索引名默认和外键约束同名）**； ** `DROP FOREIGN KEY` 只会删掉外键约束，不会自动删掉这个索引！如果不再需要这个索引，必须单独执行 DROP INDEX 删除。**

> ⚠️ 重点坑：**不能先删索引！** 如果外键约束还存在，直接删索引会报错：`Cannot drop index ... needed in a foreign key constraint` 顺序：**先删外键 → 再删索引**
